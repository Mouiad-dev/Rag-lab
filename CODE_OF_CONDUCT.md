# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). All contributors and maintainers are expected to follow it in every project space, including issues, pull requests, discussions and chat.

## Reporting

Report unacceptable behavior to the maintainers at: **[maintainer contact to be added before public release]**. Reports are handled confidentially. Maintainers review each report and respond with the enforcement steps described in the Contributor Covenant: correction, warning, temporary ban or permanent ban.
