# Learning workspace UI

- Make intermediate evidence visible: chunks, source pages, candidate ranks, transforms, costs and errors.
- Show planned/unavailable techniques explicitly; never let a placeholder appear to run successfully.
- Support Arabic RTL, English LTR, keyboard navigation, loading/empty/error states and accessible labels.
- Display separate task classes and budgets. A report job should not look frozen because a fast-answer timeout was reused.
- Render retrieved/generated content as untrusted. Prevent active artifact HTML from inheriting application credentials.
- Preserve exact configuration and pipeline IDs in experiment links. Avoid exposing internal credentials or raw stack traces.
