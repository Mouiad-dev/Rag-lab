## Goal
- A `TimingChatModel` wrapper records each chat call's total latency. For streamed calls it also records the time to the first non-empty token (TTFT). `complete()` calls have no TTFT, and the report shows `not_applicable` for them.
- The first call per stage and model is marked `cold`.
- A deterministic renderer joins the usage per stage (tokens and cost) with the latency stats. It also summarises the frozen runner's retrieval timings.

## Change
- Create `packages/evaluation/src/rag_foundry_evaluation/timing.py`:
  - `CallTiming` (frozen, `extra="forbid"`): `stage` (`^[a-z_]{1,32}$`), `profile_id`, `mode` (`complete` | `stream`), `total_ms` (>= 0), `ttft_ms` (float | None), `cold` (bool), `ok` (bool). ms values are `round(x, 3)`.
  - `TimingRecorder(clock=time.perf_counter)`:
    - `wrap(model, stage) -> TimingChatModel`; a bad stage raises `EvaluationError("invalid_stage")`.
    - `records() -> tuple[CallTiming, ...]`.
    - `cold` is True for the first call started per `(stage, profile_id)`.
  - `TimingChatModel` exposes `profile`.
    - `complete`: `t0 = clock()`, await the inner call, `t1 = clock()`, then record with `ok=True` and `ttft_ms=None`. On an exception, record `ok=False` and re-raise.
    - `stream`: `t0 = clock()`. On the first chunk with `delta != ""`, set `first = clock()`; this is the only clock call inside the loop. In `finally`, set `end = clock()`. `ttft_ms = (first - t0)*1000` or None; `ok` = whether a chunk carrying `usage` was seen.
- Create `packages/evaluation/src/rag_foundry_evaluation/cost_latency.py`:
  - `StageLatency`: `stage`, `calls`, `failed`, `cold_ms`, `warm_median_ms`, `total_median_ms`, `total_max_ms`, `ttft_median_ms`, `ttft_status` (`measured` | `not_applicable` | `no_tokens`).
    - The stats use ok calls only, with `statistics.median`.
    - `cold_ms` is the total of the cold ok call, or None.
    - `ttft_status` is `not_applicable` when the stage has no stream calls, and `no_tokens` when it has stream calls but no TTFT value.
  - `summarize_timings(records)`: rows sorted by stage.
  - `summarize_runner_timings(timings: dict)`: per label, in insertion order: `n`, `cold_ms` (the first case), `warm_median_ms`, `max_ms`, and `ttft` always `not_applicable`.
  - `render_cost_latency(*, title, usage: dict[str, dict], timings, runner_timings=None, notes) -> str`:
    - **Fixed header paragraph:**
      - latency is wall-clock on this machine for this run, not reproducible, and not in `results_json`;
      - cold = the first call per stage and model in this process; warm = later calls;
      - no answer or embedding cache exists, so cold/warm reflects only process, connection and model-load effects;
      - TTFT exists only for streamed calls.
    - **Table** with columns `stage | calls | failed | input_tokens | output_tokens | cost_usd | estimated_token_calls | cold_ms | warm_median_ms | total_median_ms | total_max_ms | ttft_median_ms | ttft`:
      - rows are the sorted union of usage stages and timing stages;
      - `calls` and `failed` come from the timings when the stage has any; otherwise `calls` = usage `calls` and `failed` = `-`;
      - tokens, `estimated_token_calls` and cost always come from usage; `-` when the stage has no usage;
      - a None cost renders as `unknown`;
      - ms values are `f"{x:.3f}"`, and a missing value is `-`;
      - a stage with usage but no timings shows `ttft` = `not_measured`.
    - Then a `## Retrieval timings` table when `runner_timings` is given.
- Export the new names.
