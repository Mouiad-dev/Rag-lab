## Goal
A safe base for LM Studio, vLLM and Moonshot: the key (optional for local endpoints) is read from the env var named in config, sent only as `Authorization: Bearer`, and never leaks. `OpenAICompatibleEmbeddingModel` passes `EMBEDDING_CHECKS` via `httpx.MockTransport`.

## Change
- Create `adapters/_keys.py`: move `read_api_key(env_var)` and its `_KEY_CHARS` check here unchanged; `_anthropic_http.py` re-imports it so existing imports and tests keep working (no other change there).
- Edit `pyproject.toml`: `openai_compatible = ["httpx==0.28.1"]`; run `uv lock` (metadata only, no new package).
- Create `adapters/_openai_http.py`:
  - `_load_httpx()` raising `AdapterDependencyError("openai_compatible")`.
  - `build_headers(key: SecretStr | None)`: `content-type`, plus Bearer only when a key is given.
  - `openai_status_error(profile_id, status, body_bytes)`: 400/422 → `invalid_request`, 401/403 → `auth`, 402 → `billing`, 404 → `model_not_found`, 408/504 → `timeout`, 413 → `invalid_request`, 429 → `rate_limited`, 500/502 → `server_error`, 503 → `overloaded`, other → `bad_response`. Never copies `error.message`; request id only if 01 names a header, validated by a strict pattern.
  - `post_json(api_base, path, payload, *, key, timeout_s, transport, profile_id)`: `trust_env=False`, no redirects, no retries; refuses (before any I/O) to send a key to a non-loopback `http` URL; errors raised after the `except` block so `__cause__` and `__context__` are None.
- Create `adapters/openai_compat.py` (embeddings part):
  - `OpenAICompatibleEmbeddingModel(profile, *, api_base, api_key_env: str | None, timeout_s=60.0, transport=None, clock=...)`: reads the key at construction when `api_key_env` is set (`MissingCredentialError` names only the variable); `__repr__` shows class and profile id only.
  - `POST {api_base}/embeddings` with `input` list and `model`; vectors reordered by `data[].index`; count and `embedding_dim` mismatch → `bad_response`; empty input handled like the Ollama adapter.
  - Usage: `PROVIDER` when `usage.prompt_tokens` is an int ≥ 0. Missing: `ESTIMATED` if `profile.capabilities.local`, else `bad_response` (never estimate a paid call). Cost via `estimate_cost`.
- Create `tests/providers/test_openai_compat_embedding.py`: `EMBEDDING_CHECKS` pass; index reordering; each status maps; keyless local endpoint sends no `Authorization`; key over remote `http` refused before any request; leak test (sentinel key via `monkeypatch.setenv` under a custom var name, DEBUG logs incl. httpx/httpcore/h11, `str`/`repr`/`traceback.format_exception`, no `__cause__`/`__context__`) for success, 401, 429, connection and bad-JSON paths.
