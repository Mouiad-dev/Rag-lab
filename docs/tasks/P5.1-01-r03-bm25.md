## Change
- `kinds.py`: add frozen `ScoreComponent(name: str, value: float, term: str | None = None)` (name matches `^[a-z0-9_]{1,40}$`, value finite). `RetrievedChunk`: `distance: float | None = None`; add `score_components: tuple[ScoreComponent, ...] = ()`. `RetrievalResult`: add `scoring: str | None = None`. Export `ScoreComponent`.
- `retrievers.py` (R02): set `score_components=(ScoreComponent(name="cosine_similarity", value=score),)` and `scoring="cosine"`. Nothing else changes.
- Create `rag_foundry_indexing/lexical_text.py`: `TOKENIZER_ID = "lab-lexical-v1"`; `lexical_tokens(text) -> tuple[str, ...]`: (1) `normalize_with_map` view (drops bidi controls, tatweel, harakat; folds alef variants); (2) fold Arabic-Indic digits U+0660-0669 and U+06F0-06F9 to ASCII; (3) `casefold()`; (4) word tokens `[^\W_]+`; (5) identifier tokens: every match of `[^\W_]+(?:[-_./:][^\W_]+)+` that contains a digit is also emitted whole (e.g. `ab-1234`). No stopwords, no stemming, no teh-marbuta/yeh folding (documented limits).
- Create `rag_foundry_indexing/bm25.py`: `BM25Config(k: 1..50 = 5, k1: 0.0..3.0 = 1.2, b: 0.0..1.0 = 0.75, max_chunks: 1..50000 = 20000)`, frozen, `extra="forbid"`. `BM25Retriever` manifest `R03`, `PluginKind.RETRIEVER`, `Fidelity.FAITHFUL`, version `1.0.0`; ctor `(config, *, scope, index_version, index)`.
  - `retrieve(query)`: same empty / >2000-char checks as R02; zero query tokens -> `IndexingError("no_query_terms")`. On every call `index.get_index_version(scope, id)` (scope recheck; NotFoundError passes through) and state must be `ready` else `IndexingError("not_ready")`.
  - Corpus = that version's chunks, paged with `list_chunks(limit=500)`; more than `max_chunks` -> `IndexingError("lexical_corpus_too_large")`. Stats built once per instance and kept in memory (not stored; index versions are immutable).
  - Score: sum over distinct query terms `idf * tf*(k1+1) / (tf + k1*(1 - b + b*dl/avgdl))`, `idf = ln(1 + (N - df + 0.5)/(df + 0.5))`, `dl` = token count. Only score > 0 returned; ties by chunk ordinal; rank from 1.
  - Hit: `distance=None`, `score_components` = one `ScoreComponent(name="bm25_term", term=t, value=...)` per matched term in query-term order. Result `technique_id="R03"`, `scoring="bm25-okapi-lucene-idf"`.
- `__init__.py`: export `BM25Config`, `BM25Retriever`, `lexical_tokens`; `register_builtin_plugins` also registers `BM25Retriever` (add a line only).
- `packages/indexing/pyproject.toml`: add `rag-foundry-chunking`; run `uv lock`; `uv.lock` must change only that workspace edge.
- Create `tests/indexing/test_bm25.py` (non-ASCII as `\u` escapes only):
  - Formula: chunks `alpha beta`, `alpha`, `gamma`; query `beta` -> one hit, score `0.814273 +- 1e-4`; components sum to score.
  - Exact id: `رقم القطعة AB-1234`, same with `AB-1243`, same with `AB 1234`; query `AB-1234` -> rank 1 is the first chunk and has a `bm25_term` component with term `ab-1234`. Same with `‏` inside the id in the chunk.
  - Variants: query `كِتَــاب` matches chunk `كتاب` and the reverse; `إدارة` matches `ادارة`; query `ق-٧٧٢` matches chunk `ق-772`.
  - Losing case (asserted as is): query `مكتبة` returns no hit for a chunk containing only `المكتبة` (no stemming or clitic split).
  - Other scope -> NotFoundError; building version -> `not_ready`; punctuation-only query -> `no_query_terms`; registry `validate_config("R03", {}) == BM25Config()`, unknown key rejected; R02 hits now carry `cosine_similarity`.
