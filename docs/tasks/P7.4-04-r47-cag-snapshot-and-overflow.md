## Goal
A frozen, versioned `CagSnapshot` holds every chunk of one ready index version in a fixed order with one stable, secret nonce. Building it rejects anything that would not fit explicitly (no silent selection or truncation). A corpus or bound change gives a new snapshot ID.

## Change
- Create `packages/answering/src/rag_foundry_answering/cag.py` (snapshot part):
  - `CagItem(marker ^S[1-9][0-9]?$, chunk_id, extraction_view_id, start, end, block_ids, text)`.
  - `CagSnapshot(schema: Literal["rag_foundry.cag_snapshot/1"], snapshot_id: 64 hex, tenant_id, project_id, index_version_id, embedding_key, items 1..99, nonce: str = Field(pattern=^[0-9a-f]{16}$, repr=False, exclude=True), prompt_sha256, chat_profile_id, chat_model, context_window, reserve_output_tokens, max_question_tokens, max_evidence_chars (ANSWER_MAX_EVIDENCE_CHARS_MIN..MAX), estimate_margin, estimated_prompt_tokens, tokenizer: Literal["lab-regex-v1"])`. Markers are S1..Sn in item order. `check_scope(scope, index_version_id)` raises `RunError("cag_snapshot_mismatch")`. No `to_json`; snapshots are never persisted.
  - `async build_cag_snapshot(scope, index, index_version_id, *, template, chat_profile, reserve_output_tokens, max_question_tokens, max_evidence_chars, estimate_margin=1.25, nonce_factory=lambda: secrets.token_hex(8)) -> CagSnapshot`:
    1. `get_index_version` in scope (stranger -> `NotFoundError`); not ready -> `cag_snapshot_mismatch`.
    2. Page `list_chunks` to the end; order `(extraction_view_id, start, end, chunk_id)`. None -> `cag_empty`; > 99 -> `cag_too_many_chunks`.
    3. Total chunk chars > `max_evidence_chars` -> `cag_overflow` (detail `evidence_chars=<n>/<cap>`).
    4. Nonce: up to 8 draws; a draw occurring in any chunk text is redrawn; else `RuntimeError` (message without the draws).
    5. Render the grounded request with `build_grounded_request` and a 1-char placeholder question; estimate all message tokens with the lab-regex tokenizer; `ceil(margin * (estimate + max_question_tokens)) + reserve_output_tokens > context_window` (or unknown window) -> `cag_overflow` (numbers only).
    6. `snapshot_id` = SHA-256 of canonical JSON of scope, index version, embedding key, ordered `(chunk_id, sha256(text))`, prompt sha, chat profile id/model, context window, reserve, max question tokens, `max_evidence_chars`, margin and `sha256(nonce)` (never the nonce itself).
  - Comment: "lab-regex-v1 is an estimate, not the model tokenizer; the live test checks provider prompt tokens".
- Create `tests/answering/test_cag_snapshot.py`: fixed order and markers; same inputs and nonce -> same ID; changed `max_evidence_chars` or a rebuilt index -> new ID; two builds with the default factory -> different nonces; a factory whose first draw occurs in a chunk text is redrawn; error paths (`cag_empty` if constructible, else say why not tested; `cag_too_many_chunks`; `cag_overflow` for chars and tokens; unknown window); `max_evidence_chars` outside 500..100000 rejected; stranger scope fails; the nonce is absent from `repr(snapshot)`, `snapshot.model_dump_json()` and every error message, and no chunk text appears in errors; an Arabic chunk survives (`\uXXXX` escapes in source).
