## Goal
R45 builds an in-memory multivector index (one L2-normalised vector per document token, `head="colbert"`) for a ready index version, bound to the chunks' tenant scope, and scores queries by MaxSim. Every hit explains which document token each query token matched.

## Change
- Create `packages/indexing/src/rag_foundry_indexing/late_interaction.py`:
  - `MultivectorIndex` (frozen): `tenant_id`, `project_id` from the ChunkRecords (must equal the build scope), index version id, encoder model, dim, per chunk the token vectors and offsets; `stats()` with chunks, tokens, `estimated_bytes = tokens * dim * 4` (named an estimate).
  - `build_multivector_index(scope, version, index_repo, encoder)`; dim drift -> `multivector_dim_mismatch`.
  - `LateInteractionConfig` (`k`, `max_query_tokens`). `LateInteractionRetriever`: manifest `R45`, `PluginKind.RETRIEVER`, `Fidelity.ADAPTATION` (MaxSim as in Khattab and Zaharia 2020; model, dropped special tokens and no PLAID are deviations). Constructor takes `scope`, version, index (None -> `multivector_index_missing`), encoder (None -> `TechniqueUnavailableError`). `retrieve` first checks the bound scope against the index's tenant/project (mismatch -> the repository's NotFound, no encoder call), then the R05 query checks (empty, too long, not ready, version mismatch).
  - Score = sum over query tokens of max dot product; ties by chunk id. `score_components`: top 5 query tokens by contribution, `name="maxsim_token"`, `term="<query piece>-><doc piece>"`. `scoring="r45-maxsim"`.
- `retrievers.py`: register `LateInteractionRetriever`.
- Create `tests/indexing/test_late_interaction.py` (fake encoder): hand-computed MaxSim on 2 chunks; a crafted case where MaxSim beats the mean of the same vectors; contributions sum to the score; query errors; index for another version rejected; **cross-tenant query**: index built for tenant A, retriever bound to tenant B raises NotFound with zero encoder calls; Arabic query (escapes).
