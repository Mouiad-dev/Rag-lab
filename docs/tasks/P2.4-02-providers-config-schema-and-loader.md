## Goal
`load_providers_config(path)` reads a JSON file into a frozen, `extra="forbid"` model. Unknown keys, unknown references, bad URLs and anything resembling a key value fail with a typed error naming the field, never echoing values. The file holds only the NAME of a key's env var.

## Read only these files
- `docs/decisions/ADR-0001-provider-agnostic-layer.md` (Decision items 2–4; "Decision for P2.4" from 01)
- `packages/providers/src/rag_foundry_providers/{capabilities,errors}.py`
- `packages/core/src/rag_foundry_core/settings.py` (`_validate_ollama_base_url`: rules to mirror; do not edit)
- `config/providers.example.json` (to replace)
- `tests/core/test_settings.py` (bad-URL cases for the parity test)

## Change
- Create `rag_foundry_providers/_urls.py`: `validate_base_url(value, field) -> str` with exactly the Settings rules (http/https, host, no whitespace/control chars, valid port, no user info, no query/fragment, strip one trailing `/`). `is_loopback(url) -> bool` (`127.0.0.0/8`, `::1`, `localhost`).
- Create `rag_foundry_providers/config.py` (pydantic, stdlib `json`, no new deps; `hide_input_in_errors` style: errors never contain input values):
  - `Endpoint`: `id` (profile id pattern), `adapter: Literal["fake", "ollama", "anthropic", "openai_compatible"]`, `base_url: str | None`, `api_key_env: str | None` (pattern `^[A-Z][A-Z0-9_]{0,63}$`), `local: bool`. Rules: `fake` has no base_url/key; `ollama`/`openai_compatible` need base_url; `anthropic` needs `api_key_env`; a key over `http` is allowed only to a loopback host.
  - `ProvidersConfig`: `schema_version: Literal[1]`, optional `note: str`, `endpoints`, `profiles: tuple[ModelProfile, ...]` (existing model, so cost rates and capabilities are reused), `stages: dict[str, str]` (stage id → profile id). Rate fields must be JSON strings (`"0.10"`); a JSON number for a rate is rejected (no float drift).
  - Cross-checks, all reported together: duplicate ids; `profile.provider` names an endpoint; `profile.capabilities.local == endpoint.local`; stage targets exist; `tool_calling`, `structured_output` or `vision` set `True` on a profile whose adapter does not implement them (a per-adapter table; all four adapters implement none in P2.4).
  - `ProvidersConfigError(ProviderError)` with a list of `(location, problem)`; wraps pydantic errors without input values or `__cause__`/`__context__`.
  - `load_providers_config(path: Path) -> ProvidersConfig`: UTF-8, rejects duplicate JSON keys (`object_pairs_hook`), files over 1 MiB, and a non-object root.
- Replace `config/providers.example.json` with a loadable file: endpoints ollama, anthropic, lmstudio, vllm (port per 01), moonshot (values from 01, else `null` model profile omitted); profiles local-chat, local-embed, anthropic-haiku (verified rates as strings), plus one each for lmstudio/vllm/moonshot only where 01 confirmed the model; stages `generator`, `query_transform`, `judge` → local-chat, `embedder` → local-embed. Placeholders only, no key values.
- Create `tests/providers/test_providers_config.py`: the example loads; each rule above has a failing case; unknown key at every level fails; a sentinel value placed in any string field never appears in `str()`/`repr()` of the error; URL parity: every bad URL rejected by `Settings` is rejected by `validate_base_url`.

## Constraints
- Do not edit `settings.py`, `capabilities.py` or `registry.py`. No YAML/TOML dependency. No env var is read here.
