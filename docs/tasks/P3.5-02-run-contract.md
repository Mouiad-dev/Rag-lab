## Change
- Create `rag_foundry_contracts/runs.py` (all models `_Model`):
  - `MAX_QUESTION_CHARS = 2000`, `MAX_RUN_K = 20`; `Marker = Annotated[str, Field(pattern=r"^S[1-9][0-9]?$")]`.
  - `RunRequest`: `contract_version: str = CONTRACT_VERSION` (checked with `check_contract_version`, as in `AnchorResolveRequest`), `question: str` (1..2000 chars, validator rejects whitespace-only), `technique_id: str = "R02"` (pattern `^[A-Z][0-9]{2}$`), `index_version_id: str | None = None` (1..64), `k: int = 5` (1..20), `min_score: float | None = None` (-1..1, finite). No technique-specific rules here (server-side).
  - `RunStatus` StrEnum: `answered`, `abstained`, `ungrounded`. `AbstentionReason` StrEnum: `no_evidence`, `low_score`, `model_declined`, `truncated_output`, `uncited_answer`, `invalid_citation`, `citation_unresolved`.
  - `Evidence`: `marker`, `rank: int >= 1`, `score: float`, `used: bool` (sent to the model), `anchors: tuple[SourceAnchor, ...]` (min 1).
  - `Citation`: `marker`, `anchors: tuple[SourceAnchor, ...]` (min 1).
  - `RunPins`: `technique_id`, `technique_version`, `index_version_id: str | None`, `embedding_key: str | None`, `chat_profile_id`, `chat_provider`, `chat_model`, `prompt_template` (pattern `^[a-z0-9-]+-v[0-9]+$`), `min_score: float | None`, `k: int | None`.
  - `RunUsage`: `model_calls`, `input_tokens`, `output_tokens` (all >= 0), `estimated_cost_usd: Decimal | None`.
  - `RunResponse`: `contract_version: str = CONTRACT_VERSION` (checked with `check_contract_version`), `run_id` (1..64), `status`, `abstention_reason: AbstentionReason | None = None`, `answer: str | None = None`, `citations: tuple[Citation, ...] = ()`, `evidence: tuple[Evidence, ...] = ()`, `pins`, `usage`, `warnings: tuple[str, ...] = ()` (each matches `^[a-z_]{1,64}$`).
  - `RunResponse` model validator: evidence markers and ranks unique and `marker == f"S{rank}"`; `answered` => reason None, answer non-blank, >= 1 citation, every citation marker is a `used` evidence marker, no duplicate citation markers; `abstained` => reason set, answer None, no citations; `ungrounded` => reason None, answer non-blank, no citations, no evidence, `pins.index_version_id is None`.
- `export.py`: add `run-request.v1.json`, `run-response.v1.json`; regenerate into `packages/contracts/schemas/` with `uv run python -m rag_foundry_contracts.export packages/contracts/schemas`.
- `__init__.py`: re-export the new public names.
- Fixtures `packages/contracts/fixtures/runs/`: `request.json` (R02, en question), `response-answered.json` (en anchor, one used evidence S1, citation S1), `response-abstained.json` (`low_score`, one unused evidence carrying the ar anchor), `response-ungrounded.json` (R01). Every fixture states `"contract_version": "1.0"`.
- `tests/contracts/test_runs.py`: all fixtures validate; schema drift test for both files; whitespace-only and 2001-char questions rejected; k 0/21 rejected; `min_score` 1.5 and NaN rejected; major version 2 rejected on both `RunRequest` and `RunResponse`; unknown field rejected; one negative case per validator rule above (each built from a valid fixture with exactly one field changed); `Decimal` cost round-trips through JSON.
