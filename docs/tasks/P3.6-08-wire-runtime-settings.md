## Goal
`LocalRunner`, `AnswerService`, the score gate, `IndexService` and both worker CLIs take tunables from one `RuntimeSettingsService` snapshot per run or build; responses pin `settings_sha256` and the effective values are logged once per run. With no file and no overrides every value equals today's, and the P3.6-00 golden files still match unchanged.
