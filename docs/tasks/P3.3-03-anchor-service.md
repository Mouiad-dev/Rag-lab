- `rag_foundry_ingestion/anchor_service.py`, `AnchorService(store, views, *, provider_namespace, context=32, max_views=10)`:

Group the rest by `extraction_view_id`; more than `max_views` distinct views -> `AnchorError("too_many_views")` before any lookup. Per group: `get_view` NotFoundError (unknown, malformed, other tenant: identical) -> `unavailable/not_found`; `read_payload` raising `ExtractionError` or `ObjectStoreError` -> `unavailable/integrity_error`; else `resolve_anchor` per item.
