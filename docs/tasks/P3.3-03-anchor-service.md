## Change
- `extraction.py`: move the body of `ExtractionService.load_payload` into module function `async def read_payload(store, scope, view) -> ExtractionPayload`; the method delegates. Behavior unchanged.
- `rag_foundry_ingestion/anchor_service.py`, `AnchorService(store, views, *, provider_namespace, context=32, max_views=10)`:
  - `async anchor(scope, view_id, block_id, start, end) -> SourceAnchor` and `async anchors_for_span(scope, view_id, start, end)`: `views.get_view(scope, view_id)` (NotFoundError passes through), `read_payload`, then the 02 functions with `SourceRef(namespace, view.document_id, view.document_version_id, view.id)`.
  - `async resolve(scope, anchors) -> tuple[AnchorResolution, ...]`: same order as input. Foreign namespace -> `unavailable/foreign_namespace` with no lookup. Group the rest by `extraction_view_id`; more than `max_views` distinct views -> `AnchorError("too_many_views")` before any lookup. Per group: `get_view` NotFoundError (unknown, malformed, other tenant: identical) -> `unavailable/not_found`; `read_payload` raising `ExtractionError` or `ObjectStoreError` -> `unavailable/integrity_error`; else `resolve_anchor` per item.
- `errors.py`: add `too_many_views` to the `AnchorError` codes.
- `tests/ingestion/test_anchor_service.py` (LocalObjectStore + in-memory repos, real intake and extraction of a small `.md`): create then resolve -> exact; result order kept with mixed views; payload read once per view (spy on `open_read`); other tenant -> `not_found` and nothing read; tampered payload object -> `integrity_error`; 11 views -> `too_many_views` with nothing read; foreign namespace never calls the repository; existing `test_extraction_service.py` still passes unchanged.
