## Goal
`build_registry` binds each adapter as `Resilient(Budgeted(Recording(adapter)))`. The same contract suite (`CHAT_CHECKS`, `EMBEDDING_CHECKS`) passes offline for fake and MockTransport-backed Ollama, Anthropic and OpenAI-compatible adapters, and (opt-in) live for Ollama and Anthropic. A budget overrun stops a pipeline run with `BudgetExceededError`.

## Change
- Edit `pipeline.py`: `build_registry(..., ledger: UsageSink | None = None, budget: RunBudget | None = None, retry: RetryPolicy | None = None, retry_sleep=asyncio.sleep)`. If any bound profile is non-local and `budget is None` → raise `BudgetRequiredError` (from 04) before any adapter is built or key read (D5). Chat and embedding adapters are wrapped `Recording` (if ledger) → `Budgeted` (if budget; `default_max_output_tokens` from the adapter's `default_max_tokens` property, None for fake/Ollama) → `Resilient` (always; `retry or RetryPolicy()`, `sleep=retry_sleep`). Rerankers are bound unwrapped (fake only today). Local-only configs without these arguments still build.
- Edit `tests/providers/test_pipeline_selection.py`: tests that bind a paid profile pass `budget=RunBudget(Decimal("1"))`; their assertions stay the same (the missing-key test still gets `MissingCredentialError`).
- Create `tests/providers/test_contract_suite.py` (network guard active): one config with endpoints fake, ollama, anthropic and openai_compatible (MockTransports with valid JSON and stream replies; sentinel keys via monkeypatch); build with a `UsageLedger`, `RunBudget(Decimal("1"))`, default policy and a no-op `retry_sleep`; run every `CHAT_CHECKS` and `EMBEDDING_CHECKS` entry against each bound chat/embedding model (parametrized by profile id); afterwards ledger calls > 0 and budget spent <= cap.
  - **Done test:** a paid-rate profile with `RunBudget(Decimal("0.000001"))` → the first `complete` through the registry raises `BudgetExceededError`; the MockTransport saw 0 requests; no retry.
  - 503 then 200 → one success, transport saw 2 requests, ledger holds 1 record. Non-local profile without a budget → `BudgetRequiredError`, transport untouched, key env var never read.
- Edit `tests/live/test_anthropic_live.py`: replace `_CappedModel`/`_guard` with the wrappers (`RunBudget(SPEND_CAP_USD)`, `RetryPolicy(max_attempts=2)`, same `MAX_OUTPUT_TOKENS`); keep skip rules, cap 0.05, the summary test and its assertions.
- Edit `tests/live/test_ollama_live.py`: run the same check tuples through the wrapped stack with `RunBudget(Decimal("0"))` (local, never blocked).
