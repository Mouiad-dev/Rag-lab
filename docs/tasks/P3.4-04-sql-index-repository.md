## Change
- `migrations/versions/0003_minimal_index.py`, raw SQL only (ADR D7). `sql/models.py` and `migrations/env.py` stay unchanged; say so in the migration docstring ("not mirrored in models.py; no autogenerate").
  - `CREATE EXTENSION IF NOT EXISTS vector`; `ALTER TABLE extraction_views ADD CONSTRAINT uq_extraction_views_tenant_id_project_id_id UNIQUE (tenant_id, project_id, id)`.
  - `index_versions`: a column per `IndexVersion` field except `extraction_view_ids`; CHECKs: `state` in 3 values, `distance = 'cosine'`, `embedding_dim` 1..16000, hex formats, counts >= 0; `created_at DEFAULT clock_timestamp()`, `ready_at` nullable; FK `(tenant_id, project_id)` -> `projects (tenant_id, id)`; UNIQUE `(tenant_id, project_id, id)`.
  - `index_version_views (tenant_id, project_id, index_version_id, extraction_view_id)`: PK `(index_version_id, extraction_view_id)`, UNIQUE on all four columns, FK `(tenant_id, project_id, index_version_id)` -> `index_versions`, FK `(tenant_id, project_id, extraction_view_id)` -> `extraction_views`.
  - `chunks`: `id`, `tenant_id`, `project_id`, `index_version_id`, `extraction_view_id`, `ordinal`, `start_cp`, `end_cp`, `split_level`, `block_ids text[]`, `text`, `text_sha256`, `embedding vector NOT NULL`; CHECKs: `end_cp > start_cp`, `char_length(text) = end_cp - start_cp`, `ordinal >= 0`, hex format; UNIQUE `(index_version_id, ordinal)`; FK on the four scope/version/view columns -> `index_version_views`; btree `(tenant_id, project_id, index_version_id, ordinal)`. No ANN index.
  - Triggers: `chunks` BEFORE INSERT rejects unless the version is `building` and `vector_dims(NEW.embedding) = embedding_dim`; `chunks` and `index_version_views` BEFORE UPDATE reject; `index_versions` BEFORE UPDATE allows only `building -> ready|failed` with only `state`, `chunk_count`, `ready_at` changed.
  - Downgrade drops triggers, functions, tables and the new constraint; keeps the extension.
- `sql/index_repository.py`: `SqlIndexRepository(sessionmaker)` implementing the port. Writes lock the version row (`SELECT ... FOR UPDATE`, scoped) and check state first so typed `IndexingError`s are raised (triggers are the backstop). Vectors pass `check_vector` first; literal `"[" + ",".join(repr(x) for x in checked) + "]"`, bound as a parameter with `CAST(:q AS vector)`.
  - `search`, one session, two statements: (1) scoped lookup `SELECT state, embedding_dim FROM index_versions WHERE id, tenant_id, project_id` -> no row: NotFoundError; not `ready`: `not_ready`; dim differs: `dimension_mismatch`; (2) search joining `index_versions` on id and scope, still filtering tenant, project, version and `state = 'ready'`, `ORDER BY c.embedding <=> CAST(:q AS vector), c.ordinal LIMIT :k`; distance read as float. Empty result -> `[]`.
  - Malformed UUIDs -> NotFoundError without a DB round trip.
- TRUNCATE lists in `tests/storage/test_sql_repository.py`, `tests/storage/test_sql_extraction_repository.py`, `tests/api/test_anchors_db.py`: prepend `chunks, index_version_views, index_versions, ` (one-line edit each).
- `tests/storage/test_sql_index_repository.py` (`db` marker, same harness, same TRUNCATE list): run `INDEX_REPOSITORY_CHECKS`; raw-SQL trigger tests (wrong-dim insert, insert into a ready version, chunk UPDATE, pinned-column UPDATE on `index_versions`, chunk with another project's view rejected by FK); downgrade to `0002_extraction_views`, then upgrade head.
