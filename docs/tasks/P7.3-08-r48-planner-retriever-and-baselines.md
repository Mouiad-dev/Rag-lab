## Goal
R48 is a `retriever` plugin (adaptation). One chat call turns the question into a logical form under the schema; the executor (07) runs it; hits are the original chunks behind the supporting facts. The trace shows the plan, each step's bindings, missing facts and conflicts (no chain-of-thought). On the KAG fixture it is compared with R02 dense and R38 entity-graph retrieval, with losing cases.

## Change
- Create `packages/indexing/src/rag_foundry_indexing/kag_retrieve.py`:
  - `R48_PLAN_SYSTEM_V1` + SHA (untrusted-JSON wording; the question is data). User JSON: `{"schema": ..., "grammar": "rag_foundry.kag_lf/1", "question": q}`. Reply: the logical form.
  - `KagConfig(extra="forbid")`: `max_hits` (10, 1-50), `max_output_tokens`, `temperature=0.0`.
  - `KagRetriever`: manifest `R48`, `RETRIEVER`, `1.0.0`, `Fidelity.ADAPTATION`; constructor `(config, *, scope, graph, index, index_version, chat)` calls `graph.check_scope`; version must be `ready`.
  - `retrieve(q)`: one plan call (usage kept even on invalid output). Invalid JSON gives `PlanRejection("invalid_logical_form")`; any rejection gives status `rejected` and empty hits; otherwise `execute`.
    - Hits only when `answered`: chunks from `chunks_for_fact` over `fact_ids`, in fact order, deduplicated; a missing chunk raises `kag_source_mismatch`. `scoring="kag-logical-form"`, score 1.0, component `support_facts`.
    - `incomplete` and `conflict` give empty hits (abstain). No fallback to chunk retrieval.
  - `last_trace = KagTrace(status, attempts: tuple[KagAttempt(plan_json, rejection, execution_status)], steps, answer, conflicts, missing, usage)`; one attempt here (08a may add a second).
- Register in `retrievers.py`; export names; update only a built-in count test if one counts plugins.
- Create `tests/indexing/test_kag_retrieve.py` (graph loaded from the store; scripted plan replies keyed by question). Every comparison prints `recall (hits=n)` per arm:
  - **Multi-hop** "Who leads the organization that Cedar Labs supplies?": R48 answers Omar Nasser, recall 1.0 over the 2 gold spans. R38 (graph from `R38_REPLIES`, default config) and R02 (k=3, lexical test embedder): values asserted as produced, with a comment.
  - **Constraint + count** "How many organizations founded after 2015 supply the Harbor Authority?": derived answer 1 with supporting facts. R38 and R02 have no count operator; record their hit recall only.
  - **Conflict** "When was Blue Reef founded?": `conflict`, empty hits, conflict in the trace.
  - **Losing cases:** extraction miss "Who leads Delta Works?" -> `incomplete`, empty hits, while R02 returns the paragraph; partial "Which organizations supply the Harbor Authority?" -> `answered` with Cedar Labs and Delta Works only (Gulf Marine's fact was rejected in 06; a comment says the KG cannot know it is incomplete); a plan with `deduce` -> `unsupported_operator`; an undeclared predicate -> `schema_violation`; malformed plan JSON -> `invalid_logical_form`, usage recorded.
  - **Arabic** question about the Arabic organization answers with its span.
  - **Guards:** stranger scope, another version's graph, not-ready version raise; `check_plugin_contract` passes; injected text in the question stays in the user JSON.
