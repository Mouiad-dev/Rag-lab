## Goal
`SqlDocumentRepository` implements `DocumentRepository` on PostgreSQL with SQLAlchemy 2 async and passes the same `REPOSITORY_CHECKS` as the in-memory repository. The schema comes from one Alembic migration (enforcing version immutability in the database), applied by a `rag-foundry-migrate` console script.

Stop and report on an advisory or API mismatch.
- Settings: `database_url: SecretStr | None = None` (never logged; `postgresql+psycopg://` only; validated without echoing input).
- `rag_foundry_storage/sql/engine.py`: `create_sessionmaker(url: SecretStr) -> async_sessionmaker`.
- `rag_foundry_storage/sql/models.py`: `tenants`, `projects`, `documents`, `document_versions`. Constraints: `UNIQUE(document_id, version_number)`, `UNIQUE(document_id, sha256)`, composite FKs `(tenant_id, project_id, document_id)` so a version cannot point to another scope's document, `CHECK` on sha256 format, size > 0, media type in the four `MediaType` values.
- `rag_foundry_storage/sql/migrations/` (inside the package) with revision `0001_document_intake`, including triggers that raise on any `UPDATE` of `document_versions` and on `UPDATE` of `documents.tenant_id/project_id`.
- `rag_foundry_storage/sql/migrate.py`: `run_migrations(url: SecretStr, action: Literal["upgrade","downgrade"], revision: str)` builds `alembic.config.Config()` in code (`script_location` from the package path; URL passed via `config.attributes`, never written to an ini file or log). It is **sync** (env.py runs its own event loop): call it outside any running loop. Console script `rag-foundry-migrate [upgrade|downgrade] [revision]` (default `upgrade head`) reading `load_settings().database_url`; exits non-zero with a safe message when unset.
- `rag_foundry_storage/sql/repository.py` `SqlDocumentRepository(sessionmaker)`: one session per call; every query filters by tenant_id and project_id. `create_document_or_get` takes `pg_advisory_xact_lock(hashtextextended('sha:' || :project_id || ':' || :sha256, 0))`, `add_version_or_get` takes `pg_advisory_xact_lock(hashtextextended('doc:' || :document_id, 0))`; both re-read inside the lock before inserting (a hash collision only serializes, never merges). Dedup order: earliest `created_at`, then lowest version ID. `ensure_local_scope(scope)` upserts a tenant and project (used by checks and by 05 in dev/test).
- Tests `tests/storage/test_sql_repository.py`, marker `db` (register strictly in root pytest markers), skipped unless the env var `RAGF_TEST_DATABASE_URL` is set (not a `RAG_FOUNDRY_*` name, so `load_settings` does not reject it). Module setup runs `run_migrations(..., "upgrade", "head")` synchronously. `RepoFactory` = truncate all tables, then `ensure_local_scope` for each requested scope. Run every `REPOSITORY_CHECKS` entry; 10-way concurrent same-bytes test (one version); `UPDATE document_versions` raises; a sync test runs `downgrade base` then `upgrade head`.
