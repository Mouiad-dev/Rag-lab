## Goal
A provider port returns generated tokens with their logprob and top-k alternatives for a raw prompt (no chat template). The Ollama adapter implements it with the fields verified in P7.5-13. The orchestrator registers the approved GGUF as a local Ollama model with a raw template. If 13 said NO-GO, skip this spec.

## Change
- `capabilities.py`: `Capability.RAW_LOGPROBS` (default None, declared True only by profiles that opt in).
- `messages.py`: `TokenLogprob(token: str, logprob: float, top: tuple[tuple[str, float], ...])`, `RawCompletionRequest(prompt, max_output_tokens, temperature=0.0, top_p=1.0, top_k=0, top_logprobs: int (1..20, the verified Ollama max), stop: tuple[str, ...])` (P7.5-13 condition (e): sampler options are always sent explicitly, never left to the GGUF defaults temp 0.6 / top_p 0.9; `top_k=0` means no top-k cut; validate temperature >= 0, 0 < top_p <= 1, top_k >= 0), `RawCompletionResult(text, tokens: tuple[TokenLogprob, ...], finish_reason, usage)`.
- `ports.py`: `RawCompletionModel` Protocol `complete_raw(request) -> RawCompletionResult`; missing capability -> `MissingCapabilityError` before I/O.
- Ollama adapter: `complete_raw` via `/api/generate` with `raw: true` and the verified logprob fields; maps the response to `TokenLogprob`; errors after send are `ProviderCallError`; usage recorded as for chat.
- Existing provider fake (`fake.py`, the provider-layer test double from P2.1; ADR-0022's "technique fakes only in tests/" does not apply to it): add `complete_raw` returning scripted tokens and logprobs; it never claims to be a model result.
- Tests `tests/providers/test_raw_completion.py` (mocked transport): request body has `raw: true`, `logprobs: true`, `top_logprobs`, `stream: false` and `options` with `temperature`, `top_p`, `top_k`, `num_predict` (and `stop` when given); no `system`, `template` or `messages` field; parsing of tokens and top-k; non-opted profile rejected before I/O; contract check added in `contract_checks.py`.
- Live `tests/live/test_raw_completion_live.py` (gated `RAG_LIVE_OLLAMA=1` + `RAG_SELFRAG_MODEL`): Self-RAG prompt format from 13 for one English question with no passage; print the first 10 tokens with logprobs and top-k; assert at least one reflection token string appears as one whole token. Also run the same prompt twice with `top_k=1` and `top_k=0` and print whether the first position's top-20 logprobs are equal (pre-sampler) or not (post-sampler); print only, the decision is P7.5-15's.
- Orchestrator steps (after owner OK, recorded in Result): download the GGUF to `var/models/selfrag/`, verify sha256, create a Modelfile (`FROM` the local file, `TEMPLATE "{{ .Prompt }}"`, no system prompt, context length from 13), `ollama create <name>`; record name, sha256, Ollama version, VRAM use from `ollama ps`.
