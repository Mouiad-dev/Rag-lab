## Goal
`LocalObjectStore` implements the `ObjectStore` port on the local filesystem: it streams an upload to a staging file under a byte limit while computing SHA-256, then atomically moves it to a project-scoped content-addressed key. Settings gain `object_store_root` and `max_upload_bytes`.

## Change
- Create `packages/storage` (`rag-foundry-storage`, depends on `rag-foundry-domain` only); register in workspace, sources, dev group and `Dockerfile`.
- `rag_foundry_storage/local_store.py` `LocalObjectStore(root: Path, *, chunk_size=1 MiB)`:
  - `key_for(scope, sha256)` (sync) → `t/{tenant_id}/p/{project_id}/sha256/{hex[:2]}/{hex}` (D7). IDs and hash validated against strict patterns; nothing from the client becomes a path.
  - `stage`: writes to `root/.staging/<uuid4>` (exclusive create), counts bytes and hashes while streaming; exceeding `max_bytes` stops reading at once, deletes the file, raises `UploadTooLargeError`; 0 bytes → `EmptyUploadError`. Staging file removed on any exception, including cancellation.
  - `commit`: validate the key, refuse any key that escapes `root` or whose components **below `root`** are symlinks (`root` itself may be a symlink, e.g. a mounted volume) → `ObjectStoreError`. `fsync` the staged file, `os.replace` to the target, then `fsync` the parent directory (skip where the OS does not support directory fsync, e.g. Windows). If the target already exists, or `os.replace` raises (e.g. Windows `PermissionError` on an existing read-only target) and the target now exists with the same hash → dedup: discard the staged file and return. Existing target with a different hash → `ObjectStoreError`. Files are made read-only (0o444 where the OS allows).
  - `discard`: idempotent. `open_read(key)` (async iterator of bytes) for later steps; same path checks.
- Edit `settings.py`: `object_store_root: Path = Path("var/objects")` (D4) and `max_upload_bytes: int = Field(100 * 1024 * 1024, ge=1, le=1024**3)` (D6). Extend `tests/core/test_settings.py` (bounds, env override).
- Edit `.gitignore`: add `var/`.
- Create `tests/storage/test_local_store.py` (all on `tmp_path`): hash and size match `hashlib`; exactly `max_bytes` passes, `max_bytes + 1` fails and leaves no staging file; empty upload fails; same bytes committed twice keep one file; two concurrent commits of the same bytes to the same key (`asyncio.gather`) both succeed and leave one file with the right hash; different bytes at an existing key → `ObjectStoreError`; key traversal (`..`, absolute, backslash, bad hex, bad IDs) rejected; symlinked directory below root rejected, symlinked root accepted (skip with reason where symlinks are not permitted); cancellation mid-stage leaves no file; `isinstance(store, ObjectStore)`.

## Constraints
- stdlib only (`hashlib`, `os`, `pathlib`, `asyncio.to_thread` for blocking I/O). No `aiofiles`.
- Do not log file content, full paths of user data, or filenames. Do not touch compose or the API.
