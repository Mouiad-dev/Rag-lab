## Change
- `rag_foundry_domain/indexing.py` (frozen, `extra="forbid"`):
  - `IndexState` StrEnum `building|ready|failed`. `IndexConfig`: `chunker_id` (`^[A-Z][0-9]{2}$`), `chunker_version` (semver), `chunker_config_json` (1..8192), `chunker_config_sha256` (must equal SHA-256 of the JSON's UTF-8), `embedding_profile_id` (1..128), `embedding_provider` (1..64), `embedding_model` (1..256), `embedding_dim` (1..16000), `distance: Literal["cosine"]`, `embedding_key: Sha256Hex`.
  - `NewIndexVersion(IndexConfig)`: `extraction_view_ids: tuple[Uuid4, ...]` (1..100, strictly ascending), `corpus_sha256`, `unanchored_chunk_count >= 0`. `IndexVersion(NewIndexVersion)`: `id`, `tenant_id`, `project_id`, `state`, `chunk_count >= 0`, `created_at`, `ready_at: UtcDatetime | None`.
  - `NewChunk`: `extraction_view_id`, `ordinal >= 0`, `start >= 0`, `end > start`, `split_level` 0..63, `block_ids` (1+ ids, pattern `^b[0-9]{5,8}$`, strictly increasing by numeric ordinal `int(id[1:])`, i.e. payload order, not string order), `text` (len == end - start), `text_sha256` (matches), `embedding: tuple[float, ...]` (stored as returned by `check_vector`). `ChunkRecord`: same without `embedding`, plus `id`, `index_version_id`, `tenant_id`, `project_id`. `ScoredChunk`: `chunk`, `distance: float`, `rank >= 1`.
  - `check_vector(values) -> tuple[float, ...]` (pgvector stores float4): round-trip each value through float32 with `struct.unpack("f", struct.pack("f", x))[0]`; invalid if any input or result is non-finite or `struct.pack` raises `OverflowError`; invalid if the squared norm, rounded the same way to float32, is 0 (underflow). Raises `IndexingError("invalid_vector")`; returns the float32 values. Used by `NewChunk` and by `search` on the query.
  - `embedding_key_for(provider, model, dim) -> str`: SHA-256 hex of `json.dumps({"scheme":"embedding-key-v1","provider":..,"model":..,"embedding_dim":..,"distance":"cosine","preprocessing":"none"}, sort_keys=True, separators=(",",":"))`. Profile id is not part of the key. `corpus_sha256_for(pairs: Iterable[tuple[view_id, payload_sha256]])`: SHA-256 of `"\n".join(f"{v}:{p}")` sorted by view id, UTF-8.
- `errors.py`: `IndexingError(IntakeError)` with `CODES` `not_building`, `not_ready`, `dimension_mismatch`, `invalid_vector`, `duplicate_ordinal`, `empty_index`, `invalid_k`, `invalid_page`, `incompatible_embedding`, `missing_embedding_dim`, `empty_query`, `query_too_long`, `too_many_views`, `embedding_count_mismatch` (unknown code -> ValueError; message carries no text).
- `ports.py`: `IndexRepository` Protocol (unknown/malformed/other-scope IDs -> same `NotFoundError`): `create_index_version(scope, new)` (every view in scope, else NotFoundError, nothing written); `add_chunks(scope, index_version_id, chunks)` (all-or-nothing; `not_building`, `dimension_mismatch`, `duplicate_ordinal`, view not in the version -> NotFoundError); `mark_ready` (sets `chunk_count`, `ready_at`; zero chunks -> `empty_index`); `mark_failed`; both only from `building` else `not_building`; `get_index_version`; `list_chunks(scope, id, *, offset=0, limit=100)` (limit 1..500, offset >= 0 else `invalid_page`; ordinal order); `search(scope, id, query, k)` (version must exist in scope else NotFoundError; `ready` only else `not_ready`; dim -> `dimension_mismatch`; `check_vector`; k 1..100 else `invalid_k`; cosine distance ascending, ties by ordinal; ranks 1..n; an empty list is valid).
- New `rag_foundry_domain/index_testing.py`: `InMemoryIndexRepository(views)` (exact cosine in Python over float32 values), `make_new_index_version(view_ids, *, dim=4)`, `make_chunk(view_id, ordinal, vector, text="t")`, `IndexRepoFactory` Protocol (`async (scopes) -> (docs, views, index)`), `INDEX_REPOSITORY_CHECKS` covering every rule above plus: other-tenant chunks with identical vectors never returned; ties `[1,0,0,0]` x2 ordered by ordinal; Arabic-with-harakat and non-BMP emoji chunk text round-trips; records frozen; distances compared with tolerance 1e-5.
- `tests/domain/test_indexing.py`: model validators (block ids `b99999` before `b100000` accepted, reverse rejected); `check_vector`, one test per case: `[3.5e38, 0, 0, 0]` (float32 overflow), `inf`, `nan`, all zeros, `[1e-30] * 4` (values fit float32, squared norm underflows -> invalid), valid vector returned as float32 values; `embedding_key_for` golden value computed in the test from the spec formula, and it differs when only the model differs; run `INDEX_REPOSITORY_CHECKS` against the in-memory repo.
