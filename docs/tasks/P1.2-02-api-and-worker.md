## Goal
`uv run rag-foundry-api` serves `GET /health` and returns `{"status": "ok", "version": "0.0.0"}`. `uv run rag-foundry-worker --once` starts, loads settings and exits 0. Both are covered by tests.

## Read only these files
- `pyproject.toml` (root: workspace members, dev group and sources)
- `packages/core/pyproject.toml` (copy its build backend and metadata style)
- `packages/core/src/rag_foundry_core/settings.py` (`Settings`, `load_settings`)
- FastAPI docs: "Testing" and app factory basics. Uvicorn docs: `uvicorn.run` (current official docs).

## Change
- Edit the root `pyproject.toml`:
  - Change `members` to `["packages/core", "apps/api", "apps/worker"]`.
  - Add `rag-foundry-api`, `rag-foundry-worker` and `httpx` to the `dev` group, with workspace sources for the two apps. Then run `uv lock`.
- Create `apps/api/pyproject.toml`: name `rag-foundry-api`, deps `rag-foundry-core` (workspace), `fastapi`, `uvicorn`, script `rag-foundry-api = "rag_foundry_api.main:run"`.
- Create `apps/api/src/rag_foundry_api/__init__.py` and `main.py`:
  - `create_app(settings: Settings | None = None) -> FastAPI`
  - `GET /health` returns status and `rag_foundry_core.__version__`, with no settings values or env echo.
  - `run()` loads settings and calls `uvicorn.run(create_app(s), host=s.api_host, port=s.api_port)`.
- Create `apps/worker/pyproject.toml`: name `rag-foundry-worker`, dep `rag-foundry-core` (workspace), script `rag-foundry-worker = "rag_foundry_worker.main:main"`.
- Create `apps/worker/src/rag_foundry_worker/__init__.py`, `__main__.py` and `main.py`:
  - `main(argv=None) -> int` uses argparse with `--once`.
  - It loads settings, logs `worker started env=<environment>` and returns 0 with `--once`.
  - Without `--once` it loops with `time.sleep(worker_poll_seconds)` and returns 0 on `KeyboardInterrupt`. The loop does no work yet.
- Create `tests/api/test_health.py` (TestClient: 200, exact JSON body, unknown route 404) and `tests/worker/test_main.py` (`main(["--once"]) == 0`, and settings errors from a bad env file propagate as a non-zero exit or `ValidationError`).

## Constraints
- The API binds to `127.0.0.1` by default. No CORS, auth or database yet.
- `/health` must not leak settings, paths or environment variables.
- Do not import vendor or model SDKs. The worker does not import FastAPI.
- If the user declines httpx, drop it. Test `/health` by starting `rag-foundry-api` in a subprocess on a free port and fetching it with `urllib.request`. Always terminate the server.
