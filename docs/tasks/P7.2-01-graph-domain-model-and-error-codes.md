## Change
- Create `packages/domain/src/rag_foundry_domain/graphs.py` (frozen, `extra="forbid"`):
  - `GraphSpan(chunk_id: Uuid4, extraction_view_id: Uuid4, start >= 0, end > start, quote)`; validator `len(quote) == end - start`.
  - `Entity(entity_id ~ ^ent_[0-9a-f]{16}$, name 1-500, type 1-64, mentions: 1-50 GraphSpan)`; `Relation(relation_id ~ ^rel_[0-9a-f]{16}$, source_id, target_id, label 1-200, evidence: 1-50 GraphSpan)`.
  - `normalize_name(s)`: NFC, casefold, collapse whitespace. `entity_id_for(name, type)` and `relation_id_for(source_id, label, target_id)`: prefix + first 16 hex of SHA-256 over canonical JSON of the normalized parts. No alias resolution.
  - `graph_key_for(payload) -> str`: SHA-256 hex (64) of canonical JSON. The builder (04) passes `{index_version_id, technique_id, builder_version, prompt_sha256, chat_provider, chat_model, config}`.
  - `EntityGraph(schema: Literal["rag_foundry.entity_graph/1"], graph_key, tenant_id, project_id, index_version_id, technique_id="R38", generator_json <= 8000, entities <= 5000, relations <= 10000)`. Validators: unique IDs; relation endpoints exist; entities and relations sorted by ID (builder sorts). Methods:
    - `check_scope(scope, index_version_id)` -> `IndexingError("graph_scope_mismatch")`.
    - `to_json()` / `from_json()` (export form; unknown schema -> `graph_invalid`).
    - `neighbors(entity_id) -> tuple[(relation_id, other_entity_id, direction), ...]`, sorted; relations are traversed **undirected**, `direction` is `forward` or `reverse`.
    - `shortest_path(a, b, max_hops) -> tuple[(relation_id, direction), ...] | None`: stdlib BFS, neighbors in sorted order, deterministic.
- `errors.py`: add to `IndexingError.CODES`: `graph_scope_mismatch`, `graph_source_mismatch`, `graph_invalid`, `graph_exists`, `graph_too_large`, `graph_evidence_missing`, `graph_key_mismatch`, `untraced_claim`, `community_cap_exceeded`, `global_search_too_many_communities`.
- Create `tests/domain/test_graphs.py`:
  - every new code constructs (`IndexingError(code).code == code`);
  - ID functions are stable and merge "Cedar  Labs" / "cedar labs"; Arabic names (`\uXXXX` escapes) normalize under NFC;
  - validation errors: quote length mismatch, dangling relation endpoint, duplicate ID;
  - JSON round-trip equals; stranger scope and other version fail `check_scope`;
  - `shortest_path` walks an edge in reverse (relations stored as `Omar Nasser -leads-> Harbor Authority`, path from `Harbor Authority` side) and returns `reverse`; `max_hops` cut-off returns `None`; deterministic tie between two equal-length paths.
