## Change
- Create `scripts/tasks.py`. Standard library only, under ~80 lines. Use `argparse` with these subcommands:
  - `lint`: `ruff check .` and `ruff format --check .`
  - `format`: `ruff format .` and `ruff check --fix .`
  - `test`: `pytest`
  - `repo`: `verify_package.py`, `unittest discover -s tests/hooks -v` and `build_flow.py --check`
  - `check`: `repo`, then `lint`, then `test`. Stop at the first failure and return its exit code.
  - Run every command with `subprocess.run([...], cwd=ROOT, check=False)` using list arguments. Use `sys.executable` for Python scripts and `[sys.executable, "-m", "ruff"|"pytest"]` for tools. Never use `shell=True`. Print each command before running it.
- Edit `CONTRIBUTING.md` and add a "Development setup" subsection with these commands:
  - `uv sync --locked`
  - `uv run python scripts/tasks.py check`
  - the individual `uv run pytest` and `uv run ruff check .` commands
  - Note that the three plain `python scripts/...` checks stay stdlib-only and do not need uv.
