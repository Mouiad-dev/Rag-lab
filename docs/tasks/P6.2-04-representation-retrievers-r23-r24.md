## Goal
- R23 and R24 retrievers search the stored synthetic representations and return the **original** chunk as the hit.
- They report which representation matched (kind, ordinal, synthetic text). The synthetic text appears only in the trace, never in `hit.text`.

## Change
- Create `packages/indexing/src/rag_foundry_indexing/representations.py`.
- `RepresentationSearchConfig`:
  - `representation_key` (64 lowercase hex), `k` 5 (1..50), `candidate_k` 20 (1..100, must be >= k, else a validation error), `include_original: bool`.
  - R23 default `include_original=True`; R24 default `False` (subclass the config or override the default).
- `RepresentationMatch(chunk_id, rank, kind: Literal["original","summary","question","context_prefix"], ordinal, synthetic: bool, text: str | None, distance)`. For `original`: `ordinal=0`, `synthetic=False`, `text=None`. `RepresentationRetrieval(result, matches)`.
- Base class `_RepresentationRetriever(config, *, scope, index_version, index, embedder)`, with `retrieve_traced(question)` and `retrieve(question) -> RetrievalResult`. Order:
  1. `check_question(question)`: `QueryTransformError` `empty_query` / `query_too_long`.
  2. Version state not ready -> `IndexingError("not_ready")`. Embedding key differs from the version -> `incompatible_embedding`. Both happen **before** any embedding call.
  3. `get_representation_set` (NotFoundError for another scope or an unknown key). If `set.technique_id` is not the plugin's id -> `representation_technique_mismatch`.
  4. Embed the question once (`input_type="query"`). Run `representation_search(candidate_k)`. If `include_original`, also run `index.search(candidate_k)`.
  5. A matched kind outside the plugin's allowed kinds -> `representation_kind_mismatch`. R23 allows `summary` and `question`; R24 allows `context_prefix`.
  6. **Merging candidates.** Keep the smallest distance per chunk. On ties prefer `original`, then kind in string order, then ordinal. Sort by (distance, chunk ordinal), take k, number the ranks from 1.
  7. **Building each hit.** `hit.text = chunk.text`. Check `sha256(chunk.text) == chunk.text_sha256`, else `representation_source_mismatch`. `score = 1 - distance`. Add one component `ScoreComponent(name="representation_cosine", value=score, term=f"{kind}:{ordinal}")`. Keep the parent span from the chunk.
  8. Set `RetrievalResult.technique_id` to the plugin id. `grounding` is `"corpus"`, `index_version_id` is the version id, `scoring` is `"representation-max-cosine"`.
- Plugins, both `PluginKind.REPRESENTATION`, 1.0.0, ADAPTATION:
  - `MultiRepresentationRetriever` (R23);
  - `ContextualRetriever` (R24).

  Register both in `retrievers.py`; export them in `__init__.py`.
- Create `tests/indexing/test_representation_retrievers.py`:
  - **Setup.** `ScriptedEmbedder` (dim 4) with a dict text->vector. `ready_index` holds chunk A `"Port Sallow tide log."` at (0,0,1,0) and chunk B `"Mill Lane bakery opens early."` at (0,0,0,1). Insert the R23 set and rows with `add_representations`: A summary `"S-A"` (1,0,0,0); B question 0 `"Q-B0"` (0,1,0,0); B question 1 `"Q-B1"` (0.6,0.8,0,0).
  1. Query `"q1"` -> (1,0,0,0), k=2: r1 A score approx 1.0, term `summary:0`; r2 B score approx 0.6, term `question:1`. `matches[0].text == "S-A"`, `synthetic is True`.
  2. Query `"q2"` -> (0,0,1,0), `include_original=True`: r1 A term `original:0`, score 1.0; r2 B term `original:0`, score 0.0.
  3. Same query, `include_original=False` (losing case): r1 A term `summary:0`, score 0.0; r2 B term `question:0`.
  4. In every result, `hit.text` is the chunk text, and no synthetic string is a substring of any `hit.text`.
  5. R24 on an R24 set with A context_prefix text = U+0633 U+064A U+0627 U+0642 + `" A"` (backslash-u escapes in code), vector (1,0,0,0): r1 A term `context_prefix:0`, and the Arabic text appears only in `matches`.
  6. Errors:
     - R24 on the R23 key -> `representation_technique_mismatch`;
     - a stranger scope -> NotFoundError;
     - an unknown key -> NotFoundError;
     - `candidate_k < k` -> ValidationError;
     - an embedder with another model -> `incompatible_embedding`;
     - an empty question -> `QueryTransformError` `empty_query`;
     - a version that is not ready -> `not_ready`, with the embedder never called.

## Constraints
