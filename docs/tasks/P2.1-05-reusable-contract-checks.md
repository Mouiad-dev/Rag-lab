## Goal
`rag_foundry_providers.contract_checks` exposes port-level checks as plain async functions with no pytest import. P2.2/P2.3 adapters and the P2.5 suite can reuse them. They pass against the fake provider while every non-loopback socket connection is blocked. This closes the P2.1 done criteria.

## Change
- Create `src/rag_foundry_providers/contract_checks.py`. Each check is `async def check_<name>(model) -> None` and uses plain `assert` or raises `AssertionError` with a clear message. Group the checks in tuples:
  - `CHAT_CHECKS`:
    - `complete` returns a `ChatResult` whose usage matches the profile.
    - The usage has `operation=chat`, tokens `>= 0`, latency `>= 0`, and cost that is `None` or `>= 0`.
    - An Arabic user message is accepted.
    - Streaming: if `declared(streaming)` is `True`, there is exactly one usage-bearing chunk and it is last, with `operation=chat_stream` and non-empty concatenated text. Otherwise `stream` raises `MissingCapabilityError`.
    - `tools` / `response_schema` raise `MissingCapabilityError` when the flag is not `True`. When it is `True`, the result is checked for `tool_calls`/`structured` shape (unreachable with the fake; adapters exercise it).
  - `EMBEDDING_CHECKS`:
    - Count matches.
    - Each vector length equals `profile.capabilities.embedding_dim`, and all values are finite.
    - `operation=embed` and `output_tokens == 0`.
    - Empty input returns empty vectors.
    - Both `input_type` values are accepted.
  - `RERANK_CHECKS`:
    - Indices are unique and inside the input range.
    - Scores are non-increasing.
    - `top_n` is respected.
    - `operation=rerank`.
  - `REGISTRY_CHECKS(registry, pid)`: binding round-trip, and that `validate_requirements` accepts the profile's own declared capabilities.
- Edit `__init__.py` to export the registry, fake and contract-check names.
- Create `tests/providers/conftest.py` with an autouse fixture, `no_network`, that monkeypatches the following to raise `RuntimeError("network blocked in provider tests")`:
  - `socket.getaddrinfo`
  - `socket.create_connection`
  - `socket.socket.connect` / `connect_ex` for non-loopback addresses only. Loopback must stay allowed because the Windows asyncio event loop uses a loopback `socketpair`.
- Create `tests/providers/test_fake_contract.py`. Parametrize over each check tuple with `ids` set to the function names. Run chat checks against both `fake_chat_profile(streaming=True)` and `(streaming=False)`. Add one guard self-test: `socket.create_connection(("example.com", 80))` raises the guard error.
- Replace `packages/providers/README.md` with:
  - What P2.1 provides: ports, profiles and flags (`None` = not declared), usage and cost (`None` = unknown), registry, fake.
  - How adapters reuse `contract_checks`.
  - That there are no adapters, no keys and no network yet, and that the local Ollama default arrives in P2.2.

## Constraints
- `contract_checks.py` must not import pytest or anything outside stdlib and pydantic.
- Do not weaken the checks to suit the fake. A check that needs a capability the fake lacks must test the refusal path.
- `docs/PROGRESS.md` is updated by the owner after review, as in P1.5.
