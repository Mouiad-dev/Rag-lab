## Goal
A post-retrieval expander turns ranked hits into wider source spans read from the pinned extraction view, never leaving the caller's scope or the index version. R21 widens each hit by N neighbouring sentences. Every output hit is an exact code-point span: `hit.text == canonical[start:end]`.

## Change
- Create `packages/indexing/src/rag_foundry_indexing/context_expansion.py`:
  - `SourceBlockRef(block_id,start,end)`, `ViewSource(extraction_view_id, text, blocks)`; Protocol `SourceTextReader.view_source(scope, view_id) -> ViewSource`.
  - `PayloadSourceReader(store, uow, *, max_cached_views=16)`. It calls `get_view` in a read-only UoW (scope is checked there), **closes the UoW**, and only then calls `read_payload`. Cache key `(tenant_id, project_id, view_id)`; evict the oldest beyond the cap.
  - `ExpansionSeed(chunk_id,start,end,rank)`, `ExpandedContext(chunk_id, extraction_view_id, start, end, seeds, flags)`, `ExpansionTrace(technique_id, input_technique_id, index_version_id, rule, input_chars, output_chars, contexts, dropped_for_budget)`, `ExpandedRetrieval(trace, input, result)`; all frozen, `extra="forbid"`.
  - `async load_sources(result, *, scope, index, index_version, source, max_seeds) -> (fetched_version, sources)`. Checks, in order (all `IndexingError`):
    1. invalid input as in `check_single_input` -> `expansion_invalid_input`;
    2. more hits than `max_seeds` -> `expansion_too_many_candidates`;
    3. `result.index_version_id != index_version.id` -> `expansion_version_mismatch`;
    4. `await index.get_index_version(scope, index_version.id)`: NotFoundError passes through; a state other than ready -> `not_ready`;
    5. a hit's view not in `version.extraction_view_ids` -> `expansion_view_not_in_index`;
    6. `end > len(text)` or `text[start:end] != hit.text` -> `expansion_source_mismatch`.
  - `context_id_for(technique_id, view_id, start, end)` = `"ctx_" + sha256(json [tid, view, start, end])[:24]`.
  - `merge_overlapping(candidates)`: candidates in the same view that share at least one code point merge into the earlier-ranked one. Repeat until no two overlap. Touching spans (`a.end == b.start`) do NOT merge.
  - `assemble(...)`. Merging happens **before** this step.
    - Outputs are ordered by best seed rank, and ranks are renumbered from 1.
    - **Budget.** Applied in rank order: stop at the first output that would push the total above `max_total_chars`. Its seeds and all later seeds go to `dropped_for_budget`.
    - **Result fields.** `technique_id` = the expander's id (`"R21"` here), `index_version_id` unchanged, `grounding="corpus"`, and a fixed `scoring` string per technique (`"sentence-window"` for R21).
    - **Each output hit.** text = the source slice; block_ids = source blocks overlapping the span; score = best seed score; distance None. Components = the best seed's components + `seed_rank` (source = input technique id) + `expanded_chars`.
    - **Ids.** An output whose span equals a single seed span keeps that seed's chunk_id and parent span. Any other output gets `context_id_for` and no parent span.
  - `ExpandingRetriever(base, expander)`: `retrieve(q)` returns `expander.expand(base result).result` and stores the full `ExpandedRetrieval` in `.last`.
- Create `sentence_window.py`. `SentenceWindowConfig`:
  - `window` 1 (1..5), `stay_in_paragraph` True, `max_window_chars` 2000 (20..20000), `max_total_chars` 8000 (20..100000), `max_seeds` 20 (1..50).
  - `SentenceWindowExpander`: manifest R21, `CONTEXT_BUILDER`, 1.0.0, ADAPTATION. Init: `(config, *, scope, index_version, index, source)`; method `async expand(result) -> ExpandedRetrieval`.
  - **Rule.** A paragraph is a maximal range without `\n[ \t]*\n`. Sentences come from `sentence_ranges` over the seed's paragraph(s), or over the whole text when `stay_in_paragraph` is False. The window is the sentences overlapping the seed, plus `window` before and after, unioned with the seed span.
  - **Too long.** If the window is longer than `max_window_chars`, reduce `window` one step at a time, down to 0 (flag `window_reduced`). If even window 0 is too long, which happens when a seed covers part of a long sentence, the output is the exact seed span (flag `seed_only`).
- Edit `retrievers.py` (register R21) and `__init__.py` (export new names).
- Create `tests/indexing/_source_reader.py`: `StaticSourceReader({(tenant_id, project_id, view_id): ViewSource})`. It raises NotFoundError for any other key.
- Create `tests/indexing/test_sentence_window.py`. Use `T1 = "Alpha one. Beta two. Gamma three.\n\nDelta four. Eps five."`, whose sentences are [0,10) [11,20) [21,33) [35,46) [47,56); `ready_index` holds those 5 spans. Expected:
  1. seed [11,20), window 1 -> one hit [0,33) `"Alpha one. Beta two. Gamma three."`, id starts `ctx_`, `technique_id == "R21"`.
  2. seed [21,33) -> [11,33); with `stay_in_paragraph=False` -> [11,46).
  3. seeds [11,20) r1, [35,46) r2 -> [0,33) r1 and [35,56) r2; `input_chars` 20, `output_chars` 54. With `max_total_chars=40`, `dropped_for_budget == (id of [35,46),)`.
  4. seeds [0,10) r1, [21,33) r2 -> one hit [0,33) whose seeds are both.
  5. seed [11,20) with `max_window_chars=25` -> [11,20), same chunk_id, flag `window_reduced`.
  6. `T3 = "Alphaaaaa oneeeeee twoooooo three."` is one sentence [0,34). Seed chunk [0,9) `"Alphaaaaa"` with `max_window_chars=20` -> hit [0,9), same chunk_id, flag `seed_only`.
  7. `merge_overlapping` unit: [0,10) [8,20) [18,30) -> one [0,30). [0,10) [10,20) -> two (touching).
  8. Arabic TA, written in the test with backslash-u escapes:
     - Code points: U+0627 U+0644 U+0623 U+0648 U+0644 U+0649 `.` space U+0627 U+0644 U+062B U+0627 U+0646 U+064A U+0629 U+061F space U+0627 U+0644 U+062B U+0627 U+0644 U+062B U+0629 `.` (len 25).
     - Sentences [0,7) [8,16) [17,25). Seed [8,16) -> [0,25) == TA.
  9. Errors:
     - a stranger scope raises NotFoundError;
     - a result whose `index_version_id` is another version raises `expansion_version_mismatch`;
     - a hit whose view id is not in the index raises `expansion_view_not_in_index`;
     - hit text `"Beta twx."` raises `expansion_source_mismatch`;
     - 21 seeds with `max_seeds=20` raise `expansion_too_many_candidates`.
  10. For every output, `hit.text == T[start:end]`. `ExpandingRetriever` over a stub base sets `.last`.
