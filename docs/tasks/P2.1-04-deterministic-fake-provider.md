## Goal
`rag_foundry_providers.fake` provides `FakeChatModel`, `FakeEmbeddingModel` and `FakeReranker`. They implement the P2.1-02 ports with no network or keys, and they give the same outputs and the same `Usage` on every run, process and OS.

## Change
- Create `src/rag_foundry_providers/fake.py`:
  - Add the helpers `fake_chat_profile(id="fake-chat", *, streaming=True)`, `fake_embedding_profile(id="fake-embed", *, dim=16)` and `fake_reranker_profile(id="fake-rerank")`.
    - Use `provider="fake"`, `model="fake-<kind>-v1"` and `local=True`, with cost rates `Decimal("0")`.
    - `tool_calling` and `structured_output` are declared `False`. Declare them honestly, because the fake does not implement them.
  - Tokens are `len(text.split())` summed over the input. This is a documented approximation, not a tokenizer.
  - Latency comes from an injected `clock: Clock`. The default is `StepClock(step_s=0.001)`, a deterministic counter, so the default `latency_ms` is `1.0` per call. Real adapters will use `time.perf_counter`.
  - Cost is `estimate_cost(profile, ...)`.
  - `FakeChatModel(profile, clock=...)`:
    - `complete` calls `check_chat_request(..., streaming=False)` and returns `text = f"[fake] {last user message content}"`, with `finish_reason="stop"`, `operation=chat` and output tokens counted on `text`.
    - `stream` calls `check_chat_request(..., streaming=True)`. It yields the words of the same text with their original whitespace preserved, so that the deltas concatenate exactly to `complete().text`. The last chunk carries `Usage` (`operation=chat_stream`).
  - `FakeEmbeddingModel(profile, clock=...)`. For each text, compute the vector from the SHA-256 of `f"{model}\x00{input_type}\x00{text}"` (UTF-8), expanded with counter blocks to `dim` floats. Map each 4-byte unsigned int to `[-1, 1]`, then L2-normalize. `output_tokens=0`, and empty input gives `vectors=()` with zero tokens. Do not use Python `hash()`.
  - `FakeReranker(profile, clock=...)`. The score is the Jaccard overlap of the casefolded whitespace tokens of the query and the document. Sort by score descending, then index ascending, and apply `top_n`.
- Create `tests/providers/test_fake_provider.py`:
  - `asyncio.run` drives the async calls. Do not add pytest-asyncio.
  - Two instances give identical outputs and `Usage`.
  - Embeddings are equal in a subprocess run with a different `PYTHONHASHSEED`. Pin the first 3 floats of one English and one Arabic text as golden values.
  - Vectors have length `dim` and unit norm within `1e-9`. Document and query vectors differ.
  - Stream concatenation equals `complete` text, and only the last chunk has usage.
  - `tools` or `response_schema` raise `MissingCapabilityError`. A profile with `streaming=False` refuses `stream`.
  - Rerank ordering covers tie-breaks and `top_n`.
  - The usage fields match the profile, the default latency is `1.0`, and the cost is `Decimal("0")`.
