## Change
- `bundle.py` `write_bundle_dir(files, root)`: `root` must not exist (else `BundleError("target_exists")`; this replaces "absent or empty"). Write into `tempfile.mkdtemp(dir=root.parent, prefix=f".{root.name}.tmp-")`. Self-check with `import_bundle(read_bundle_dir(tmp))`, then `os.replace(tmp, root)`. On any exception, `shutil.rmtree(tmp, ignore_errors=True)` and re-raise. Docstring: the exists check and the replace are not atomic together (check-then-act race). On POSIX, `os.replace` onto a directory that appeared meanwhile can fail or behave differently. The CLI is single-user dev only.
- `bundle.py` add `BundleAnchorCollector(store, uow, anchors: AnchorService, *, limits=DEFAULT_LIMITS, max_chunks=10_000)` with `async anchors_for_views(scope, view_ids, index_version_id=None) -> tuple[SourceAnchor, ...]`:
  - Every view goes through `uow.extractions.get_view(scope, id)` first (other scope -> `NotFoundError`). Then one block anchor per payload block (`anchors.anchor(scope, view, block_id, start, end)`).
  - With an index: `get_index_version(scope, id)`. State must be READY, else `BundleError("index_not_ready")`. Its `extraction_view_ids` must all be in `view_ids`, else `BundleError("index_views_not_exported")`. Page `list_chunks(limit=500)`. More than `max_chunks` -> `BundleError("too_large")`. Per chunk: `anchors_for_span(start, end)`, plus `anchors_for_span(parent_start_cp, parent_end_cp)` when the pair is set.
  - Dedupe by `anchor_id`. Same id with different canonical JSON -> `BundleError("anchor_collision")`. Over `limits.max_anchors` -> `BundleError("too_large")`. Return in a deterministic order (sorted by view id, start, end, anchor_id).
- Create `apps/worker/src/rag_foundry_worker/bundle_cli.py`, script `rag-foundry-bundle = "rag_foundry_worker.bundle_cli:main"` in `apps/worker/pyproject.toml`:
  - `export --views ID [ID ...] [--index ID] --out DIR` runs the collector, then export, then `write_bundle_dir`.
  - `verify DIR` runs `read_bundle_dir` and `import_bundle`.
  - Scope args and wiring as in `index_cli.py`. Refuse when `settings.environment == "prod"`.
  - Output: safe summary lines only (`bundle_id`, file count, total bytes, anchor count, view count). On failure: `error: <BundleError.code>` with a non-zero exit. Never print tenant/project ids, paths of the object store, or env values.
- `uv lock` only if the script entry changes the lock. It must not add any dependency.
