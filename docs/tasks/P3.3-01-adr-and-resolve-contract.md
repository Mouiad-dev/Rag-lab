## Change
- `docs/decisions/ADR-0011-source-anchors-and-resolution.md` (status accepted only once the owner has confirmed): copy D1-D12 as decided by the owner (planner defaults: computed-only anchors, no table; deterministic `anchor_id` (scheme `anchor-id-v1`); exact always set, prefix/suffix up to 32 code points block-relative; no new hash field; contract stays 1.0; PDF regions deferred, page_index from block; statuses exact/mismatch/unavailable; batch 100 anchors / 10 views / 1 MiB; module in ingestion; `provider_namespace` setting; structure route deferred; one anchor per block). Add the row to `docs/decisions/README.md`.
- `rag_foundry_contracts/resolve.py`:
  - `ResolutionStatus` StrEnum: `exact`, `mismatch`, `unavailable`.
  - `ResolutionReason` StrEnum: `foreign_namespace`, `not_found`, `source_mismatch`, `unsupported_precision`, `block_not_found`, `range_out_of_bounds`, `quote_mismatch`, `prefix_mismatch`, `suffix_mismatch`, `page_mismatch`, `integrity_error`.
  - `AnchorResolution(_Model)`: `contract_version`, `anchor_id` (1-256 chars), `status`, `reason: ResolutionReason | None`, `exact: str | None`, `block_id: str | None`, `section_path: tuple[str, ...] = ()`, `page_index: int | None`. Validators: `status == exact` iff `reason is None`; `exact` and `block_id` set iff status is `exact`; when status is not `exact`, `section_path == ()` and `page_index is None`.
  - `AnchorResolveRequest`: `contract_version`, `anchors: tuple[SourceAnchor, ...]` with 1 to `MAX_RESOLVE_ANCHORS = 100` items. Model validator: reject any anchor whose `anchor_id` is longer than 256 chars (`SourceAnchor` itself does not change), so an over-long ID is a 422 at the request, never a 500 when building `AnchorResolution`.
  - `AnchorResolveResponse`: `contract_version`, `results: tuple[AnchorResolution, ...]` (same order as the request).
  - All use `check_contract_version` (1.x accepted, other majors rejected).
- `export.py`: add `anchor-resolve-request.v1.json` and `anchor-resolve-response.v1.json`; regenerate into `packages/contracts/schemas/`.
- `packages/contracts/fixtures/resolve/request.json` and `response.json`: one en and one ar anchor from `fixtures/sources/anchors.json`, one exact and one `quote_mismatch` result.
- `tests/contracts/test_resolve.py`: fixtures validate; schema drift test for both new files; 0 and 101 anchors rejected; major 2 rejected; each broken status/reason/exact/block_id/section_path/page_index combination rejected; empty and 257-char `anchor_id` rejected (in `AnchorResolution`, and a 257-char `anchor_id` rejected by `AnchorResolveRequest`); unknown field rejected.
