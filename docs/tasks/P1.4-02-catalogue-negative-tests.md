## Goal
A pytest module runs `scripts/verify_package.py` against a temporary copy of the repository. The unmodified copy passes (exit 0); each deliberately broken catalogue variant fails (exit 1) with the expected message. Because pytest runs in `tasks.py check`, CI fails if the catalogue validator stops catching these, without needing a broken commit.

## Read only these files
- `scripts/verify_package.py` (`ROOT` is derived from the script's own path; `check_catalogue` messages; `SKIP_DIRS`)
- `config/techniques.json` (entry shape, `allowed_statuses`, `allowed_catalog_statuses`)
- `tests/stack/test_compose_config.py` (house style for subprocess tests)
- `pyproject.toml` (pytest `--import-mode=importlib`; ruff config)

## Change
- Create `tests/repo/test_catalogue_validation.py`:
  - Module/session fixture: `shutil.copytree(ROOT, tmp)` with an ignore for `.git`, `.venv`, `node_modules`, `private`, `__pycache__`, `.ruff_cache`, `.pytest_cache`, `.env` (never copy the local secret file). Running `tmp/scripts/verify_package.py` then validates the copy, since `ROOT` resolves from the script path. Do not modify `verify_package.py`.
  - Per test: rewrite `tmp/config/techniques.json` (or `tmp/docs/techniques/TECHNIQUE_CATALOG.md`) and restore the original afterwards (fixture with `yield`), so cases are independent.
  - Run with `subprocess.run([sys.executable, str(script)], cwd=tmp, capture_output=True, text=True, timeout=120, check=False)`.
  - `test_unmodified_copy_passes`: exit 0, stdout contains `72 catalogue entries`.
  - Parametrized broken cases, each asserting exit 1 and a substring of stderr:
    - status `"done-ish"` on one entry → `Invalid status`
    - `catalog_status: "proposed"` → `Proposed entries belong in the app database`
    - delete entry `C05` → `include the committed 72-entry curriculum`
    - duplicate an entry's `id` → same message as above
    - `roadmap_step: "P99.9"` → `Unknown roadmap_step`
    - `phase` not matching `roadmap_step` → `phase does not match roadmap_step`
    - `primary_source: "http://example.com"` → `primary_source must be null or an https URL`
    - `date_added: "2026/01/01"` → `date_added must be YYYY-MM-DD`
    - remove that entry's row from the copied `TECHNIQUE_CATALOG.md` → `Missing or out-of-sync catalogue row`
    - invalid JSON in `techniques.json` → `Invalid JSON: config`
- No `__init__.py` needed (importlib mode); match existing `tests/*` layout.

## Constraints
- Never write to the real `config/` or `docs/`; only under `tmp_path_factory`.
- Pick the mutated entry by ID (e.g. `C05`, `R10`), not by list index.
- Must pass on Windows and Linux (use `pathlib`, `sys.executable`, UTF-8 reads/writes).
