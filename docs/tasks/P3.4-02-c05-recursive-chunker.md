## Goal
A pure, deterministic C05 plugin turns canonical text into code-point spans `(start, end, split_level)` per ADR-0012 D2-D4, registers in `TechniqueRegistry` under `C05`, and shows separator fallback on an oversized paragraph. No I/O.

## Change
- `packages/techniques/src/rag_foundry_techniques/kinds.py` (+ re-export in `__init__`): frozen `extra="forbid"` pydantic models `TextBlock(block_id: str, start: int>=0, end: int>start)`, `ChunkInput(text: str min 1, blocks: tuple[TextBlock, ...] = ())` (validator: blocks ascending, non-overlapping, `end <= len(text)`), `ChunkSpan(start: int>=0, end: int>start, split_level: int 0..63)`; `Chunker` Protocol: `manifest: ClassVar[PluginManifest]`, `config: BaseModel` (the validated config, kept as an attribute; 05 serializes it), `__init__(self, config)`, `chunk(self, doc: ChunkInput) -> tuple[ChunkSpan, ...]`.
- New member `packages/chunking` (`rag-foundry-chunking`, deps: `rag-foundry-techniques` only), `rag_foundry_chunking/recursive.py`:
  - `RecursiveConfig` (frozen, `extra="forbid"`): `chunk_size=800` (32..8000), `chunk_overlap=100` (0..chunk_size//4), `separators: tuple[str, ...]` = ADR D3 default (`\u` escapes); validator: non-empty, unique, last item `""`.
  - `RecursiveChunker`: manifest `C05`, `PluginKind.CHUNKER`, `1.0.0`, `Fidelity.ADAPTATION`, `config_model=RecursiveConfig`; stores `self.config`.
  - Algorithm on `doc.text` (C05 ignores blocks): split a range by `separators[level]`, cutting right after each occurrence; pieces longer than `chunk_size` recurse with `level+1`; the `""` level cuts at `chunk_size`, moved left while the cut would sit before a combining mark (`unicodedata.combining(ch) != 0`), U+200D, U+FE0E, U+FE0F, or between `\r` and `\n` (no safe point: cut at `chunk_size`). Greedily merge consecutive pieces while length <= `chunk_size`. Overlap: next chunk starts at the earliest trailing piece of the previous chunk with `prev_end - piece_start <= chunk_overlap` and `piece_start > prev_start`, else no overlap. Trim edge whitespace (`str.isspace`) by moving `start`/`end`; drop empty chunks. `split_level` = highest piece level in the chunk. Output sorted by `(start, end)`, no duplicates.
  - `rag_foundry_chunking/__init__.py`: `register_builtin_plugins(registry)` registers `RecursiveChunker`.
- Root `pyproject.toml`: member, source and dev-group entry. `Dockerfile`: copy `packages/chunking/pyproject.toml`. `uv lock` (only the new workspace edge changes). If `uv lock` fails in the Codex sandbox (no network), leave it and note it in Result; the orchestrator runs it.
- `tests/chunking/test_recursive.py` (text via escapes): each span `text[start:end]` has no edge whitespace and length <= chunk_size; every non-whitespace code point covered; overlap per adjacent pair <= chunk_overlap; same output on repeat; `register_builtin_plugins` then `validate_config("C05", {})` equals defaults, unknown key rejected; config rejects overlap > size//4, separators not ending in `""`, duplicates; a 2000-code-point paragraph of English sentences without newlines gives some `split_level >= 2` and all sizes <= 800; a 3000-code-point run of `بَ` is never cut before `َ`; a repeated ZWJ emoji sequence (`\U0001f469‍\U0001f4bb `) is never cut before `‍`; Arabic text splits after `؟` and `،` at the expected levels (small chunk_size); whitespace-only text gives `()`.
