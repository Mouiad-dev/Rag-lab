## Goal
The framework-neutral async ports `ChatModel`, `EmbeddingModel` and `Reranker` exist with their request and result types. Every result carries a non-optional `Usage`. A static test fails if any workspace code outside `rag_foundry_providers/adapters/` imports a vendor SDK, or if the providers package imports LangChain.

## Change
- Create `src/rag_foundry_providers/messages.py`. All models are pydantic, frozen and `extra="forbid"`.
  - `ChatMessage(role: Literal["system","user","assistant","tool"], content: str)`
  - `ToolSpec(name, description, parameters_schema: dict)`
  - `ToolCall(id, name, arguments: dict)`
  - `ChatRequest(messages: tuple[ChatMessage, ...]` with at least 1 item, `max_output_tokens: int | None`, `temperature: float | None`, `tools: tuple[ToolSpec, ...] = ()`, `response_schema: dict | None = None)`
  - `ChatResult(text, tool_calls=(), structured: dict | None, finish_reason: Literal["stop","length","tool_calls"], usage: Usage)`
  - `ChatChunk(delta: str, usage: Usage | None = None)`
  - `EmbeddingResult(vectors: tuple[tuple[float, ...], ...], usage)`. A validator requires all vectors to have equal length.
  - `RerankItem(index: int >= 0, score: float)`
  - `RerankResult(items: tuple[RerankItem, ...], usage)`
- Create `src/rag_foundry_providers/ports.py`. Each port is a `typing.Protocol` with `runtime_checkable`, and each has `profile: ModelProfile`.
  - `ChatModel`: `async complete(request) -> ChatResult`; `stream(request) -> AsyncIterator[ChatChunk]`.
  - `EmbeddingModel`: `async embed(texts: Sequence[str], *, input_type: Literal["document","query"] = "document") -> EmbeddingResult`.
  - `Reranker`: `async rerank(query, documents: Sequence[str], *, top_n: int | None = None) -> RerankResult`.
  - The docstrings state the contract:
    - Streaming yields exactly one chunk with `usage`, and it is the last chunk.
    - Empty `texts` returns empty vectors with zero tokens.
    - Rerank items are unique input indices, sorted by score descending with ties broken by index ascending, and capped by `top_n`.
    - Retries and timeouts belong to adapters (P2.5).
  - `check_chat_request(profile, request, *, streaming: bool) -> None` raises `MissingCapabilityError` (stage `None`) when the request needs a capability whose `declared()` is not `True`. Non-empty `tools` needs `tool_calling`, `response_schema` needs `structured_output`, and `streaming` needs `streaming`. Report all missing capabilities at once.
- Edit `__init__.py` to export the public names from 01 and 02.
- Create `tests/providers/test_ports.py`:
  - The `check_chat_request` cases cover each single missing capability, all three missing at once, `declared=False` versus `None`, and the pass case.
  - Each message validator rejects bad input.
  - A minimal in-test stub class satisfies `isinstance(stub, ChatModel)`.
- Create `tests/repo/test_no_vendor_sdk.py` (stdlib only, AST-based, same structure as `test_independence.py`):
  - Forbidden top-level modules: `anthropic`, `openai`, `litellm`, `ollama`, `cohere`, `mistralai`, `voyageai`, `google.genai`, `google.generativeai`.
  - These are forbidden in all `packages/` and `apps/` sources except under `packages/providers/src/rag_foundry_providers/adapters/` (which does not exist yet).
  - `langchain*` is forbidden anywhere in `packages/providers`.
  - No `pyproject.toml` other than `packages/providers/pyproject.toml` lists a forbidden distribution.
  - Add negative self-tests for the detector, including `from google import genai`.

## Constraints
