## Goal
A C19 plugin splits a document into regions, classifies each region with explicit, inspectable rules (prose, mixed-script, list, table-like, code-like), routes each region to a named segmentation policy (an existing chunker plugin), and returns spans with exact source offsets plus a decision report. A comparison helper shows policy decisions and failures against one fixed policy. The router is rule-based; a model router is not implemented in this step (stated in the lesson and catalogue note).

## Change
- Create `packages/chunking/src/rag_foundry_chunking/adaptive.py`:
  - `RegionKind = Literal["prose", "mixed_script", "list", "table", "code"]`; `PolicyId = Literal["C02", "C05", "C06", "C07", "C21"]`.
  - `AdaptiveConfig` (frozen, forbid): `chunk_size: int = 800` (32..8000); `use_blocks: bool = True`; `policies: dict[RegionKind, PolicyId]` default `{"prose": "C06", "mixed_script": "C21", "list": "C07", "table": "C07", "code": "C05"}` (validator: exactly the five kinds); `fallback_policy: PolicyId = "C05"`; `mixed_min_share: float = 0.2` (0..0.5); `router: Literal["rules"] = "rules"`.
  - Policy construction: each policy id maps to its chunker class and a config built from `chunk_size` only (C02: `words_per_chunk = max(1, chunk_size // 6)`; C05: `chunk_overlap=0`; others default plus `chunk_size`). Document the mapping in the module docstring.
  - Regions: `paragraph_ranges(doc, use_blocks)`; then merge consecutive regions of the same kind (merge is in order and never crosses a region of another kind).
  - `classify(text, start, end, mixed_min_share) -> tuple[RegionKind, dict[str, float | int], str]` (kind, features, a short reason string). Features: `lines`, `chars`, `list_line_share` (lines starting, after spaces, with `-`, `*`, `•`, `\d+[.)]` or Arabic-Indic digits then `.`/`)`), `table_line_share` (lines with >= 2 `|` or >= 2 tabs), `code_line_share` (lines indented >= 4 spaces or a tab, or ending with `{`, `}`, `;`, or starting with ```` ``` ````), `arabic_share`, `latin_share` (letters by `script_of`, over all letters). Rules in this order: table if `table_line_share >= 0.5` and `lines >= 2`; code if `code_line_share >= 0.5`; list if `list_line_share >= 0.5`; mixed_script if both shares >= `mixed_min_share`; else prose.
  - `class RegionDecision(BaseModel)` (frozen, forbid): `start`, `end`, `kind`, `policy`, `reason`, `features: dict[str, float | int]`, `failed: bool = False`, `error: str | None = None`, `chunk_count: int`.
  - `AdaptiveChunker`: manifest `C19`, `PluginKind.CHUNKER`, `"1.0.0"`, `Fidelity.ADAPTATION`, `config_model=AdaptiveConfig`. `segment(doc) -> tuple[tuple[ChunkSpan, ...], tuple[RegionDecision, ...]]`: for each region run the routed policy on `ChunkInput(text=doc.text[start:end], blocks=<doc blocks inside the region, shifted>)` and shift spans back by `start`. If the policy raises, or returns a span outside the region, record `failed=True` with the exception class name and message (truncated to 200) and use `fallback_policy` for that region (if the fallback also fails, raise). `chunk(doc)` returns only the spans, sorted by `(start, end)`. Spans never cross a region boundary.
  - `class PolicyComparison(BaseModel)`: `adaptive_chunks: int`, `fixed_chunks: int`, `fixed_policy: PolicyId`, `fixed_cross_region: int` (fixed-policy spans that cross a region boundary), `regions: tuple[RegionDecision, ...]`, `failures: int`, `oversized_adaptive: int`, `oversized_fixed: int` (spans longer than `chunk_size`).
  - `compare_with_fixed(doc, config, fixed_policy: PolicyId = "C05") -> PolicyComparison`.
- Edit `packages/chunking/src/rag_foundry_chunking/__init__.py`: register `AdaptiveChunker`; export `AdaptiveChunker`, `AdaptiveConfig`, `RegionDecision`, `PolicyComparison`, `compare_with_fixed`. Add lines only.
- Create `tests/chunking/test_adaptive.py` (non-ASCII as escapes):
  - A document with an English prose paragraph, a bullet list, a pipe table, an indented code block, and an Arabic + English mixed paragraph (blank-line separated): each region gets the expected kind and policy; spans slice the source exactly, never cross region boundaries, have no edge whitespace and are within `chunk_size`.
  - Each classification rule has a positive and a near-miss negative case (e.g. one pipe per line is not a table; 1 of 3 list lines is not a list); Arabic-Indic numbered list detected.
  - With blocks: regions follow the blocks when `use_blocks=True`.
  - Policy failure: monkeypatch one policy class's `chunk` to raise; the region is `failed=True`, the fallback spans are used, other regions are unaffected; a policy returning an out-of-region span is also caught.
  - Config: custom `policies` mapping used; missing kind or unknown policy rejected; `router` other than `rules` rejected.
  - `compare_with_fixed`: on the mixed fixture with a small `chunk_size`, the fixed C05 policy has `fixed_cross_region > 0` and the adaptive one has none (adaptive spans never cross by construction); counts consistent.
  - Deterministic on repeat; registry `validate_config("C19", {}) == AdaptiveConfig()`.
