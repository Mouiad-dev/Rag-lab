## Change
- Create `packages/cache/src/rag_foundry_cache/keys.py`:
  - `GenerationParams` (frozen, extra forbidden, all required): `max_output_tokens: int`, `temperature: float | None`, `k: int`, `min_score: float | None`, `max_evidence_chars: int`, `packer: str` (`"none"` or a config SHA), `citation_check: Literal["off","warn"]`.
  - `ResponseKeyInputs` (frozen, extra forbidden, no defaults; strings non-blank unless optional): `authz_revision`, `history: tuple[tuple[Literal["user","assistant"], str], ...]`, `technique_id`, `technique_version`, `retriever_config_sha256`, `index_version_id | None`, `embedding_key | None`, `prompt_template`, `prompt_sha256`, `chat_profile_id`, `chat_provider`, `chat_model`, `generation: GenerationParams`, `settings_sha256 | None`, `mode: Literal["source_only","enriched"]`, `freshness: Literal["static_snapshot","current"]`, `tools: tuple[str, ...]`, `is_action_run: bool`, `output_language: Literal["en","ar","auto"]`, `contract_version`.
  - `exact_key(scope, question, inputs)` and `partition_key(scope, inputs)`: SHA-256 hex of canonical JSON (sorted keys, no NaN; NFC on strings only; no case folding, whitespace or punctuation changes). `partition_key` excludes only the question. Blank question -> `CacheError("cache_key_invalid")`.
  - `source_version_ids(response) -> tuple[str, ...]`: sorted unique `anchor.source.document_version_id` over all citation and evidence anchors.
- Create `packages/domain/src/rag_foundry_domain/response_cache.py`:
  - `CacheEntry` (frozen): `key`, `partition` (64 hex), `tenant_id`, `project_id`, `response_json` (1..200000 chars; the cache package parses it as `RunResponse`), `source_run_id`, `source_version_ids` (1..200), `created_at`, `expires_at` (> created_at), `features_json: str | None` (R51 guarded features, never the question), `question_vector: tuple[float, ...] | None`, `vector_key: str | None` (vector and key both set or both None). No question text field.
  - `ResponseCacheStore` Protocol: `get(scope, key)`, `put(scope, entry)` (existing key -> `CacheError("cache_exists")`; entries are never updated), `delete(scope, key) -> bool`, `similar(scope, partition, vector_key, vector, k) -> list[tuple[CacheEntry, float]]` (cosine, descending), `invalidate_sources(scope, version_ids) -> int`, `invalidate_partition(scope, partition) -> int`, `purge_expired(scope, now) -> int`.
  - `InMemoryResponseCacheStore`: keyed by `(tenant, project, key)`; per-scope reverse index `version_id -> keys`. `get` returns `None` when absent; a stored entry whose scope differs from the caller's raises `CacheError("cache_scope_mismatch")`; `put` with a scope different from the entry's raises the same; `similar` searches only the caller's scope, partition and vector_key; expiry is not enforced by `get` (the caller revalidates).
  - `RESPONSE_CACHE_STORE_CHECKS`: tuple of async check functions taking a store factory (pattern of `KG_STORE_CHECKS`): round trip; other scope gets `None`; `cache_exists` on a second put; delete; reverse-index invalidation only in its scope; partition invalidation; `similar` isolation by scope, partition and vector_key, ordering, `k`; `purge_expired`.
- Tests: `tests/domain/test_response_cache_store.py` runs `RESPONSE_CACHE_STORE_CHECKS` on the in-memory store plus a forced-collision case; `tests/cache/test_keys.py`: every input field (parametrized, including each `GenerationParams` field, one history turn, `authz_revision`) changes the exact key; partition ignores only the question; Arabic questions differing only in diacritics give different keys; the question never appears in a key or error; `source_version_ids` uses `document_version_id`.
