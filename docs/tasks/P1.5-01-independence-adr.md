## Change
- Create `docs/decisions/ADR-0008-independent-product-and-consumers.md` from the template. Date 2026-11-01. Status: `accepted (records the 2026-10-26 decision in REUSE_AND_INTEGRATION.md §1)`. Decision points, one line each:
  1. RAG Foundry builds, starts and tests with no consumer checkout, config, service or credential.
  2. No imports of consumer code, no shared DB/migrations, no sibling-path dependencies.
  3. Integration only through versioned framework-neutral JSON contracts (`packages/contracts`, P1.5-02), HTTP `/api/v1` and portable source bundles; consumers own their adapter.
  4. No consumer-specific fields (course, lesson, video, TTS, timing) in core entities or public contracts.
  5. Source anchors are owned by immutable document/extraction versions, not chunk/index IDs.
  Consequences: a static test guards 1–2 now; REUSE §7 gates stay planned (not run). Link REUSE_AND_INTEGRATION.md and SOURCE_ANCHORS_AND_MEDIA.md.
- Edit `docs/decisions/README.md`: add the ADR-0008 row (status `accepted`).
- Edit `docs/architecture/SUMMARY.md`: add one Key decisions row `Independence | ... | [ADR-0008](...)`.
- Create `tests/repo/test_independence.py` (stdlib only, read files as UTF-8):
  - Root `pyproject.toml`, every `packages/*/pyproject.toml`, `apps/*/pyproject.toml` and `uv.lock` contain no `book2video` (case-insensitive).
