## Goal
A new workspace package `rag-foundry-contracts` (`rag_foundry_contracts`) holds framework-neutral pydantic models for source references and anchors, contract version `1.0`. Their JSON Schema is committed and a test fails if it drifts. Contracts depend only on pydantic.

## Change
- Create `packages/contracts/pyproject.toml` (name `rag-foundry-contracts`, version `0.0.0`, deps `pydantic>=2.14.2` only) and `packages/contracts/README.md` (purpose, no ORM/Lang/UI deps, v1 rules).
- Create `src/rag_foundry_contracts/__init__.py` exporting the public names, and `source.py`. All models: `ConfigDict(frozen=True, extra="forbid")`.
  - `CONTRACT_VERSION = "1.0"`; `UnsupportedContractVersionError(ValueError)`; `check_contract_version(v: str)` accepts `1.x`, raises for other majors or malformed strings.
  - `SourceRef`: `provider_namespace`, `document_id`, `document_version_id`, `extraction_view_id` (non-empty str).
  - `TextRange`: `start: int >= 0`, `end: int`; validator `end >= start`. Docstring: zero-based half-open Unicode code points in canonical block text, not UTF-8 bytes or UTF-16 units.
  - `PageRegion`: `page_index >= 0`, `x0,y0,x1,y1` floats in [0,1], top-left origin, `x0 <= x1`, `y0 <= y1`.
  - `Precision` (StrEnum): `exact_text`, `exact_region`, `approximate_region`, `page_only`, `unavailable`.
  - `SourceAnchor`: `contract_version` (validated by `check_contract_version`), `anchor_id`, `source: SourceRef`, `block_id`, `section_path: tuple[str, ...] = ()`, `text_range: TextRange | None`, `exact/prefix/suffix: str | None`, `page_index: int | None` (>= 0), `page_label: str | None`, `regions: tuple[PageRegion, ...] = ()`, `precision: Precision`, `warnings: tuple[str, ...] = ()`. Validator: `exact` requires `text_range`, and `len(exact) == end - start`.
  - `export.py`: `schemas() -> dict[str, dict]` returning `{"source-anchor.v1.json": SourceAnchor.model_json_schema()}`; `python -m rag_foundry_contracts.export <dir>` writes them (sorted keys, indent 2, trailing newline, UTF-8, LF).
- Generate and commit `packages/contracts/schemas/source-anchor.v1.json`.
- Edit root `pyproject.toml`: add member, workspace source and dev-group entry. Run `uv lock`.
- Edit `Dockerfile`: add `COPY packages/contracts/pyproject.toml packages/contracts/pyproject.toml` in the dependency layer.
- Create `tests/contracts/test_source_anchor.py`: valid anchor round-trips (`model_dump_json` → `model_validate_json`); rejects `end < start`, negative start, region coords outside [0,1], `exact` length mismatch, unknown field, version `2.0` (`UnsupportedContractVersionError`); committed schema equals `schemas()` output; recursive key scan of the schema finds none of `chunk_id`, `index_id`, `course`, `lesson`, `video`, `tts`, `start_ms`.
- Add to `tests/stack/test_dockerfile.py`: every workspace member in root `pyproject.toml` has a matching `COPY <member>/pyproject.toml` line (use `tomllib`).
