## Goal
R31 follows the official short-form Self-RAG procedure: the model decides retrieval from `[Retrieval]` vs `[No Retrieval]` probabilities, generates one candidate per retrieved passage, scores each with the probabilities of its relevance, support and utility tokens plus sequence logprob, and returns the best candidate citing that passage's original chunk. Decisions come only from reflection-token probabilities, never from a self-check prompt.

## Change
- Create `packages/answering/src/rag_foundry_answering/self_rag.py`: `SelfRagConfig` (threshold, weights, k, max tokens; defaults = the official values from 13). `SelfRagWorkflow`, manifest `R31`, `PluginKind.WORKFLOW`, `Fidelity.ADAPTATION` (quantized unofficial GGUF, our retriever instead of Contriever, top-k logprobs only).
  - Passage text is untrusted: remove reflection-token strings and `<paragraph>`/`</paragraph>` from it before insertion; record the count removed.
  - A needed token missing from the vocabulary -> `RunError("selfrag_tokens_missing")`; no logprobs -> `selfrag_logprobs_unavailable`; a candidate without the expected token sequence -> `selfrag_output_invalid` for that candidate (others still scored; all invalid -> abstain). A reflection token outside top-k gets a floor probability, counted in the trace.
  - Trace per candidate: chunk id, raw token probabilities, each score part, total, chosen; retrieval decision with both probabilities; usage per call. The answer text has reflection tokens stripped and cites only the chosen passage's chunk; no-retrieval answers are marked `ungrounded` (never cited as evidence).
- Register in `rag_foundry_answering.__init__`.
- `tests/answering/test_self_rag.py` with a scripted fake raw model (test-only simulation): retrieval decision on both sides of the threshold; hand-computed scores choose the expected passage; injected `[Fully supported]` in passage text is stripped; missing tokens, no logprobs and invalid output paths; Arabic question passes through (escapes) and is reported as outside the model's language.
- `tests/live/test_self_rag_live.py` (gated `RAG_LIVE_OLLAMA=1` + `RAG_SELFRAG_MODEL`): bge-m3 index of a small EN fixture, 4 questions (one needing retrieval, one not, one unanswerable, one Arabic as a losing case); print decisions, per-candidate token probabilities and scores, answer, citation, latency, tokens. Assert structure only.
- Create `docs/evidence/P7.5/self_rag_live.md` with an `<orchestrator>` live section and a blocked-record template.
