## Goal
`PrefixCacheProbe` (R49, `cache` plugin) runs a fixed experiment against any `ChatModel` through the port and records, per call, provider cached-token counts, phase timings, total time and (stream mode) TTFT. `cache_metric` is `reported` when the provider returns a cached-token count, otherwise `unavailable`; timings never become a hit claim.

## Change
- Create `packages/cache/src/rag_foundry_cache/prefix.py`:
  - `PrefixProbeConfig(prefix_text: 1..200000 chars, questions: 2..10 non-blank, max_output_tokens: 1..512 = 64, temperature: float = 0.0, mode: Literal["complete","stream"] = "complete", arms: tuple of arm names = all four, in order)`; extra forbidden. Plugin class with a class-level `manifest`: `R49`, kind `cache`, version 1.0.0, fidelity `adaptation`, `config_model=PrefixProbeConfig`.
  - `async run(chat, *, clock, salt_factory) -> PrefixProbeReport`. Arms in this order (skipping arms not in `config.arms`); system = prefix (plus a salt line where stated), user = question:
    1. `cold`: a fresh salt line in front of the prefix on every call; one call per question.
    2. `warm`: identical prefix; first call labelled `prime` (question 1), then one call per question.
    3. `changed`: prefix with its first character replaced; question 1.
    4. `eviction_attempt`: a different prefix B of the same length (one call), then the original prefix (one call). It is an attempt: whether B evicts A depends on the runtime (slots, keep-alive) and is only observable through reported cached counts.
  - Mode `complete`: `chat.complete`, `ttft_ms=None`. Mode `stream`: TTFT = clock at the first non-empty delta minus start; usage from the final chunk (fields may be missing).
  - Per call record: arm, label, ttft_ms, total_ms (wall clock), input/output tokens, cache read/write tokens, `cache_read_reported` (from `Usage`, added in P7.4-02), `timings` (or None), token_source, prefix SHA-256. No prompt or question text.
  - Report: records; `cache_metric = "reported"` if any call has `cache_read_reported` true or cache read or write tokens > 0 (so Anthropic and OpenAI-compatible usage counts as reported without adapter changes), else `"unavailable"` (absent counts are unavailable, never "0 hits"); per-arm medians of ttft, prefill, decode and cache-read tokens (`None` if any value in that arm is missing; the cache-read median is `None` when any call in the arm has `cache_read_reported` false and 0 cache-read tokens); fixed `note`: "timings are a proxy; a lower warm prefill alone does not prove a cache hit".
  - Invalid config -> `CacheError("prefix_probe_invalid")` before any call. Provider errors re-raised unchanged.
- `__init__.py`: export the probe and `register_builtin_plugins(registry)` (R49). Register the cache package in `test_builtin_kinds.py` (51 -> 52), `test_contract_kit.py` `_builtins()` and `new_technique.py` `_builtin_ids()`.
- Create `tests/cache/test_prefix_probe.py` (local fake chat for complete and stream, fake clock): arm order and counts (2 questions: cold 2, warm 3, changed 1, eviction_attempt 2 = 8); `arms` subset honoured; cold prefixes all differ, warm byte-identical; stream TTFT at the first non-empty delta; complete-mode TTFT None; fake reporting cache-read tokens -> `reported`; fake reporting `cache_read_reported=True` with 0 tokens on every call -> `reported` with a cache-read median of 0; fake without the flag and 0 tokens -> `unavailable` and cache-read median `None`; missing timings -> `None` medians, never 0; no question or prefix text in `report.model_dump_json()`; invalid config raises before any call.
