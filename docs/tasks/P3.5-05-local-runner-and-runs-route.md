## Goal
One composition point, `LocalRunner.run(scope, RunRequest)`, used by the API and the CLI: validates the request, maps the technique to a retriever, builds per-run local models with ledger + budget + retry, enforces concurrency and deadline, calls `AnswerService`. The API exposes it synchronously with safe error mapping.
