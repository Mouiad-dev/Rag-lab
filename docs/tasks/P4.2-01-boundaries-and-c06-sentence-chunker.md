## Goal

## Change
- Create `packages/chunking/src/rag_foundry_chunking/boundaries.py` (pure functions, ranges are `(start, end)` code-point offsets into `text`, `end` exclusive):
  - `TERMINATORS = (".", "!", "?", "؟", "۔", "…")` and `CLOSERS = ('"', "'", ")", "]", "}", "”", "’", "»", "›")`.
  - `DEFAULT_ABBREVIATIONS`: lowercase, no trailing dot: `mr mrs ms dr prof sr jr st vs e.g i.e fig no approx dept`.
  - `trim(text, start, end) -> tuple[int, int] | None`: move inward past `str.isspace` chars; `None` if empty.
  - `sentence_ranges(text, start, end, abbreviations) -> list[tuple[int, int]]`: trimmed, ascending, non-overlapping ranges that together cover every non-whitespace code point in `[start, end)`. Rules: (1) a blank line (`\n`, then only non-newline whitespace, then `\n`) always ends a sentence; (2) a maximal run of `TERMINATORS`, then any `CLOSERS`, ends a sentence at the position after them only if that position is `end` or a whitespace char; (3) exception, only when the run is exactly one `.`: no boundary if the token before the period (maximal non-whitespace run, leading `CLOSERS`/`(`/`[`/`"`/`«` stripped, lowercased) is in `abbreviations`, or its last `.`-separated part is a single letter (`str.isalpha()` and length 1, any script: `J. Smith`, `U.S. Army`, Arabic `د. ...`), or the next non-whitespace char is lowercase (`str.islower()`). Arabic comma `،`, Arabic semicolon `؛`, `;` and `,` never end a sentence. `3.14` never splits (no whitespace after the period).
  - `word_ranges(text, start, end) -> list[tuple[int, int]]`: maximal non-whitespace runs.
  - `safe_cut_ranges(text, start, end, size) -> list[tuple[int, int]]`: cut `[start, end)` into pieces of at most `size`; each cut moves left while unsafe; if no safe point, cut at `size`. Unsafe cut position `i` (cut between `i-1` and `i`): `unicodedata.combining(text[i]) != 0`; `text[i]` in `‍ ‌ ︎ ️` or `text[i-1] == "‍"`; `text[i]` is a skin-tone modifier `\U0001f3fb`..`\U0001f3ff`; `text[i-1:i+1] == "\r\n"`; both `text[i-1]` and `text[i]` are regional indicators (`\U0001f1e6`..`\U0001f1ff`) and the count of consecutive regional indicators ending at `i-1` is odd.
  - `pack(text, units, size, overlap_units) -> list[tuple[int, int, int]]`: `units` is an ascending list of trimmed `(start, end, level)` each with `end - start <= size`. Greedy: add consecutive units while `unit_end - chunk_start <= size`. With `overlap_units > 0`, a new chunk starts with up to the last `overlap_units` units of the previous chunk, dropping the oldest of them until the chunk start is strictly after the previous chunk start and the overlap units plus the first new unit fit in `size`. Each chunk is `(first_start, last_end, max_level)`; starts and ends strictly increase.
- Create `packages/chunking/src/rag_foundry_chunking/sentence.py`:
  - `SentenceConfig` (frozen, `extra="forbid"`): `chunk_size: int = 800` (32..8000), `overlap_sentences: int = 0` (0..3), `abbreviations: tuple[str, ...] = DEFAULT_ABBREVIATIONS` (validator: each lowercase, non-empty, no whitespace, no trailing `.`, unique).
  - `SentenceChunker`: manifest `C06`, `PluginKind.CHUNKER`, `1.0.0`, `Fidelity.ADAPTATION`, `config_model=SentenceConfig`; keeps `self.config`. `chunk(doc)`: sentence ranges over `doc.text` (blocks ignored), level 0; a sentence longer than `chunk_size` becomes word units (level 1) packed without overlap, and a word longer than `chunk_size` becomes `safe_cut_ranges` units (level 2). Then `pack`. Return `tuple(ChunkSpan(...))` sorted by `(start, end)`.
- Edit `packages/chunking/src/rag_foundry_chunking/__init__.py`: import and register `SentenceChunker`; export `SentenceChunker`, `SentenceConfig`. Keep the C05 lines unchanged (another session adds C01-C04 lines here).
- Create `tests/chunking/test_boundaries.py` and `tests/chunking/test_sentence.py` (all non-ASCII as `\u` escapes):
  - English: `Dr. Smith arrived. He said "Stop." Then he left!` gives exactly 3 sentences (`Dr.` not a boundary; boundary after the closing quote).
  - `J. Smith`, `U.S. Army`, `e.g. this`, `pi is 3.14 today.` do not split inside; `Wait... What?! Yes.` gives 3 sentences.
  - Arabic: a text with `؟` and `.` ends sentences there; `،` and `؛` do not end a sentence (assert the exact ranges); a quoted Arabic sentence ending `.»` splits after `»`; Arabic `د. ` abbreviation does not split.
  - Mixed: an Arabic sentence followed by an English sentence and NFC text with harakat (for example `بَ`): ranges exact; `unicodedata.is_normalized("NFC", text)` asserted on fixtures.
  - Every `ChunkSpan`: `text[start:end]` has no edge whitespace, length `<= chunk_size`; every non-whitespace code point is covered; deterministic on repeat; with `overlap_sentences=1` some adjacent pair overlaps by exactly one whole sentence and starts/ends strictly increase.
  - A sentence longer than `chunk_size` gives `split_level` 1; a 3000-code-point word gives `split_level` 2 and no cut before `َ`, ZWJ, `️`, a skin-tone modifier, inside `\r\n`, or inside a regional-indicator pair (`\U0001f1f8\U0001f1e6` repeated).
  - Seeded property test (300 random texts over `"ab .?!\n؟،َ»"` with real characters, sizes 32/40/64, overlap 0/1/2): coverage, bounds, strictly increasing starts and ends.
  - Registry: `register_builtin_plugins` then `validate_config("C06", {}) == SentenceConfig()`; unknown key rejected; bad abbreviations rejected.
