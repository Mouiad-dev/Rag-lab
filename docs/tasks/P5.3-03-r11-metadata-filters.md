## Goal
`MetadataFilteredRetriever` (R11) wraps any retriever on one index version. It keeps only hits whose extraction view matches a structured filter on document id, document version id, media type and version creation date. Allowed views are resolved only through scope-checked repositories from the index version's own view list, so a filter can never widen scope. A filter naming another tenant's document returns no hits and never calls the inner retriever.

## Change
- Create `rag_foundry_indexing/metadata_filter.py`:
  - `MetadataFilter` (frozen, `extra="forbid"`; **no** tenant/project/scope/index fields): `document_ids`, `document_version_ids` (`tuple[Uuid4, ...] | None`, max 100), `media_types: tuple[MediaType, ...] | None`, `created_from`, `created_to: UtcDatetime | None` (from inclusive, to exclusive, compared with `DocumentVersion.created_at`). Rules: `None` means no constraint. `()` matches nothing. Fields combine with AND, values inside a field with OR.
  - `intersect(a, b | None) -> MetadataFilter`: per tuple field, None+X gives X and X+Y gives `sorted(set(X) & set(Y))`. Dates take the later `from` and the earlier `to`. If `from >= to`, nothing matches. The result is never wider than either input.
  - `ViewMetadata` (frozen): `view_id, document_id, document_version_id, display_name, media_type, version_created_at`.
  - `async resolve_views(filter, *, scope, index_version, extractions, documents) -> tuple[ViewMetadata, ...]`: for each id in `index_version.extraction_view_ids`, sequentially call `extractions.get_view(scope, id)`, `documents.get_version(scope, view.document_id, view.document_version_id)` and `documents.get_document(...)`. Keep the matches, ordered by `(version_created_at, document_id, view_id)`. `NotFoundError` propagates (an integrity fault, never skipped).
  - `MetadataFilterConfig` (frozen, forbid): `k: 1..50 = 5`, `filter: MetadataFilter = MetadataFilter()`.
  - `MetadataFilteredRetriever`: manifest `R11`, `PluginKind.RETRIEVER`, `Fidelity.ADAPTATION`, `1.0.0`. Constructor `(config, *, scope, index_version, index, extractions, documents, inner: Retriever)`.
  - `async choices() -> tuple[ViewMetadata, ...]` = `resolve_views(config.filter, ...)` after the version scope/ready check (used by R12).
  - `async retrieve(query, *, extra_filter: MetadataFilter | None = None)`:
    1. `index.get_index_version(scope, id)` (NotFoundError passes through); not READY gives `not_ready`.
    2. `effective = intersect(config.filter, extra_filter)`; `allowed = resolve_views(effective, ...)`.
    3. If `allowed` is empty, return `RetrievalResult(technique_id="R11", grounding="corpus", index_version_id=<id>, hits=())` **without** calling `inner`.
    4. `inner_result = await inner.retrieve(query)`. If its grounding is not corpus or its version differs, raise `selection_version_mismatch`.
    5. Keep the hits whose `extraction_view_id` is in `allowed`, then the first `k`. Renumber ranks and add `input_rank` (source = inner tid). `scoring=f"filter[{inner_tid}]:post:{len(allowed)}/{len(views)}views"`.
  - Docstring: this is post-filtering. Build `inner` with a large k (for example 50), or the result can hold fewer than `k` hits (the documented losing case).
- Register in `register_builtin_plugins` (the registry only needs the class). Export `MetadataFilter`, `MetadataFilterConfig`, `MetadataFilteredRetriever`, `ViewMetadata`, `intersect`, `resolve_views`.
- Create `tests/indexing/_multi_doc_index.py`: `async def multi_doc_index(embedder)`. Its `InMemoryDocumentRepository` takes a clock whose n-th call returns the 1st of month n in 2026 UTC (2026-01-01, 2026-02-01, ...). Owner documents are created first, in this order: `report-2024` (`text/markdown`), `report-2025` (`text/plain`), `notes` (`text/html`), each with one view and two chunks. The stranger scope then gets one `text/plain` document with the same texts and its own ready index. It returns a simple namespace with the scopes, repos, the owner version, the stranger version, and the document ids by tag.
- Create `tests/indexing/test_metadata_filter.py` (inner = `DenseRetriever(DenseConfig(k=50))` with `LexicalTestEmbedder`):
  - With no filter, the ids are the inner top-k. `document_ids=[report-2025]` keeps only its view. `media_types=["text/markdown"]` keeps only report-2024. `created_from=2026-02-01` excludes report-2024.
  - **Negative scope tests** (all required):
    1. `document_ids=[stranger doc id]` gives `hits == ()`, and the embedder records **no** query call.
    2. `document_ids=[owner report-2025, stranger doc]` gives only report-2025 hits, a subset of the unfiltered ids.
    3. `MetadataFilter.model_validate({"tenant_id": ...})`, `{"project_id": ...}` and `{"index_version_id": ...}` each raise `ValidationError`. `validate_config("R11", {"filter": {"tenant_id": ...}})` is rejected.
    4. The stranger scope on the owner's version gives NotFoundError. The stranger scope on its own version with `document_ids=[owner doc]` gives `()`.
    5. For every pair from a list of 5 filters, the ids under `intersect(f, g)` are a subset of the ids under `f` and under `g`.
  - Config `report-2024` plus extra `report-2025` gives `()`. `extra_filter=None` equals the config filter. An inner retriever on another version gives `selection_version_mismatch`. A building version gives `not_ready`.
