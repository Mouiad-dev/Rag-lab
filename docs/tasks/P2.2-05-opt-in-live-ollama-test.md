## Change
- Create `tests/live/test_ollama_live.py`. It sits outside `tests/providers`, so the offline guard does not apply; it talks only to the configured base URL, which is loopback by default.
  - Mark every test `@pytest.mark.live`.
  - Skip unless `RAG_LIVE_OLLAMA=1`. Do not use a `RAG_FOUNDRY_` prefix, because `load_settings()` rejects unknown `RAG_FOUNDRY_*` variables.
  - Skip with a clear reason when `GET {ollama_base_url}/api/tags` (stdlib `urllib`, 2 s timeout) fails, or when it does not list both `gemma4:e4b` and `bge-m3` (match `bge-m3` or `bge-m3:latest`).
  - Take the base URL from `load_settings().ollama_base_url`.
  - Parametrize `CHAT_CHECKS` over `OllamaChatModel(ollama_chat_profile(), api_base=...)` and `EMBEDDING_CHECKS` over `OllamaEmbeddingModel(ollama_embedding_profile(), api_base=...)`.
  - Embed one English and one Arabic text: 1024 dims, all finite, vectors differ.
  - Chat with one short English and one short Arabic prompt: non-empty text, `done_reason` mapped.
  - Print `token_source`, tokens and latency per call. Never print env vars.
  - Use generous timeouts, because the first call loads the model.
- Edit `packages/providers/README.md`: replace "Not yet" with "Local Ollama (P2.2)". Cover:
  - installing the `[ollama]` extra;
  - the default profiles (`gemma4:e4b`, `bge-m3`, zero cost rates);
  - running Ollama natively or with `docker compose --profile ollama up -d ollama`;
  - `ollama pull` with sizes from FREE_MODELS;
  - the live-test command;
  - that token counts are `estimated` when Ollama omits them;
  - that this is a direct adapter (LiteLLM re-decided at P2.3/P2.4).
- Run it once on the dev PC and fill the Result with exact outputs. The owner updates `docs/PROGRESS.md` after review.
