## Goal
R41 indexes rendered PDF pages as patch multivectors and ranks pages by MaxSim against query token vectors. Pages are indexed only when the PDF bytes match the scoped document version. A page hit becomes evidence only through original text chunks on that page; pages without text are reported, never cited. The index is bound to one tenant scope.

## Change
- Create `packages/indexing/src/rag_foundry_indexing/visual.py`:
  - `VisualPageIndex` (frozen): `tenant_id`, `project_id` from the ChunkRecords (must equal the build scope), index version id, per page the view id, document version id, page_index, patch vectors, mapped chunk ids; encoder model, dim; `stats()` with pages, patches, `estimated_bytes` (named an estimate).
  - `build_visual_index(scope, version, pdf_by_view: Mapping[view_id, bytes], index_repo, doc_repo, encoder)`: for each view load the view and its `DocumentVersion` through scoped reads; require `sha256(pdf bytes) == DocumentVersion.sha256`, else `ExtractionError("page_image_invalid")` and nothing is indexed for that view; render with `render_pdf_pages`; map each page to chunks whose blocks have that `page_index` in the same view; dim drift -> `multivector_dim_mismatch`.
  - `VisualMultivectorRetriever`: manifest `R41`, `PluginKind.RETRIEVER`, `Fidelity.ADAPTATION` (ColPali MaxSim per Faysse et al. 2024; colSmol-256M, no token pooling). Index None -> `visual_index_missing`; encoder None or dependency error -> `TechniqueUnavailableError`. `retrieve` first checks the bound scope against the index tenant/project (mismatch -> NotFound, no encoder call), then the R45 query checks. Rank pages by MaxSim; each anchored page returns its first chunk with `score_components` `page_maxsim` (`term="page:<n>"`); `scoring="r41-page-maxsim"`. `search_with_report()` also returns `unanchored_pages` (page index, score), which `retrieve()` drops.
- Register the retriever in `register_builtin_plugins`.
- Create `tests/indexing/test_visual.py` (fake page encoder, fixture PDF from P7.5-07): chart query ranks page 1 first; two queries give different page orders; page 3 only in `unanchored_pages`; hits carry chunks whose blocks are on the scored page; **sha mismatch**: one changed byte in the PDF -> `page_image_invalid`, no pages indexed; **cross-tenant query**: index built for tenant A, retriever bound to tenant B -> NotFound with zero encoder calls; another tenant's view at build -> NotFound; index for another version rejected.
