## Goal
The extractor interface plus deterministic txt and Markdown extractors that turn stored text bytes into canonical text, ordered `SourceBlock`s and an `OffsetMap` from canonical text to the decoded source.

## Change
- `rag_foundry_ingestion/extract/base.py`: `ExtractionResult(canonical_text, blocks, source_map, raw_map, source_space: Literal["decoded_text","pdf_page_text"], page_starts: tuple[int, ...] | None, warnings, extractor, extractor_version, profile_id, unicode_version)`; `Extractor` Protocol (`name`, `version`, `media_types`, sync `extract(data: bytes, *, text_encoding: str | None, limits: ExtractionLimits) -> ExtractionResult`); `ExtractionLimits(max_chars=5_000_000, max_pages=2_000)`; `EXTRACTORS` by `MediaType` (missing or not installed -> `unsupported_extractor`); helper `finish(raw, raw_map, blocks_on_raw, ...)` that applies `CANONICAL_V1`, sets `source_map = canon_to_raw.compose(raw_map)` and moves block ranges to canonical offsets (03b and 04 reuse it).
- Text types: decode with `text_encoding` (`utf-8-sig` drops the BOM; offsets start after it). `max_chars` checked on raw text (`text_too_long`); empty canonical -> `no_text_layer`.
- `extract/plain.py` (`txt`, version `1`): raw = source (identity `raw_map`); whitespace-only lines are blank; paragraphs = runs of non-blank lines; blank lines are outside blocks.
- `extract/markdown.py` (`markdown`, version `1`): raw = source, markup kept verbatim.
  - ATX heading: 0-3 spaces, 1-6 `#`, then space, tab or end of line; title = rest stripped, minus a closing `#` run preceded by a space.
  - Fence: 0-3 spaces then 3 or more backticks or tildes; ends at a line with a fence of the same character and length >= the opening, or at EOF -> `code` (fence lines included).
  - Other runs of non-blank lines -> `paragraph` (setext headings, lists and tables are paragraphs; documented limit).
  - `section_path`: a heading pops entries with level >= its own, then pushes its title (its own path includes itself); other blocks get the current path.
- Tests `tests/ingestion/test_extract_text.py`: per block, `canonical[start:end]` maps through `source_map` to a source span that re-normalizes (`CANONICAL_V1`) to the block text; CRLF; BOM; Arabic and mixed headings; ATX edge cases (`#5`, `####### x`, closing `#`s, 4-space indent, `#` alone); unclosed fence; tilde fence closed only by tildes; txt whitespace-only lines; `max_chars`; empty input; same bytes twice give equal results.

## Constraints
- No new dependency; no I/O. Escapes only: no literal invisible, bidi or combining characters in source or tests. Only `CANONICAL_V1` is applied.
