## Goal
Two fusion plugins merge `RetrievalResult` lists from one index version into one ranked list, never invent candidates, and keep every input's components visible, tagged with the source technique ID and its original rank.

## Change
- `kinds.py` `ScoreComponent`: add `source: str | None = None` (must match `^[A-Z][0-9]{2}$`) and `source_rank: int | None = Field(default=None, ge=1)`. Add `class Fusion(Protocol): def fuse(self, results: Sequence[RetrievalResult]) -> RetrievalResult: ...`; export `Fusion`.
- `errors.py`: add to `IndexingError.CODES` exactly: `fusion_too_few_branches`, `fusion_duplicate_branch`, `fusion_version_mismatch`, `fusion_invalid_ranks`, `fusion_duplicate_candidate`, `fusion_candidate_conflict`, `fusion_weights_mismatch`.
- Create `rag_foundry_indexing/fusion.py`:
  - `check_inputs(results)` (shared, runs before any scoring): fewer than 2 results -> `fusion_too_few_branches`; repeated `technique_id` -> `fusion_duplicate_branch`; any `grounding != "corpus"`, any `index_version_id is None`, or ids not all equal -> `fusion_version_mismatch`; per list, ranks must be exactly `1..n` in list order -> else `fusion_invalid_ranks`; a chunk_id twice in one list -> `fusion_duplicate_candidate`; the same chunk_id in two lists with different `(extraction_view_id, start, end, text, parent_start, parent_end)` -> `fusion_candidate_conflict`. An empty hit list is valid.
  - `RrfConfig(k: 1..50 = 5, rrf_k: int 1..1000 = 60)`. `RrfFusion` manifest `R07`, `PluginKind.FUSION`, `Fidelity.FAITHFUL`, `1.0.0`. Formula (Cormack, Clarke, Buettcher, SIGIR 2009): `score(d) = sum over lists containing d of 1/(rrf_k + rank)`, where `rank` is the input hit's own `rank` field (not recomputed from scores). A list that lacks d adds nothing and gets no component. Sum in input-list order.
  - `WeightedConfig(k: 1..50 = 5, weights: dict[str, float] = {})`, each weight >= 0 and finite, sum > 0 when non-empty. Empty means equal weights `1/n`. When non-empty, the key set must equal the input technique IDs, or -> `fusion_weights_mismatch`. `WeightedFusion` manifest `R08`, `Fidelity.ADAPTATION`. Normalization is min-max per input list over that list's returned hits: `norm = (s - min) / (max - min)`. Degenerate list (one hit, or all scores equal): every hit gets `norm = 1.0` plus a `ScoreComponent(name="normalization_degenerate", value=1.0, source=tid)`. `score(d) = sum of weight * norm` over lists containing d. Absent counts as 0, the same as the lowest listed hit (documented limit).
  - Fused hit: copy chunk fields from the first list that holds it. Set `distance=None` and keep the parent pair. Components, per source in input order: every original component with `source` and `source_rank` set, then the contribution: `rrf_contribution` (value `1/(rrf_k+rank)`) or `min_max_score` (norm) plus `weighted_contribution` (weight*norm), all tagged with source and source_rank. The `*_contribution` values sum to `score`.
  - Order: `(-round(score, 12), min source rank, chunk_id)`. Ranks are re-numbered from 1, then truncated to `k`. Result: `technique_id` = `R07`/`R08`, the common `index_version_id`, `scoring` = `rrf-k{rrf_k}` or `weighted-minmax`.
- `retrievers.py` `register_builtin_plugins`: also register `RrfFusion`, `WeightedFusion`. `__init__.py`: export the configs, plugins and `check_inputs`.
- Create `tests/indexing/test_fusion.py` with hand-built `RetrievalResult`s (ASCII only):
  - RRF by hand: A(R03)=[x,y,z], B(R02)=[y,w]. Expect order y, x, w, z; y = 1/62+1/61 (approx 0.0325225); exactly two `rrf_contribution` on y, with `source_rank` 2 (R03) and 1 (R02). Tie: A=[x,y], B=[y,x] -> x before y (chunk_id).
  - Weighted by hand: R03 scores x=8,y=4,z=2; R02 y=0.9,w=0.5; equal weights -> y 0.6667, x 0.5, then w and z both 0: w (min rank 2) before z (rank 3). Single-hit list and all-equal list -> norm 1.0 and `normalization_degenerate`.
  - Original `bm25_term` components are kept with `source="R03"`; the fused chunk_id set is a subset of the input union (never invented).
  - Each of the 7 new error codes is raised by one case, and `IndexingError(code)` constructs for each. Registry: `validate_config("R07", {}) == RrfConfig()`; an unknown key is rejected.
