## Change
- Create `packages/domain/src/rag_foundry_domain/uow.py`: `UnitOfWork` Protocol (attributes `documents`, `extractions`, `indexes`, `prompts`, `settings` typed by the existing ports; `read_only: bool`; `async commit()`, `async rollback()`, `__aenter__`, `__aexit__`), `UnitOfWorkFactory` Protocol (`__call__(self, *, read_only: bool = False) -> UnitOfWork`), and `WRITE_METHODS: Mapping[str, frozenset[str]]` per family: documents `create_document_or_get`, `add_version_or_get`; extractions `create_view_or_get`; indexes `create_index_version`, `add_chunks`, `mark_ready`, `mark_failed`; prompts `create`, `activate`; settings `append`. Docstring: one UoW per task, never shared or nested; exit without commit rolls back; in a read-only UoW `commit()` and every write method raise `RuntimeError("read-only unit of work")`; no model call or object-store I/O while a UoW is open.
- Create `packages/domain/src/rag_foundry_domain/uow_adapters.py`: `PerCall(factory, family)` using `WRITE_METHODS`: a write opens a write UoW, calls, commits; any other async method opens a read-only UoW. Unknown attribute -> `AttributeError`. Helpers `per_call_documents(factory)` ... `per_call_settings(factory)`.
- Create `packages/domain/src/rag_foundry_domain/uow_testing.py`: `InMemoryUnitOfWorkFactory(*, documents=None, extractions=None, indexes=None, prompts=None, settings=None)`; missing repos are created linked (extractions over documents, indexes over extractions). Write UoWs: serialized by an `asyncio.Lock`; on enter snapshot each repo's data (`copy.deepcopy` of instance attributes, skipping asyncio primitives, callables and references to other repositories); on rollback or exit without commit restore in place. Read-only UoWs expose each repo through a guard that raises `RuntimeError` for every name in `WRITE_METHODS`. A nested write UoW in the same task raises `RuntimeError` (no deadlock); use from another task raises `RuntimeError`. Counters: `opened`, `committed`, `rolled_back`, `open_now`.
- `errors.py`: `StoreError(IntakeError)` with codes `store_unavailable`, `commit_failed` (same pattern as `PromptError`).
- `apps/api/src/rag_foundry_api/errors.py`: `StoreError` handler: `store_unavailable` -> 503 `storage_unavailable` "storage unavailable"; other -> 500 `storage_error` "storage error"; never exception text.
- Tests `tests/domain/test_uow.py`: rollback restores each of the five repos after a write (document, view, index version, prompt activation, settings override); commit keeps them; an exception inside the block rolls back and re-raises; read-only commit raises; every write method of every family raises inside a read-only UoW and changes nothing; nested write raises (this guard is what 06b relies on for `mark_failed`); other-task use raises; `PerCall` passes every shared suite (`REPOSITORY_CHECKS`, `EXTRACTION_REPOSITORY_CHECKS`, `INDEX_REPOSITORY_CHECKS`, `PROMPT_STORE_CHECKS`, `SETTINGS_REPOSITORY_CHECKS`) over an `InMemoryUnitOfWorkFactory`, and writes commit exactly once per call. API tests for both `StoreError` codes and envelopes (existing error test file if any, else new).

## Constraints
- `rag_foundry_domain` imports no `sqlalchemy`. Existing in-memory repos and shared suites unchanged (if a suite needs concurrency the in-memory UoW cannot give, stop and report). Never await inside a generator expression.
