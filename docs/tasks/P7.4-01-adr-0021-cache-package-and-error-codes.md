## Change
- `docs/decisions/ADR-0021-cag-and-cache-layers.md`, Status: **Accepted (owner, 2026-11-22)**, at most 80 lines. Decisions:
  - Four mechanisms, four IDs, never merged: R47 CAG (`workflow` plugin, `rag_foundry_answering.cag`); R49 prefix-cache probe, R50 exact and R51 semantic response caches (`cache` plugins, `rag_foundry_cache`). Response caching is not CAG.
  - R47: bounded, versioned snapshot of all chunks of one ready index version, fixed order, explicit overflow, no silent selection. A **stable per-snapshot nonce** (owner approved 2026-11-22) keeps the prefix byte-stable. Hardening: drawn with `secrets.token_hex(8)`, redrawn if it occurs in any chunk text, `repr=False`, never logged, dumped, persisted, traced or printed; every question checked before any model call; an answer echoing the bare nonce abstains; a rebuilt snapshot draws a new one. Residual risks stated: the provider sees the nonce (e.g. Ollama debug logs), and runtime KV caches are not tenant-partitioned. The `full_context_uncached` arm uses a per-run nonce. `RunPins.k` is not meaningful for R47 (all items are sent; the trace holds the real item count).
  - R47 on Ollama relies on runtime prefix reuse, which Ollama does not document between requests; no KV save/load/truncate (paper's HF `DynamicCache` path needs torch and a model download: not done, open item).
  - R49: `cache_metric = "reported"` only when the provider returns a cached-token count (Ollama `prompt_eval_cached_count`, Anthropic `cache_read_input_tokens`), else `unavailable`. Timings are proxies, never a hit claim. Anthropic `cache_control` (5-minute TTL only) is added behind the existing extra; one paid Haiku run, hard cap USD 0.05 (owner approved 2026-11-22).
  - R50/R51 key: SHA-256 of canonical JSON of scope, authorization revision (from the caller; open item), question, history, index/corpus/pipeline/prompt/model/generation versions, mode, freshness; no plaintext in keys, traces or stored rows. Stored entries hold the response, source document version IDs and the question's guarded features, never the question text. Only `answered` responses with citations whose pins match the key inputs are stored. Every hit revalidates scope, expiry, index version, `SourceGate` revocation and anchor resolution; any failure or store error is a miss. Bypass: tools, action runs, enriched or current-information mode. R51 shares the R50 partition and relaxes only the question match.
  - Results are `CachedRun(response, trace)`; the `RunResponse` contract is unchanged until v1.2 (open item).
  - Storage (owner approved 2026-11-22): port and entry model in `rag_foundry_domain`, in-memory store, and migration `0014_response_cache` with a SQL store; rows are scoped, never updated, removed only by explicit invalidation or expiry purge; reverse index on source versions. Product source deletion does not exist yet; `SourceGate` models revocation (open item). vLLM metrics: later.
  - Headings "R47 fidelity", "R49 fidelity", "R50/R51 notes" with placeholders; P7.4-12 fills them.
