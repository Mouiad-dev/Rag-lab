## Goal
- R26 keeps only the sentences of each hit that share content terms with the question, plus the qualifier sentence (negation or condition) right after a kept sentence. Kept text is never rewritten: every output hit is an exact sub-span with `hit.text == input_hit.text[start - input_hit.start : end - input_hit.start]`, so anchors and citations still point at the source.
- Any date, number, unit or negation that compression removes is listed in `trace.lost_constraints`. Nothing is lost silently.

## Arabic word lists (write each as `\u` escapes of these code points)
There are two matching modes:
- **Unfolded:** months and units are matched on NFC+casefold text **without** alef folding, so U+0623 is kept.
- **Folded:** stopwords and condition words are compared with `lexical_tokens` output, which folds alef, so they use the bare U+0627.

Months (unfolded):
- Jan: U+064A U+0646 U+0627 U+064A U+0631
- Feb: U+0641 U+0628 U+0631 U+0627 U+064A U+0631
- Mar: U+0645 U+0627 U+0631 U+0633
- Apr: U+0623 U+0628 U+0631 U+064A U+0644
- May: U+0645 U+0627 U+064A U+0648
- Jun: U+064A U+0648 U+0646 U+064A U+0648
- Jul: U+064A U+0648 U+0644 U+064A U+0648
- Aug: U+0623 U+063A U+0633 U+0637 U+0633
- Sep: U+0633 U+0628 U+062A U+0645 U+0628 U+0631
- Oct: U+0623 U+0643 U+062A U+0648 U+0628 U+0631
- Nov: U+0646 U+0648 U+0641 U+0645 U+0628 U+0631
- Dec: U+062F U+064A U+0633 U+0645 U+0628 U+0631

Units (unfolded):
- dollar: U+062F U+0648 U+0644 U+0627 U+0631
- day: U+064A U+0648 U+0645
- days: U+0623 U+064A U+0627 U+0645
- hour: U+0633 U+0627 U+0639 U+0629
- minute: U+062F U+0642 U+064A U+0642 U+0629
- minutes: U+062F U+0642 U+0627 U+0626 U+0642
- year: U+0633 U+0646 U+0629
- km: U+0643 U+0645
- kg: U+0643 U+063A
- metre: U+0645 U+062A U+0631

Stopwords (folded):
- U+0639 U+0644 U+0649
- U+0627 U+0644 U+0649
- U+0627 U+0644 U+062A U+064A
- U+0627 U+0644 U+0630 U+064A
- U+0647 U+0630 U+0627
- U+0647 U+0630 U+0647

Condition words (folded):

## Change
- Create `evidence_constraints.py` (in `rag_foundry_indexing`). It is shared with P6.3-03.
  - `MONTHS`: english january..december plus the Arabic months above.
  - `UNITS`:
    - EN: `% kg g km m cm mm l ml usd eur percent day days hour hours minute minutes year years metre metres meter meters`;
    - AR: the Arabic units above.
  - `evidence_constraints(text) -> tuple[str, ...]`. The output is, in order and deduplicated:
    1. `hard_constraints(text)`;
    2. month words found by `_WORD_RE` on unfolded NFC+casefold text;
    3. `f"{number} {unit}"` pairs. Match on unfolded NFC+casefold text with digits folded to ASCII, using `(?<![\d.,])(\d+(?:[.,]\d+)?)\s?(UNIT)(?![^\W_])`, longest unit first.
  - `is_qualifier(text) -> bool`: true when `hard_constraints` contains `"not"` or an `_AR_NEG` word, or `lexical_tokens(text)` contains `unless`, `except`, `only`, `if` or an Arabic condition word.
  - `STOPWORDS`:
    - EN: `the and for with what which when where who how does did are was were that this from about has have into its than then there their they you your can will`;
    - AR: the stopwords above.
  - `content_terms(text) -> frozenset[str]` = `lexical_tokens(text)` with length >= 3 that are not in STOPWORDS. Never put `not` in STOPWORDS.
- Create `compression.py`, R26, `CONTEXT_BUILDER`, 1.0.0, ADAPTATION.
  - `ExtractiveCompressionConfig`: `min_overlap` 1 (1..10), `keep_qualifiers` True, `max_total_chars` 8000 (20..100000), `max_hits` 50 (1..50).
  - Models (all frozen, `extra="forbid"`):
    - `SentenceDecision(chunk_id, start, end, overlap, reason: overlap|qualifier|no_overlap|budget, constraints)`;
    - `CompressionTrace(technique_id, input_technique_id, rule="lexical-overlap-v1", question_terms (sorted), input_chars, output_chars, kept, dropped, removed_hits, lost_constraints)`;
    - `CompressedRetrieval(trace, input, result)`.
  - `ExtractiveCompressor(config).compress(question, result)`. Checks:
    - an empty question raises `empty_query`, one over 2000 chars raises `query_too_long`;
    - call `check_single_input`; catch `IndexingError` with code `selection_invalid_input` and re-raise `IndexingError("compression_invalid_input")` (as `check_rerank_input` does);
    - more hits than `max_hits`, or any `hit.end - hit.start != len(hit.text)`, raises `compression_invalid_input`. Add that code to CODES.
  - Rule (put it in the docstring):
    - Sentences come from `sentence_ranges(hit.text, 0, len(hit.text))` and are shifted by `hit.start`.
    - Keep a sentence when `|content_terms(sentence) & content_terms(question)| >= min_overlap` (reason `overlap`).
    - If `keep_qualifiers` is on, also keep the next sentence of the same hit when `is_qualifier` holds (reason `qualifier`). This is not chained.
    - Budget: walk the kept sentences in (hit rank, start) order. Contiguous kept sentences form one piece `[first.start, last.end)`. Stop at the first sentence that would push the sum of piece lengths above `max_total_chars`; it and all later kept sentences get reason `budget`.
    - A hit with no kept sentence goes to `removed_hits`.
    - `lost_constraints`: the constraints of all input hit texts that are absent from the union of the output hit constraints, in input order.
  - Output hits:
    - ranks are renumbered from 1 in (input rank, start) order; score is copied from the source hit;
    - components are the source hit's + `input_rank` (source = input technique id, `source_rank`) + `kept_sentences`;
    - `block_ids` and the parent span are copied from the source hit;
    - a piece equal to the whole hit keeps its `chunk_id`; otherwise the id is `"cmp_" + hashlib.sha256(json.dumps(["R26", chunk_id, start, end], separators=(",", ":")).encode("utf-8")).hexdigest()[:24]`;
    - the result has `technique_id="R26"`, and the input's grounding, index version and scoring.
  - `CompressingRetriever(base, compressor)`: `retrieve(q)` returns `compress(q, await base.retrieve(q)).result` and stores the full result in `.last`.
- Register R26 in `retrievers.py` and export the new names in `__init__.py`.
