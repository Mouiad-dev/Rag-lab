## Goal
A builder turns the chunks of a ready index version into a `SummaryTree` and writes it once through `SummaryTreeStore.add_summary_tree`. Leaves are the original chunks; then level by level it clusters, summarizes each cluster with one chat call and embeds the summaries, until one node is left or `max_levels` is reached. Lineage is structural and checked by the model and the store.

## Change
- Create `packages/indexing/src/rag_foundry_indexing/raptor_build.py`:
  - `R37_SUMMARY_SYSTEM_V1` + SHA-256 (untrusted-JSON wording of R23/R38). User JSON: `{"level": int, "children": [{"text"}]}` (no IDs). Reply: `{"summary": str}`.
  - `RaptorBuildConfig(extra="forbid")`: `cluster: ClusterConfig`, `max_levels` (3, 1-5), `max_leaves` (500, at most 2000), `max_summary_chars` (1200, at most 4000), `max_output_tokens`, `temperature=0.0`, `on_invalid: fail|skip`.
  - `RaptorTreeBuilder(config, *, scope, index_version, index, source, chat, embedder)`; `index` provides `SummaryTreeStore`:
    - `tree_key()` per P7.3-01 with `technique_id "R37"`, `builder_version "1"`.
    - `build() -> RaptorBuildReport(tree_key, levels, nodes, chat_calls, embed_calls, promoted: tuple[(level, leaf_spans_of_promoted)], usage_chat, usage_embed)`.
  - Order: version ready; chunk count <= `max_leaves` (else `tree_too_large`); `check_chat`; embedder key equals `index_version.embedding_key` (else `incompatible_embedding`); `get_summary_tree` finds the key -> `tree_exists`. Only then any model call. One `add_summary_tree` write at the end.
  - Leaves: one per chunk; chunk text must equal the view slice (else `tree_source_mismatch`); embed leaf texts in one batch.
  - Each level: `cluster_nodes` with `ClusterItem.key` = the node's first lineage span `(start, end)`; one `call_json` per cluster in cluster order. Empty summary, one longer than `max_summary_chars`, invalid JSON or shape is invalid:
    - `fail`: raise `raptor_summary_invalid` (usage so far stays on the builder's ledger);
    - `skip`: the cluster's members are promoted unchanged into the next level's pool and listed in `promoted`.
  - Embed all summaries of a level in one batch. Stop when the pool has 1 node, the pool did not shrink, or `max_levels` is reached.
- Export the names from `__init__.py`.

- Create `tests/indexing/test_raptor_build.py`:
  - 3 level-1 clusters equal the topics; root lineage equals all 13 leaf spans; each span quote equals the view slice; the stored tree equals the loaded tree;
  - `chat_calls == number of summary nodes`; `len(usage_embed) == embed_calls`;
  - two builds on two fresh fixture indexes give the same structure by labels;

  - wrong embedder key, not-ready version, stranger scope, too many leaves and an existing key raise before any chat call;

  - an injected instruction in a chunk stays inside the user JSON.
