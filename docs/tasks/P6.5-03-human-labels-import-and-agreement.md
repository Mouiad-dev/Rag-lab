## Goal
- A strict importer accepts **human** labels for a judge item set and a rubric version.
- `agreement()` computes the percent agreement and Cohen's kappa per annotator against the judge verdicts.
- The judge item file has 6 items with neutral ids and **no expected labels**.
- The human label file is a committed **placeholder with zero labels**, so the report says "not yet measured".
- Tests use in-memory synthetic labels, for arithmetic only.

## Change
- Create `packages/evaluation/src/rag_foundry_evaluation/human_labels.py`.
  - **`HumanLabel`** fields:
    - `item_id` (KEY);
    - `annotator_id` (`^human-[a-z0-9-]{1,32}$`);
    - `label` (str);
    - `labeled_on` (`^\d{4}-\d{2}-\d{2}$`);
    - `source: Literal["human"]`.
  - **`HumanLabelSet`** fields: `format` `"rag-foundry.human-labels"`, `format_version` `"1"`, `rubric_id`, `rubric_version`, `items_id`, `items_sha256` (hex64), `status` (`placeholder_not_labeled` | `labeled`), `note` (at most 500 chars), `labels`.
    - `placeholder_not_labeled` requires `labels == ()`.
    - `labeled` requires at least one label.
    - A duplicate `(item_id, annotator_id)` pair is rejected.
  - **`load_human_labels(path, *, items, rubric)`** loads strictly; a duplicate key or NaN gives `invalid_human_labels`. Further error codes:
    - `label_rubric_mismatch`;
    - `label_items_mismatch` (sha);
    - `label_unknown_item`;
    - `label_unknown_value`.
  - **`placeholder_labels(items, rubric)`** has the note "No human has labeled these items yet. Do not fill this file with model output or author guesses." Also add `dump_human_labels`.
  - **`AgreementReport`** fields: `rubric_id`, `rubric_version`, `prompt_sha256`, `annotator_id | None`, `status` (`not_yet_measured` | `no_comparable_items` | `measured`), `n_items`, `n_compared`, `n_judge_invalid`, `n_unlabeled`, `percent_agreement`, `cohens_kappa`, `kappa_status` (`defined` | `undefined_chance_agreement_1` | `not_computed`), and `confusion` as `(judge, human, count)` tuples, nonzero counts only, sorted.
  - **`agreement(verdicts, labels, *, rubric)`**:
    - A verdict whose rubric id, version or `prompt_sha256` differs from the rubric raises `verdict_rubric_mismatch`.
    - **No labels:** one report with `not_yet_measured`, `annotator_id=None`, `n_items = n_unlabeled = len(verdicts)`, the other numbers 0 or None, and `not_computed`.
    - **Otherwise:** one report per annotator, sorted by annotator id.
      - `n_compared`: labelled items whose verdict is `ok`.
      - `n_judge_invalid`: labelled items whose verdict is `invalid_output`; they are excluded.
      - `n_unlabeled`: verdicts this annotator did not label.
    - **Formulas:**
      - `p_o = agree/n`;
      - `p_e = sum over rubric labels of (judge_c/n)*(human_c/n)`;
      - `kappa = (p_o - p_e)/(1 - p_e)`;
      - when `p_e == 1`, kappa is None with `undefined_chance_agreement_1`;
      - round to 6 decimal places.
    - `n_compared == 0` gives `no_comparable_items`.
  - **`render_agreement(reports)`**:
    - For `not_yet_measured`, print exactly `Judge agreement: not yet measured (0 human labels).`
    - Otherwise print a table: annotator, n_compared, n_judge_invalid, n_unlabeled, percent, kappa (`-` when None), kappa_status.
    - Always add "Judge labels are evaluator output, not ground truth."
- Create `tests/evaluation/_judge_items.py` with `judge_items_v1()`, `items_id` `answer-support-items`.
  - Item ids are neutral: `j-01` .. `j-06`. **Ids, file content and fields carry no expected label.**

  - Tests:

    2. **Placeholder agreement:** 6 ok verdicts give `not_yet_measured`, `n_unlabeled` 6, and None for both percent and kappa. The rendered text contains the exact line.
    3. **Binary case:** (S,S)x4, (S,U)x1, (U,S)x1, (U,U)x4 give `percent_agreement 0.8` and `cohens_kappa 0.6`.

    8. **Loader rejections, each with its exact code:**
       - `source: "llm_judge"`;

    9. **Neutral ids:** no `item_id` contains `faithful`, `wrong`, `flip`, `partial`, `unrelated`, `supported` or `unsupported`.
