## Change
- Create migration `0008_chunks_fts_simple.py` (revises `0007_chunk_parent_spans`): `ALTER TABLE chunks ADD COLUMN fts_simple tsvector GENERATED ALWAYS AS (to_tsvector('simple'::regconfig, text)) STORED`; `CREATE INDEX ix_chunks_fts_simple ON chunks USING gin (fts_simple)`. Downgrade drops both. Docstring: "PostgreSQL FTS, not BM25; 'simple' = lowercase only, no stemming/stop words/Arabic normalization".
- `indexing.py` (domain): add frozen `FtsScoredChunk(chunk: ChunkRecord, ts_rank: float, rank: int >= 1)`.
- `ports.py`: add a separate `@runtime_checkable FullTextIndex` Protocol: `fts_search(scope, index_version_id, query: str, k: int, *, operator: Literal["and","or"]) -> list[FtsScoredChunk]`. Do not change `IndexRepository`; do not add FTS to `InMemoryIndexRepository` (no fake FTS).
- `SqlIndexRepository.fts_search`: `_uuid`, `1 <= k <= 100` else `invalid_k`, version lookup exactly like `search` (NotFoundError, `not_ready`). `and` -> `websearch_to_tsquery('simple', :q)` on the raw query. `or` -> Python joins `[^\W_]+` tokens of the query with ` or ` (tokens equal to `or` dropped; none left -> `IndexingError("no_query_terms")`) then `websearch_to_tsquery`. SQL: `c.fts_simple @@ q`, `ts_rank_cd(c.fts_simple, q)` (normalization 0), `WHERE c.tenant_id=:t AND c.project_id=:p AND c.index_version_id=:i AND v.state='ready'`, `ORDER BY ts_rank DESC, c.ordinal LIMIT :k`. Bound parameters only; no string-built SQL.
- Create `rag_foundry_indexing/fts.py`: `FtsConfig(k: 1..50 = 5, operator: Literal["and","or"] = "and", text_search_config: Literal["simple"] = "simple")`; `FtsRetriever` manifest `R04`, `Fidelity.FAITHFUL`; ctor `(config, *, scope, index_version, index: FullTextIndex)`; empty / >2000 checks as R02; hits `distance=None`, `score_components=(ScoreComponent(name="ts_rank_cd", value=...),)`; result `technique_id="R04"`, `scoring="pg-fts-simple-ts_rank_cd"`. Register in `register_builtin_plugins`; export names.
- Create `tests/indexing/test_fts.py` (offline): config validation, registry `validate_config("R04", {})`, mapping from a small stub `FullTextIndex` to hits, empty query rejected without calling the stub.
- Create `tests/indexing/test_fts_db.py` (`pytest.mark.db`, setup copied from `test_index_db.py`, TRUNCATE list unchanged): ingest a markdown doc whose paragraphs are the `_fixture.MARKDOWN` facts plus `رقم القطعة AB-1234 في المخزن.` and the same with `AB-1243`; build with C05 + `LexicalTestEmbedder`.
