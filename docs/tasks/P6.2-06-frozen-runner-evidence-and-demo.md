## Goal
- The P6.1 frozen runner compares R21, R22 and R25 with an R02 baseline on the seed dataset. It runs one factor at a time, on the same index per run.
- The report shows recall changes **and** context growth (returned code points).
- A separate offline demo shows the R23/R24 mechanics, synthetic marking and metering.

All of this is a tiny fixture, not a benchmark.
