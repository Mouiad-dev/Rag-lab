## Change
- `rag_foundry_domain/offsets.py` (pure Python). A map goes from "normalized" (n) to "original" (o). Segment kinds: `CP` (equal lengths, exact per code point; adjacent `CP` runs merge while building, including 1:1 replacements), `ATOMIC` (any lengths, never split; 0-length n = deletion, 0-length o = insertion), `ATTACH` (deletion of a mark that belongs to the preceding character). Store segments flat in `array('q')` (5 ints each); validate contiguity and full coverage of `[0, n_len)` and `[0, o_len)`.
  - `to_original(start, end) -> MappedRange(start, end, exact)`: a `CP` position maps 1:1; a position inside an `ATOMIC` segment widens to the whole segment (`exact=False`); the end then extends over directly following `ATTACH` segments only (never over detached deletions such as format chars or whitespace); the start never extends backwards. A range touching inserted text gets `exact=False`; a range fully inside an insertion maps to the empty range at its `o_start`, `exact=False`. `to_normalized` mirrors this.
  - `a.compose(b)`: `a` X->Y, `b` Y->Z gives X->Z (so `search_to_canon.compose(canon_to_source)` = search->source). Atomic segments that straddle the other map's boundaries merge transitively into one atomic segment; `ATTACH` survives composition. `identity(n)`, `to_json()`/`from_json()` (`[[n0,n1,o0,o1,kind],...]`), `nbytes`.
- `rag_foundry_ingestion/normalize.py`, steps `str -> (str, OffsetMap)`, deterministic, each flagged `lossy`:
  - `newlines` (CRLF, CR -> LF; lossy). `nfc`, `nfkc`: split into groups; a boundary before `c` only if `combining(c) == 0`, `c` is not the second element of any primary composite (set built once from `unicodedata.decomposition` canonical pairs plus Hangul V U+1161-U+1175 and T U+11A8-U+11C2 jamo), and `normalize(form, c)` starts with a class-0 character. Normalize each group; an unchanged group is `CP`; a changed group is `ATOMIC` unless one code point becomes one code point. Guard: joined groups must equal `unicodedata.normalize(form, text)`, else raise (must never fire on valid text). NFKC is lossy (presentation forms, ligatures).
  - `casefold`; `strip_format` (category `Cf` plus U+034F; detached deletion); `strip_tatweel` U+0640 and `strip_harakat` U+064B-U+065F, U+0670 (`ATTACH`); `fold_alef` (U+0622, U+0623, U+0625, U+0671 -> U+0627), `fold_yeh` (U+0649, U+06CC -> U+064A), `fold_kaf` (U+06A9 -> U+0643), `fold_digits` (U+0660-U+0669, U+06F0-U+06F9 -> ASCII) as `CP`; `whitespace` (runs of `str.isspace` -> one U+0020 as `ATOMIC`; trimmed ends detached deletions).
  - `CANONICAL_V1 = [newlines, nfc]`; `SEARCH_AR_EN_V1 = [nfkc, casefold, nfkc, strip_format, strip_tatweel, strip_harakat, fold_alef, fold_yeh, fold_kaf, fold_digits, whitespace]`. `apply(profile, text) -> NormalizedText(text, map, profile_id, unicode_version, lossy_steps)`.
- Tests `tests/domain/test_offsets.py`: validation, each kind, edge rules, compose associativity, JSON round trip; 1M code-point mixed text through both profiles plus compose: wall time under 60 s and `tracemalloc` peak under 512 MiB, composed `nbytes` at most 40 bytes per segment (record the measured values in Result).
- `tests/ingestion/test_normalize.py` (write every non-ASCII code point below as a Python `\u`/`\U` escape):
  - NFC of U+0651 U+064E (shadda, fatha) is U+064E U+0651 (reordered) and gives one `ATOMIC` segment (hand-written); U+1100 U+1161 U+11A8 -> U+AC01, one segment; U+0627 U+0653 -> U+0622; U+212B -> U+00C5; emoji ZWJ sequence unchanged; non-BMP code point unchanged.
  - Grouping fuzz (fixed seed, stdlib `random`): random strings from all assigned code points (biased towards marks and jamo), both forms, guard never fires and output equals `unicodedata.normalize`. Profile idempotence fuzz: `apply(p, apply(p, x).text).text == apply(p, x).text` for both profiles.
  - **done criterion**: for each fixture and crafted strings (harakat, tatweel, presentation forms, Arabic-Indic digits, CRLF, NBSP, non-BMP emoji), compose search->canonical->original; for word ranges (start and end on non-space characters, because a range ending inside a collapsed whitespace run widens to the run by design) check that the original slice re-normalizes to the search slice; at least 6 hand-computed offset expectations (e.g. a voweled word with tatweel maps to its full original span, trailing harakat included).
