## Goal
`AnswerService.answer` turns a retriever result into a `RunResponse`: gate, anchors, nonce prompt, one chat call, citation checks, anchor resolution. Proven offline with in-memory repos, the test-only lexical embedder and a scripted chat double, on a committed 10-question fixture.

  1. `index_version` set and `config.min_score is None` -> `RunError("abstention_threshold_unset")` before any call. 2. `result = await retriever.retrieve(question)`.
  3. Nonce: call `nonce_factory()` until `not nonce_conflicts(nonce, question, texts)` (at most 8 tries, then `RuntimeError`; never a ValueError from the builder).
  4. `grounding == "none"`: `build_ungrounded_request`, `chat.complete`; blank text -> abstained `model_declined`; else `ungrounded`, answer = stripped text; warnings `truncated_output` if finish `length`, `unexpected_markers` if `parse_markers` finds any.
  5. Corpus: `gate = apply_gate(...)`; evidence for every hit: `marker=f"S{rank}"`, `used` = hit in `gate.used`, anchors = `anchors.anchors_for_span(scope, hit.extraction_view_id, hit.start, hit.end)`. Gate not `pass` -> abstained (`no_evidence` / `low_score`), no chat call. Else `build_grounded_request` with used `(marker, hit.text)`, `chat.complete`, `check_answer(..., known=used markers)`: declined/truncated/uncited/invalid -> abstained with the matching reason; ok -> per cited marker `anchors.resolve(scope, that evidence's anchors)`; any non-`exact` -> abstained `citation_unresolved`; else answered, answer = stripped model text (markers kept), citations in cited order. Warning `evidence_truncated` when `gate.truncated`.
  6. Pins (all supplied by the caller or the result): `technique_id=result.technique_id`, `technique_version` argument, index id and `embedding_key` from `index_version` (None if absent), chat `profile.id/provider/model`, template id, `min_score`/`k` (None when ungrounded). Usage from `ledger.totals()`. Abstained responses never contain model text. No logging of text.
