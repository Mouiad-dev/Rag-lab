## Goal
A framework-neutral port returns per-token vectors with code-point offsets. One local adapter serves C20 (last hidden states) and R45 (ColBERT head). It loads only safetensors; nothing downloads; tests run offline.

## Change
- `messages.py`: `TokenEncoding(vectors, offsets: tuple[tuple[int, int], ...], truncated: bool)` (equal lengths, 0 <= start <= end, non-decreasing starts) and `TokenEncodingResult(items, dim: int, usage: Usage)`.
- `ports.py`: `TokenEncoder` Protocol: `profile`, `max_tokens: int`, `async encode_tokens(texts, *, head: Literal["hidden", "colbert"], input_type: Literal["document", "query"]) -> TokenEncodingResult`. Special tokens are excluded from items; offsets are code-point offsets into the input.
- Create `sentence_transformers_tokens.py`: `SentenceTransformersTokenEncoder(model_dir=None)` (env `RAG_TOKEN_MODEL_DIR`): lazy load with `local_files_only=True`, `trust_remote_code=False`, `use_safetensors=True` (via model kwargs), CPU; if `model.safetensors` is absent -> `AdapterDependencyError` (never fall back to `.bin`). Tokenizer with `return_offsets_mapping=True`; forward of the underlying transformer for last hidden states. `head="colbert"` loads `colbert_linear.safetensors` with `safetensors` (no `torch.load`, no pickle), applies the linear layer as in the official BGE-M3 code (verify in the FlagEmbedding source; record URL, commit, MIT licence in the docstring), L2-normalises. Docstring deviation: official ColBERT vectors use `last_hidden_state[:, 1:]` and keep the final `</s>`; this port drops all special tokens. Over-long text truncated and flagged `truncated=True`. Read a `REVISION` file in the model dir into the profile if present.
- `pyproject.toml`: extra `tokens = [same pins as sparse]`; `uv lock --offline`; if the lock needs the network, stop and report.
- Create `tests/providers/_fake_token_encoder.py` (deterministic, test-only, "simulation, never registered"; counts calls) and `tests/providers/test_token_encoder.py`: offsets round-trip incl. Arabic as `\u0627\u0644...` escapes; truncation flagged; missing dir, missing `model.safetensors` (with a `.bin` present) and missing colbert head raise; no `torch.load` in the module (source grep test); protocol checks.
- Create `tests/live/test_token_encoder_live.py` (gated `RAG_LIVE_TOKENS=1` + `RAG_TOKEN_MODEL_DIR`): EN and AR, both heads; offsets round-trip, dims; print revision, dim, token count.
