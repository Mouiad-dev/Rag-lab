## Goal
For a ready index version, C20 encodes each extraction view once at token level (overlapping macro windows if longer than `window_tokens`) and mean-pools the tokens inside each chunk's code-point span. The same code builds the early baseline (each chunk encoded alone, same pooling). A small in-memory cosine search compares both, bound to the tenant scope of the chunks.

## Change
- Create `packages/indexing/src/rag_foundry_indexing/late_chunking.py`:
  - `LateChunkingConfig` (frozen, forbid): `mode: Literal["late", "early"]`, `window_tokens` (<= encoder `max_tokens`), `window_overlap_tokens` (< window), `k`.
  - `LateChunkingRepresentation`: manifest `C20`, `PluginKind.REPRESENTATION`, `Fidelity.ADAPTATION` (pooling rule in the docstring per ADR-0022).
  - `build(scope, version) -> ChunkVectors` (frozen: `tenant_id`, `project_id` taken from the ChunkRecords (all must equal the build scope, else NotFound), index version id, mode, encoder model, `{chunk_id: vector}`, per-chunk `token_count`, `windows_used`, `truncated`). Late: group chunks by view, load the view text through the scoped repository, encode windows with `head="hidden"`, assign a token to a chunk when its start offset lies in `[chunk.start, chunk.end)`; a token in an overlap is taken from the window where it is farthest from an edge (documented). Zero tokens -> `IndexingError("late_chunk_span_empty")`; bad window config -> `late_chunk_window_invalid`; count mismatch -> `token_encoding_count_mismatch`; bad offsets -> `token_offsets_invalid`.
  - `LateChunkingSearch(vectors, encoder)` (helper, not registered): `search(scope, query)` raises the same NotFound as the repository when `scope` tenant/project differ from the vectors' (checked before encoding the query); query = mean pool of query tokens; cosine top-k as `RetrievedChunk` with `late_cosine`/`early_cosine`; `scoring` `"c20-late-mean-pool"` or `"c20-early-mean-pool"`.
  - Encoder None or `AdapterDependencyError` -> `TechniqueUnavailableError`.
- `retrievers.py`: register `LateChunkingRepresentation`.
- Create `tests/indexing/test_late_chunking.py` (fake encoder, in-memory index): late and early vectors differ for a chunk that needs prior context; early equals the chunk encoded alone; late calls `encode_tokens` once per window, never per chunk; overlap assignment deterministic; error paths; another tenant's view is NotFound at build; **cross-tenant query**: vectors built for tenant A, `search` with tenant B scope raises NotFound and makes no encoder call; Arabic view (escapes).
