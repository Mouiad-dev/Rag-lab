## Goal
`ExactResponseCache` (R50, `cache` plugin) wraps any answer function. A hit is returned only after scope, expiry, pinned index version, source revocation and anchor resolution are rechecked; any failed check or store error is a miss followed by a fresh run. Only answers whose pins match the key inputs are stored. Every result carries a `CacheTrace`.

## Change
- Create `packages/cache/src/rag_foundry_cache/revalidate.py` (shared with R51):
  - `SourceGate` Protocol `async denied(scope, version_ids) -> frozenset[str]`; `AllowAllSourceGate` (docstring: no product source deletion yet; open item).
  - `async revalidate(scope, entry, response, *, now, expected_index_version_id, anchors, gate) -> str | None`, in order: `scope_mismatch`; `expired` (`now >= expires_at`); `index_version_changed`; `source_denied`; `anchor_unresolved` (any anchor not `exact` via `AnchorService.resolve` in the caller's scope; `NotFoundError` counts).
- Create `packages/cache/src/rag_foundry_cache/exact.py`:
  - `CacheTrace(layer: Literal["R50","R51"], outcome: Literal["hit","miss","bypass"], reason: str | None, key_prefix (12 hex), source_run_id | None, calls_avoided, input_tokens_avoided, output_tokens_avoided, lookup_ms, similarity: float | None)`; `CachedRun(response, trace)`.
  - `ExactCacheConfig(ttl_s: 1..2592000 = 86400)`; manifest `R50`, kind `cache`, version 1.0.0, fidelity `adaptation` (project design, no paper). `__init__(config, *, store)`.
  - `async run(scope, question, inputs, answer_fn, *, expected_index_version_id, anchors, gate, clock, run_id_factory) -> CachedRun`:
    - Bypass without store access: `freshness == "current"`, `mode == "enriched"`, non-empty `tools`, `is_action_run`.
    - Lookup errors: `CacheError("cache_scope_mismatch")` -> miss reason `scope_mismatch` (the foreign entry is never returned and never deleted); any other exception -> miss `cache_error` (reason only logged).
    - Hit -> parse `response_json`, `revalidate`; failure -> miss with that reason and `store.delete` of that entry (only for reasons other than `scope_mismatch`).
    - Valid hit: `response.model_copy` with a new `run_id` and zeroed `usage`; trace `hit`, `source_run_id`, avoided calls/tokens from the stored usage.
    - Miss: `await answer_fn()`. Store only if `status == "answered"`, at least one citation, and `response.pins` match the inputs (`technique_id`, `technique_version`, `index_version_id`, `embedding_key`, `chat_profile_id`, `chat_model`, `prompt_sha256`, `min_score`, `k`, `settings_sha256`); otherwise reasons `not_cacheable_status` or `pins_mismatch`. Put errors (`cache_exists` or others) keep the fresh answer with that reason.
  - `invalidate_sources(scope, version_ids)` passes through.
  - Register R50; builtin count 53 -> 54.
- Create `tests/cache/conftest.py` (same sys.path list as `tests/answering/conftest.py`) and `tests/cache/test_exact_cache.py` with the real `AnswerService` + `DenseRetriever` + scripted chat:
  - repeat question: hit with zero chat/embedding calls on fresh ledgers, same answer and citations, new run id;
  - changed model, one history turn, `authz_revision`, prompt sha or index version: miss;
  - other tenant, same inputs: miss and fresh run; forced collision with a test-only store whose `get` returns another tenant's entry: miss `scope_mismatch`, never that answer, and the foreign entry still exists afterwards;
  - gate denying a cited version: miss `source_denied`; `invalidate_sources` then lookup: miss;
  - expiry via fake clock; store raising on get and on put: correct fresh answers;
  - abstention not stored; an `answer_fn` whose response pins differ from the inputs (e.g. `k`): not stored, reason `pins_mismatch`; each bypass reason; no question text in any `CacheTrace` JSON or stored entry.
