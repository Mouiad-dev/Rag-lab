## Change
- Create `migrations/versions/0010_chunk_representations.py` (`revision = "0010_chunk_representations"`, `down_revision = "0009_chunk_sparse_vectors"`).
  - **Table `representation_sets`.**
    - Columns: `tenant_id, project_id, index_version_id, representation_key varchar(64), technique_id varchar(8), generator_json text, created_at timestamptz default now()`. PK `(index_version_id, representation_key)`.
    - FK `(tenant_id, project_id, index_version_id)` -> `index_versions (tenant_id, project_id, id)`. If no matching unique constraint exists, add one first; check 0003.
    - Checks: `representation_key ~ '^[0-9a-f]{64}$'`, `technique_id ~ '^R[0-9]{2}$'`, `char_length(generator_json) <= 8000`.
  - **Table `chunk_representations`.**
    - Columns: `tenant_id, project_id, index_version_id, chunk_id, representation_key, kind varchar(16), ordinal smallint, text text, text_sha256 varchar(64), embedded_input_sha256 varchar(64), embedding vector`. PK `(chunk_id, representation_key, kind, ordinal)`.
    - FKs: `(tenant_id, project_id, index_version_id, chunk_id)` -> `chunks (tenant_id, project_id, index_version_id, id)` (`uq_chunks_scope_id`), and `(index_version_id, representation_key)` -> `representation_sets`.
    - Checks: kind in `summary`/`question`/`context_prefix`, ordinal 0..15, `char_length(text)` 1..4000, both hashes `^[0-9a-f]{64}$`.
  - **Triggers.** Insert triggers on both tables require the index version state `ready`. On `chunk_representations` the insert trigger also requires `vector_dims(embedding) = embedding_dim`. No-update triggers on both tables.
  - **Index** `ix_chunk_repr_scope_key (tenant_id, project_id, index_version_id, representation_key)`.
  - **Downgrade order:** triggers, functions, index, `chunk_representations`, `representation_sets` (then any constraint added to `index_versions`).
- Edit `sql/index_repository.py`:
  - Implement `add_representations` with `write()`, locking the version like `add_sparse`, and `get_representation_set` / `representation_search` with `read()`.
  - Use the same error codes and order as P6.2-03a. Map unique violations to `duplicate_representation`, and a set that differs from the stored one to `representation_set_conflict`.
  - In search SQL alias the representation columns (`r.text AS rep_text`, `r.kind AS rep_kind`, ...), because `c.*` also has `text`. The order is `distance, c.ordinal, r.kind, r.ordinal`.
- Edit `packages/domain/src/rag_foundry_domain/uow.py`: add `add_representations` to `WRITE_METHODS["indexes"]`. Edit `tests/storage/test_sql_uow_db.py`: add an `add_representations` entry to the write-method map next to `add_sparse` (line ~163).
