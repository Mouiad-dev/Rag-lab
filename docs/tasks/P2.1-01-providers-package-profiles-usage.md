## Goal
`rag_foundry_providers` exists as a uv workspace member. It provides frozen `ModelProfile`/`Capabilities` with honest tri-state flags, a `Usage` record (provider, model, tokens, latency, estimated cost), `estimate_cost`, and typed errors. None of the errors subclass `KeyError` or `LookupError`.

## Change
- Create `packages/providers/pyproject.toml` (`rag-foundry-providers`, `0.0.0`, `requires-python >=3.12`, deps `pydantic>=2.14.2` only, hatchling `src/` layout). Create an empty `src/rag_foundry_providers/__init__.py` with a docstring only. P2.1-02 adds the exports.
- `errors.py`: `ProviderError(Exception)`, plus these subclasses:
  - `UnknownProfileError(profile_id)`
  - `DuplicateProfileError(profile_id)`
  - `ProfileKindError(profile_id, expected, actual)`
  - `ProviderUnavailableError(profile_id)`, for a known profile with no bound adapter
  - `MissingCapabilityError(problems: tuple[CapabilityProblem, ...])`. `CapabilityProblem` is a frozen dataclass: `stage: str | None`, `profile_id`, `capability: str`, `declared: bool | None`. The message lists every problem, for example `stage 'generator': profile 'x' lacks 'tool_calling' (declared false)` or `(not declared)`.
  - Each error keeps its arguments as attributes.
- `capabilities.py`:
  - `ModelKind` (StrEnum): `chat`, `embedding`, `reranker`.
  - `Capability` (StrEnum, 10 members): `chat`, `streaming`, `tool_calling`, `structured_output`, `vision`, `embeddings`, `token_embeddings`, `multivector`, `reranking`, `local`.
  - `Capabilities` (frozen, `extra="forbid"`, strict):
    - `streaming`, `tool_calling`, `structured_output`, `vision`, `token_embeddings`, `multivector`: `bool | None = None`. `None` means not declared and never counts as supported.
    - `local: bool = False`.
    - `context_window`, `max_output_tokens`, `embedding_dim`: `int | None`, each `> 0` when set.
  - `ModelProfile` (frozen, `extra="forbid"`):
    - `id` and `provider` match `^[a-z0-9][a-z0-9._-]*$`. `model` is non-empty. `kind: ModelKind`, `capabilities: Capabilities`.
    - `cost_per_mtok_in` and `cost_per_mtok_out`: `Decimal | None`, `>= 0`.
    - Validators: `embedding_dim` is required if and only if `kind == embedding`. The chat-only flags (`streaming`, `tool_calling`, `structured_output`, `vision`) must not be `True` on non-chat kinds.
    - Method `declared(cap) -> bool | None`. `chat`, `embeddings` and `reranking` are derived from `kind`. `local` is a plain bool. The others read the flag.
    - There is no secret field. `extra="forbid"` rejects `api_key`.
- `usage.py`:
  - `Operation` (StrEnum): `chat`, `chat_stream`, `embed`, `rerank`.
  - `Usage` (frozen, `extra="forbid"`): `profile_id`, `provider`, `model`, `operation`, `input_tokens` and `output_tokens` (`int >= 0`), `latency_ms: float >= 0`, `estimated_cost_usd: Decimal | None`.
  - `estimate_cost(profile, input_tokens, output_tokens) -> Decimal | None`: exact `tokens * rate / 1_000_000`. It returns `None` when a needed rate is `None`, because an unknown cost is never invented. An output rate is needed only when `output_tokens > 0`.
  - `Clock = Callable[[], float]` (monotonic seconds) and `measure_latency_ms(clock, start) -> float`.
- Root `pyproject.toml`: add the member, source and dev group. Run `uv lock`. In `Dockerfile`, add the `COPY packages/providers/pyproject.toml ...` line after techniques.
- Create `tests/providers/test_profiles_usage.py`. Cover:
  - The valid chat, embedding and reranker profiles.
  - Each validator failure, and that `api_key` is rejected.
  - The `declared()` table for all 10 capabilities.
  - `estimate_cost`: a known value, `None` on an unknown rate, and zero tokens.
  - `Usage` rejects negative tokens and latency.
  - Error messages name the IDs, and none of the errors is an instance of `KeyError`/`LookupError`.
