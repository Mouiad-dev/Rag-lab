## Goal
A pure, deterministic clustering function groups node embeddings into hard clusters of bounded size for one RAPTOR level. Its result depends only on caller-supplied stable keys and vectors, never on random IDs, so demos are byte-identical. It is an adaptation: the paper uses UMAP plus a Gaussian mixture with BIC and soft membership; this uses cosine k-means with a farthest-first start and hard membership.

## Change
- Create `packages/indexing/src/rag_foundry_indexing/raptor_cluster.py`. Module docstring names the deviations from the paper (no UMAP, no GMM/BIC, hard clusters, no soft overlap).
  - `ClusterConfig(extra="forbid", frozen)`: `target_cluster_size` (5, 2-20), `max_cluster_size` (10, 2-50, >= target), `max_iterations` (20, 1-100).
  - `ClusterItem(key: tuple[int, ...], node_id: str, embedding: tuple[float, ...])`. `key` is a stable order key from the caller (03 passes the first lineage span `(start, end)`); `node_id` is only the last tie-break.
  - `cluster_nodes(items, config) -> ClusterResult`:
    - empty input, duplicate node IDs or mixed dimensions raise `ValueError`;
    - sort items by `(key, node_id)` first, so input order never matters;
    - `k = ceil(n / target_cluster_size)`; `n <= target_cluster_size` gives one cluster;
    - init: first centroid is the first sorted item; each next is the item with the largest minimum cosine distance to the chosen centroids (ties: first in sorted order);
    - Lloyd iterations with cosine similarity; ties go to the lowest cluster index; stop when assignments stop changing or at `max_iterations`;
    - drop empty clusters; split any cluster above `max_cluster_size` by the same 2-means, repeatedly;
    - zero vectors are allowed (similarity 0), never a division error.
  - `ClusterResult(clusters: tuple[tuple[str, ...], ...], iterations, converged)`: node IDs inside a cluster in `(key, node_id)` order; clusters ordered by their first item's `(key, node_id)`; every input ID in exactly one cluster.
- Export `ClusterConfig`, `ClusterItem`, `ClusterResult`, `cluster_nodes` from `__init__.py`.
- Create `tests/indexing/test_raptor_cluster.py`:
  - three well-separated topic groups (12 items) give exactly those 3 clusters;
  - shuffled input gives the identical result;
  - the same keys and vectors with different random node IDs give the same clusters when mapped back by key (byte-identical demo guarantee);
  - `max_cluster_size=3` splits a group of 6 and no cluster exceeds 3;
  - single item, all-identical vectors and a zero vector work;
  - empty input, duplicate IDs and mixed dimensions raise;
  - `converged` is reported; `max_iterations=1` still returns a valid partition.
