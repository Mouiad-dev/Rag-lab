## Goal
`EvidenceDedup` (R10) takes one ranked `RetrievalResult` and removes repeated passages with three explicit, deterministic rules. It keeps the higher-ranked copy and records every dropped candidate with its full provenance. Distinct sources that disagree on numbers are kept.

## Change
- `errors.py`: add `"selection_invalid_input"` and `"selection_version_mismatch"` to `IndexingError.CODES` (P5.3-02/03 reuse them). Unregistered codes raise `ValueError`, so the tests below fail without this.
- Create `rag_foundry_indexing/selection.py`:
  - `check_single_input(result)`: `grounding == "corpus"`, `index_version_id` not None, ranks exactly `1..n`, unique `chunk_id`s; otherwise `IndexingError("selection_invalid_input")`.
  - `DedupConfig` (frozen, `extra="forbid"`): `rules: tuple[Literal["exact_text","span_overlap","near_text"], ...] = ("exact_text","span_overlap","near_text")` (1..3 items, no repeats), `near_threshold: float 0.5..1.0 = 0.8`, `shingle_size: int 1..5 = 3`, `span_overlap_min: float 0.1..1.0 = 0.5`, `protect_numbers: bool = True`, `k: int 1..50 | None = None` (None keeps all survivors).
  - `DroppedCandidate` (frozen): `chunk_id, extraction_view_id, start, end, input_rank, kept_chunk_id, rule, similarity (0..1)`. `DedupResult` (frozen): `result: RetrievalResult`, `dropped: tuple[DroppedCandidate, ...]`.
  - `EvidenceDedup`: manifest `R10`, `PluginKind.FUSION` (stage Q4 "Fusion and selection" in `config/pipeline_stages.json`; no new kind), `Fidelity.ADAPTATION`, `1.0.0`. `select(result) -> DedupResult` (sync, no I/O).
  - Algorithm: walk hits in input rank order. Compare each with the kept hits in kept order. Apply the enabled rules in the fixed order exact_text, span_overlap, near_text. The first match drops the candidate.
    - exact_text: `sha256(unicodedata.normalize("NFC", text))` equal, similarity 1.0.
    - span_overlap: same `extraction_view_id` and `max(0, min(ends) - max(starts)) / min(lengths) >= span_overlap_min`, similarity = that ratio.
    - near_text: Jaccard of the sets of `shingle_size`-grams over `lexical_tokens(text)`. If there are fewer tokens than `shingle_size`, the whole token tuple is one shingle; empty token lists never match. Drop if `>= near_threshold`. With `protect_numbers`, skip near_text when the two sets of tokens containing a digit differ.
  - Output: kept hits renumbered `1..n` (truncated to `k` if set; hits cut by `k` are not "dropped"), `score` unchanged. Components = original + `ScoreComponent(name="input_rank", value=float(rank), source=<input technique_id>, source_rank=rank)` + one `dedup_<rule>` component per candidate it absorbed (value = similarity, source_rank = the dropped hit's input rank). `technique_id="R10"`, same `index_version_id`, `scoring=f"dedup[{input_tid}]:{'+'.join(rules)}"`.
- `retrievers.py` `register_builtin_plugins`: register `EvidenceDedup`. `__init__.py`: export `DedupConfig`, `DedupResult`, `DroppedCandidate`, `EvidenceDedup`, `check_single_input`.
- Create `tests/indexing/test_dedup.py` (hand-built `RetrievalResult`s; every hit gets its own `extraction_view_id` unless the case says otherwise, so span overlap cannot interfere; non-ASCII only as `\u` escapes):
  - Exact text in two different views (ranks 1 and 3): rank 3 dropped, `rule="exact_text"`, its view/start/end kept in `dropped`, and the kept hit carries `dedup_exact_text` with `source_rank=3`.
  - Span overlap in the same view: `[0,100)` and `[50,150)` dropped (0.5). `[0,100)` and `[80,180)` kept (0.2). The same spans in different views are not span duplicates.
  - Near text: `"the tidal observatory records sea levels every hour along the northern harbour wall"` vs the same ending in `pier` gives Jaccard 10/12, dropped. Assert similarity within 1e-9.
  - Conflicting numbers: `"the unit price of the blue box is 10 dollars in the spring catalogue"` vs `... 12 dollars ...` (Jaccard 9/15 = 0.6). With `near_threshold=0.55` and the default `protect_numbers`, both are kept. With `protect_numbers=False`, the second is dropped.
  - Arabic: `"سعر القطعة ١٠"` vs `"سعر القطعة 10"`: not exact_text, but near_text with similarity 1.0 (digits fold).
  - Every input chunk_id appears exactly once in kept hits or in `dropped`. Kept ranks are `1..n`.
  - Duplicate chunk_ids, a gap in ranks, or `grounding="none"` all give `selection_invalid_input` (assert `.code`).
  - Registry via `register_builtin_plugins`: `validate_config("R10", {}) == DedupConfig()`. `{"rules": []}`, `{"rules": ["semantic"]}` and `{"near_threshold": 0.3}` are rejected.
