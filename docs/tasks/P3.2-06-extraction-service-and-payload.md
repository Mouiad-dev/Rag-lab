## Goal
`ExtractionService.extract(scope, document_id, version_id)` returns an existing view for the same identity key without reading anything; otherwise it reads the stored bytes (verifying sha256), runs the extractor off the event loop, stores a canonical JSON payload and records an immutable view. An offline end-to-end test proves the P3.2 done criterion.

## Change
- `ports.py`: add `open_read(self, key: str) -> AsyncIterator[bytes]` to `ObjectStore`, matching `LocalObjectStore.open_read` exactly; do not change `LocalObjectStore` (if the runtime-checkable Protocol check fails, stop and report).
- `rag_foundry_ingestion/payload.py`: `ExtractionPayload` v1: `schema_version=1`, `extractor`, `extractor_version`, `profile_id`, `unicode_version`, `source_space`, `page_starts`, `canonical_text`, `blocks`, `source_map` (`OffsetMap.to_json()`). `dumps()` = `json.dumps(sort_keys=True, separators=(",", ":"), ensure_ascii=False, allow_nan=False)` encoded UTF-8; `loads()` validates and checks blocks lie inside the text and the map covers it.
- `rag_foundry_ingestion/extraction.py` `ExtractionService(store, documents, views, *, extractors, limits)`:
  1. `get_version(scope, ...)` (scope check); pick the extractor by media type; build the `ExtractionKey` from its `name`/`version`, `CANONICAL_V1` and `unicodedata.unidata_version`; `views.find_view` hit -> return `ExtractionOutcome(view, created=False)` with no read or extract.
  2. Read `store.open_read(version.object_key)` with a running sha256, reading at most `size_bytes + 1`; hash or size mismatch -> `integrity_mismatch`.
  3. `asyncio.to_thread(extractor.extract, ...)`; payload bytes; `stage(..., max_bytes=len(payload))` then `commit` at `key_for(scope, payload_sha256)`; discard on failure before commit (same pattern as `IntakeService`).
  4. `create_view_or_get`. `load_payload(scope, view)` re-hashes against `payload_sha256` and validates.
- Tests `tests/ingestion/test_extraction_service.py` (`LocalObjectStore(tmp_path)` + in-memory repos, style of `test_intake.py`):
  - **done criterion**: a mixed Arabic/English `.md` (CRLF, harakat, tatweel, non-BMP emoji) and an `.html` with entities are ingested and extracted; payload loaded; search hits found with `SEARCH_AR_EN_V1` over canonical text map through the composed maps to hand-computed original code-point offsets, and the original slice re-normalizes to the hit (word ranges with non-space ends).
  - Second call returns the same view and does not call `open_read` (spy); tampered or truncated object -> `integrity_mismatch`; other tenant -> `NotFoundError` with nothing read; payload `dumps` is byte-identical across runs; PDF case skipped when the `pdf` extra is missing.
