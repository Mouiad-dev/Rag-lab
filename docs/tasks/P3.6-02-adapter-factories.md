## Goal
Each adapter has one `AdapterFactory` held in an explicit `AdapterRegistry`; `pipeline.build_registry`, `ollama_model_factory` and `rag-foundry-index` build adapters through it. Adding an adapter needs no edit to `pipeline.py`. Same wrappers, same errors, same messages.

## Change
- Create `packages/providers/src/rag_foundry_providers/factories.py`:
  - `AdapterFactory` Protocol: `name: str`, `kinds: frozenset[ModelKind]`, `requires_base_url: bool`, `requires_api_key: bool`, `build(profile, endpoint, *, transport, clock) -> object`.
  - `FakeFactory` (chat/embedding/reranker; neither required; calls `Fake*(profile, clock=clock)` exactly as today, clock passed even when None), `OllamaFactory` (chat/embedding; base_url), `AnthropicFactory` (chat; api key; `api_base` only when `base_url` set), `OpenAICompatibleFactory` (chat/embedding; base_url; same kwargs and `max_tokens_field` / `supports_temperature` defaults as `_construct`). Non-fake factories pass `clock` only when not None (today's `_clock`). Each checks its `requires_*` first (missing -> `ProviderUnavailableError(profile.id)`), then imports its adapter module inside `build`, so a missing extra still raises the adapter's own error.
  - `AdapterRegistry`: `register(factory)` (same name twice -> `DuplicateAdapterError`), `get(name)` (unknown -> `UnknownAdapterError`), `names() -> frozenset[str]`, `build(profile, endpoint, *, transport=None, clock=None)`: `profile.kind not in factory.kinds` -> `UnsupportedModelKindError`; else `factory.build(...)`.
  - `default_adapter_registry() -> AdapterRegistry`: a new registry with the four factories, registered only in this function.
- `errors.py`: `UnknownAdapterError(ProviderUnavailableError)` and `UnsupportedModelKindError(ProviderUnavailableError)` with `__init__(profile_id, adapter[, kind])` calling `super().__init__(profile_id)` (message unchanged) and storing `adapter` / `kind`; `DuplicateAdapterError(ProviderError)`. None subclass KeyError/LookupError.
- `pipeline.py`: delete `_construct` and `_clock`; `build_registry(..., adapters: AdapterRegistry | None = None)`; `adapter = (adapters or default_adapter_registry()).build(profile, endpoint, transport=transports.get(endpoint.id), clock=clock)`. Wrapping, order, budget and reranker checks unchanged.
- `packages/answering/src/rag_foundry_answering/runner.py` `ollama_model_factory(base_url, *, retry=RUN_RETRY, adapters=None)`: build `Endpoint(id="ollama", adapter="ollama", base_url=base_url, local=True)` once, outside the inner function; chat/embedding via `registry.build(ollama_chat_profile(), endpoint)` / `ollama_embedding_profile()`; wrap chain unchanged (`default_max_output_tokens=512`).
- `apps/worker/src/rag_foundry_worker/index_cli.py`: embedder via `default_adapter_registry().build(ollama_embedding_profile(), Endpoint(...))`; wrappers unchanged.
- Tests: create `tests/providers/test_factories.py`:
  - each factory builds the same adapter class as before for each supported kind; the fake gets the given clock;
  - unsupported pairs (anthropic embedding, ollama / openai_compatible reranker) -> `UnsupportedModelKindError`, an instance of `ProviderUnavailableError`, `str(err) == str(ProviderUnavailableError(pid))`;
  - endpoints missing `base_url` / `api_key_env` (`Endpoint.model_construct`) -> `ProviderUnavailableError`; unknown name (model_construct) -> `UnknownAdapterError`; duplicate register -> `DuplicateAdapterError`;
  - a test-only `EchoFactory` in a fresh registry passed to `build_registry(adapters=...)` binds a wrapped model (no `pipeline.py` change);
  - `default_adapter_registry().names() == set(get_args(AdapterName))`;
  - parity: for each adapter name, `Endpoint` without `base_url` is rejected exactly when `requires_base_url`, and without `api_key_env` exactly when `requires_api_key` (anthropic only);
  - importing `factories` in a subprocess does not load `rag_foundry_providers.adapters.ollama`, `.anthropic` or `.openai_compat`.
- `tests/providers/test_pipeline_selection.py` line 123: patch `rag_foundry_providers.factories.AdapterRegistry.build`. `tests/answering/test_runner.py`: `ollama_model_factory` still yields `ResilientChatModel` / `ResilientEmbeddingModel`; `"http://ollama:11434"` and `Settings().ollama_base_url` are accepted by `Endpoint`.
