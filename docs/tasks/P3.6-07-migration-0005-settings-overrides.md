## Change
- Create `packages/storage/src/rag_foundry_storage/sql/migrations/versions/0005_runtime_setting_overrides.py` (revises `0004_prompt_templates`; raw SQL; not in `models.py`):
  - Columns: `id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY`, `level varchar(8)` CHECK in ('global','tenant','project'), `tenant_id uuid NULL`, `project_id uuid NULL`, CHECK on the level/id shape, `key varchar(64) NOT NULL` CHECK `key IN (...)` with the literal list from `ALLOWED_KEYS` (adding a key needs a new migration), `value_json jsonb NULL`, `version integer NOT NULL` CHECK >= 1, `created_by varchar(128) NOT NULL`, `created_at timestamptz NOT NULL DEFAULT clock_timestamp()`, `reason varchar(500) NOT NULL`.
  - Value CHECKs (NULL allowed = reset): `jsonb_typeof(value_json) IN ('number','boolean','object')`; `octet_length(value_json::text) <= 4096`; objects hold numbers only: `jsonb_typeof(value_json) <> 'object' OR NOT jsonb_path_exists(value_json, '$.* ? (@.type() != "number")')`; object keys match the min-score pattern: `... OR NOT jsonb_path_exists(value_json, '$.keyvalue() ? (!(@.key like_regex "<MIN_SCORE_KEY>"))')`. Verify in the PostgreSQL 18 docs that `jsonb_path_exists` (non-`_tz`) is immutable and allowed in a CHECK, and the `like_regex` syntax; if not, record the alternative used in Result.
  - FKs: `tenant_id` -> `tenants(id)`; `(tenant_id, project_id)` -> `projects(tenant_id, id)`.
  - `UNIQUE NULLS NOT DISTINCT (level, tenant_id, project_id, key, version)` (PostgreSQL 15+; verify in the PG 18 CREATE TABLE docs).
  - BEFORE UPDATE OR DELETE trigger that raises. Downgrade drops table and function.
- Create `packages/storage/src/rag_foundry_storage/sql/settings_repository.py` (`SqlSettingsOverrideRepository(sessionmaker)`): bound parameters only; `validate_override` before any SQL; version = `max + 1` in one transaction, unique violation -> `SettingsError("version_conflict")`; malformed UUID -> `invalid_override`; `current(scope)` and `history` filter project rows on `tenant_id = :tenant AND project_id = :project` and tenant rows on `tenant_id = :tenant`; `OperationalError` / `InterfaceError` -> `SettingsError("store_unavailable")` without cause; never log `reason`, `created_by` or values.
- Add `runtime_setting_overrides` first in the TRUNCATE string of `tests/api/test_anchors_db.py`, `tests/indexing/test_index_db.py`, `tests/live/test_answer_live.py`, `tests/live/test_index_live.py`, `tests/storage/test_sql_extraction_repository.py`, `tests/storage/test_sql_repository.py`, `tests/storage/test_sql_index_repository.py` (FK to `projects`).
