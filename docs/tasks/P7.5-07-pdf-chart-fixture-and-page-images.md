## Goal
A deterministic generator writes a small PDF with visually distinct pages (one fact only visible in a chart). A pure function renders PDF pages to PNG bytes under strict limits, with page indices that match extraction `page_index`. Only what R41 needs; no vision chat (R40 is blocked).

## Change
- Create `tests/fixtures/multimodal/make_chart_pdf.py` (stdlib only, PDF 1.4 by hand: Helvetica text, `re f` rectangles, no dates or IDs): page 0 "Regional report" paragraph; page 1 bar chart "Visitors by region 2025" with labelled bars North, South, East, West, values only in bar heights (South tallest); page 2 ruled table "Opening hours" with text cells; page 3 only a rectangle, no text layer. Output `tests/fixtures/multimodal/chart_report.pdf`, committed.
- Create `tests/fixtures/multimodal/questions.json`: page-retrieval questions (chart, table, text, one unanswerable), each with the expected page index.
- Create `packages/ingestion/src/rag_foundry_ingestion/page_images.py`: `PageImage(page_index, width, height, png: bytes)` with `png` excluded from repr; `render_pdf_pages(pdf: bytes, *, scale=1.5, max_pages=20, max_pixels=4_000_000) -> tuple[PageImage, ...]`. Before rendering each page compute `ceil(width_pt * scale) * ceil(height_pt * scale)` from the page size and raise `ExtractionError("page_render_limit")` if over `max_pixels` (also if page count > `max_pages`). Render with pypdfium2; its bitmaps are BGR(x) by default, so request RGB output if the API offers it or reverse channels to RGB; encode PNG with a stdlib zlib writer (RGB, filter 0). Invalid PDF -> `ExtractionError("page_image_invalid")`. Every pdfium object closed (try/finally).
- Create `tests/ingestion/test_page_images.py`: running the generator twice gives identical bytes (the determinism check); extraction of the fixture yields blocks on pages 0-2 and none on page 3; rendering gives 4 valid PNGs (signature, IHDR size); a red-filled rectangle renders with R > B in a sampled pixel (channel order); page and pixel limits raise before rendering; repr has no bytes.
