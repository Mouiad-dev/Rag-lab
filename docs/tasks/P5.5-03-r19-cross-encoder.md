## Change
- Create `rag_foundry_providers/sentence_transformers_rerank.py` with `SentenceTransformersCrossEncoder`, which implements `Reranker`:
  - Model dir comes from the argument or `RAG_RERANK_MODEL_DIR`. Profile: `provider="sentence-transformers"`, `kind=RERANKER`, `Capabilities(local=True)`, model name taken from the dir name.
  - Lazy load: `CrossEncoder(str(dir), local_files_only=True, device="cpu", trust_remote_code=False)`. These cases raise `AdapterDependencyError("sparse")`:
    - a missing dir;
    - `ImportError`;
    - `OSError` or `ValueError` while loading;
    - `num_labels != 1`.
  - Scores: `predict([(query, d) ...], convert_to_numpy=True)` in `asyncio.to_thread`. It uses the model's configured activation. For `num_labels == 1` with no configured `activation_fn`, that is Sigmoid (model.py 377), so scores are in (0, 1). Do not pass `apply_softmax` and do not override the activation. Store the activation class name (`type(model.activation_fn).__name__`) on the adapter as `activation`.
  - Order: score descending, then index ascending (the port contract), then `top_n`.
  - Empty `documents`: return no items, `input_tokens=0`, and do not load or call the model.
  - Tokens: `sum(len(ids) for ids in model.tokenizer([query] * n, list(documents), truncation=True)["input_ids"])`, as `TokenSource.ESTIMATED`. If the model has no `tokenizer`, fall back to whitespace word count of query plus doc per pair, and say so in a docstring.
  - Usage: `Operation.RERANK`, measured `latency_ms`, cost 0.
- Create `rag_foundry_indexing/cross_encoder_rerank.py`:
  - `CrossEncoderRerankConfig(k=5 [1..50], max_candidates=50 [1..100])`.
  - Class `CrossEncoderReranker`, manifest `R19`, `PluginKind.RERANKER`, `Fidelity.FAITHFUL`. The mechanism (joint query-passage scoring after retrieval) follows arXiv 1901.04085; the model differs, and the lesson says so.
  - Constructor takes `config, *, reranker: Reranker | None`.
  - `async rerank(question, result) -> RerankedRetrieval`:
    1. Question checks raise `IndexingError("empty_query" / "query_too_long")`. Then run `check_rerank_input`.
    2. `reranker is None` raises `TechniqueUnavailableError("R19 needs the [sparse] extra and an approved local cross-encoder model")`. An `AdapterDependencyError` raises the same error.
    3. A non-RERANKER profile raises `rerank_wrong_model_kind`.
    4. Empty `result.hits`: return status `applied`, an empty result with the same index version, `changes == ()`, and `usage == ()`. Do not call the reranker.
    5. Otherwise call `rerank(question, [h.text ...], top_n=k)`. Validate the items: unique, in range, finite, sorted. Otherwise raise `rerank_invalid_order`.
    6. Call `apply_order` with extra component `rerank_score`. Trace usage is `(result.usage,)`.
  - Register it in `register_builtin_plugins`.
- Create `tests/live/test_cross_encoder_live.py`:
  - Skip unless `RAG_LIVE_RERANK=1` and `RAG_RERANK_MODEL_DIR` are set.
  - Run `RERANK_CHECKS`.
  - Rerank `FACT_EN` and `FACT_AR` among `DISTRACTORS` for `QUERY_EN` and `QUERY_AR`. Assert the fact is in the top 1, the output is a subset of the input, there is 1 usage, and the activation is `Sigmoid`.
  - Print the order, scores, `usage.input_tokens` and `usage.latency_ms`.

## Tests (offline; the [sparse] extra must not be needed)
- `tests/providers/test_sentence_transformers_rerank.py` uses `monkeypatch.setitem(sys.modules, "sentence_transformers", SimpleNamespace(CrossEncoder=Stub))` and a `tmp_path` model dir. The stub has:
  - `num_labels = 1`;
  - `activation_fn = SimpleNamespace()`;
  - `predict` returning `[0.2, 0.9, 0.2]`;
  - `tokenizer(q, d, truncation=True)` returning `{"input_ids": [[0] * 4, [0] * 5, [0] * 6]}`.
- Expected: items `[(1, 0.9), (0, 0.2), (2, 0.2)]`, `input_tokens == 15`, operation `rerank`, and `top_n=1` gives 1 item.
- A stub without `tokenizer`, query "a b", docs "c", "d e": `input_tokens == 7`.
- Error cases, each raising `AdapterDependencyError`:
  - `num_labels = 2`;
  - a missing dir;
  - `sys.modules["sentence_transformers"] = None` (the ImportError case).
- Empty docs: 0 items, `input_tokens == 0`, and `predict` is never called.
- `tests/indexing/test_cross_encoder_rerank.py` (`FakeReranker`, a Jaccard test double, not R19):
  - Input hits `"cat sat"`, `"dog"`, `"cat"`; question `"cat"`; k=2.
  - Expected: order `[cat, cat sat]`, `rerank_score` values `[1.0, 0.5]`, `dropped == (dog_id,)`, `moved` values `[2, -1]`, and 1 usage.
- More R19 cases:
  - A stub returning index 7, or a duplicate index, raises `rerank_invalid_order`.
  - `reranker=None` raises `TechniqueUnavailableError`.
  - A chat profile raises `rerank_wrong_model_kind`.
  - Empty hits give an empty result and 0 reranker calls.
  - `registry.validate_config("R19", {})` equals the default config.
