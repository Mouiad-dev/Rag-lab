## Goal
`rag_foundry_storage.sql.database` creates the engine and sessionmaker once and disposes them once; the API (lifespan), `extract_cli`, `index_cli`, `ask_cli` and all DB tests use it; `create_sessionmaker` and every `maker.kw["bind"].dispose()` are gone. Behaviour is unchanged.

## Change
- Create `packages/storage/src/rag_foundry_storage/sql/database.py`:
  - `@dataclass(frozen=True) class Database` with `engine: AsyncEngine`, `sessionmaker: async_sessionmaker[AsyncSession]`; `async def dispose()`.
  - `create_database(url: SecretStr) -> Database`: `create_async_engine(url.get_secret_value(), pool_pre_ping=True, hide_parameters=True)`, `async_sessionmaker(engine, expire_on_commit=False)`. Does not connect.
  - `open_database(url)` (`@asynccontextmanager`): yields a `Database`, disposes in `finally`.
  - `run_db_main(coro)`: `asyncio.Runner(loop_factory=asyncio.SelectorEventLoop)` on win32, default loop elsewhere; returns the result. Docstring: psycopg async cannot use the Proactor loop; never call from a running loop.
- Delete `engine.py`. Replace every caller (`git grep -n "create_sessionmaker\|kw\[\"bind\"\]"` must be empty afterwards, including tests from P3.6): CLIs use `async with open_database(settings.database_url) as db:` and `run_db_main(...)` (delete their own Selector-loop code); repositories still get `db.sessionmaker` (05 changes that).
- `apps/api/src/rag_foundry_api/main.py`: build the `Database` with `create_database` where the sessionmaker was built; the lifespan disposes it after `yield` (`try/finally`). Everything else unchanged (03 rewrites DI).
- Tests (`tests/storage/*`, `tests/indexing/test_index_db.py`, `tests/api/test_anchors_db.py`, `tests/live/*`, the 00 `_build`): switch to `open_database` / `create_database` + `dispose()`. Keep each file's local `run` helper unless it is a plain copy of `run_db_main` (then import it).
- Create `tests/storage/test_database.py` (offline): `create_database` with a closed-port `postgresql+psycopg` URL containing a distinctive password does not connect; `engine.hide_parameters is True`; `sessionmaker.kw["expire_on_commit"] is False`; pre-ping enabled (public pool option if one exists, else `engine.pool._pre_ping` with a comment); `open_database` disposes on normal exit and on an exception (monkeypatch `Database.dispose` to record); `run_db_main` returns the coroutine result and, on win32, runs on a `SelectorEventLoop`; the password string is absent from `repr(db)`, `str(db.engine.url)` and the `str` of a connection error (host and user may appear).
