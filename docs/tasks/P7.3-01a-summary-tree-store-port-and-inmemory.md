## Change
- `ports.py`: `@runtime_checkable class SummaryTreeStore(Protocol)`:
  - `add_summary_tree(scope, index_version_id, tree) -> None`: atomic.
  - `get_summary_tree(scope, index_version_id, tree_key) -> SummaryTree`: `NotFoundError` when missing or out of scope.
- `uow.py`: add `add_summary_tree` to `WRITE_METHODS["indexes"]`. `uow_adapters.py`: add `SummaryTreeStore` to the allowed extra ports.
- `index_testing.py` `InMemoryIndexRepository`: implement both. On add, in this order:
  - version in scope (else `NotFoundError`); state `ready` (else `not_ready`); `tree.check_scope(scope, index_version_id)`; key not present (else `tree_exists`);
  - every leaf: chunk belongs to this version, same view, span inside the chunk, `chunk.text[...] == span.quote` (else `tree_source_mismatch`); each chunk appears as at most one leaf.
  - Store a copy; get returns an equal object.
- `index_testing.py`: `make_summary_tree(scope, version, chunks)` (2 levels, fixed embeddings), `check_summary_trees(factory)`, `TREE_STORE_CHECKS = (check_summary_trees,)`. Cases: round trip; stranger scope add and get; not-ready version; duplicate key (also with a bad span -> `tree_exists` first); leaf with wrong quote, outside its chunk, wrong view, chunk of a sibling version; tree for version B added to A (`tree_scope_mismatch`); Arabic leaf round trip.
- Create `tests/domain/test_tree_store.py` running `TREE_STORE_CHECKS` offline (pattern of `test_graph_store.py`). `tests/domain/test_uow.py`: add `TREE_STORE_CHECKS` to the per-call adapter loop.
