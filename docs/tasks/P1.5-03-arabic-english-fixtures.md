## Goal
Three tiny UTF-8 text fixtures (English, Arabic, mixed) plus anchors that validate against `SourceAnchor` v1. A test proves every anchor's `exact` equals the code-point slice of its block, including Arabic diacritics and a non-BMP emoji. Provenance is recorded.

## Change
- Create `packages/contracts/fixtures/sources/`:
  - `en_short.txt`: 3 short paragraphs (block = paragraph, separated by one blank line). Paragraphs 1 and 3 are identical, to test repeated paragraphs.
  - `ar_short.txt`: 2 short Modern Standard Arabic paragraphs, one with full diacritics (tashkeel) and the Arabic comma `،`.
  - `mixed_short.txt`: 1–2 paragraphs mixing Arabic and English words, Arabic-Indic and Western digits, and one non-BMP emoji (for example U+1F4D8).
  - Each file: UTF-8 without BOM, LF line endings, final newline, under 600 characters. Write the text yourself on a neutral topic (for example how a library catalogue works). Do not quote books, websites, scripture or any third-party text.
  - `anchors.json`: a JSON list of `SourceAnchor` objects, `provider_namespace: "rag-foundry-fixtures"`, IDs like `doc-en`/`docv-en-1`/`xv-en-1`, `block_id` `p1`, `p2`, ... At least: one whole-paragraph and one mid-paragraph anchor per file, both repeated English paragraphs (same `exact`, different `block_id`), one Arabic span with diacritics, one mixed span containing the emoji. `precision: "exact_text"`, `page_index: null` (plain text has no pages).
  - `PROVENANCE.md`: author (written for RAG Foundry by the coding agent on <date>, reviewed by the maintainer), licence = repository licence, no third-party text, block rule, offset convention, and a note asking for native-speaker review of the Arabic.
- Create `.gitattributes` with `packages/contracts/fixtures/** text eol=lf` so Windows checkouts do not shift offsets.
- Create `tests/contracts/test_fixtures.py`: load each text (`read_bytes().decode("utf-8")`, assert no `\r` and no BOM); blocks = `text.rstrip("\n").split("\n\n")`; every anchor in `anchors.json` validates, and `blocks[n][start:end] == exact`; the emoji anchor has `len(exact) < len(exact.encode("utf-16-le")) // 2` (code points vs UTF-16 units); the two repeated English anchors have equal `exact` and different `block_id`; each fixture file has at least one anchor.
