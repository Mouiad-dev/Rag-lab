## Goal
`AnthropicChatModel` implements `ChatModel` on `POST /v1/messages`. It passes `CHAT_CHECKS` and `DETERMINISTIC_CHAT_CHECKS` through `httpx.MockTransport`. Usage is `PROVIDER`-sourced, including cache tokens, and cost comes from the verified rates. The key never leaks.

## Change
- Create `adapters/anthropic.py`:
  - `anthropic_chat_profile(id, model)` with two helpers, `anthropic_haiku_profile()` and `anthropic_sonnet_profile()`, using the exact IDs from P2.3-01 item 7:
    - `kind=chat`, `local=False`, `streaming=True`;
    - `tool_calling`, `structured_output` and `vision` are `False`, because they are not implemented in P2.3 (P2.4). Say so in the docstring;
    - `context_window` and `max_output_tokens` from item 7;
    - the four rates (in, out, cache read, 5-minute cache write) from item 8 in a `_PRICES` table with source URL and date. A model missing from the table gets `None` rates.
  - `AnthropicChatModel(profile, *, api_base="https://api.anthropic.com", timeout_s=60.0, default_max_tokens=1024, transport=None, clock=...)`:
    - reads the key with `read_api_key()` at construction;
    - refuses profiles that declare tools, structured output or vision as `True`;
    - `__repr__` shows only the class and profile id.
  - Payload:
    - leading `system` messages are joined into top-level `system`; a later `system` message or any `tool` role raises `ProviderError` before any call;
    - `max_tokens` is `request.max_output_tokens` or `default_max_tokens`;
    - a request that sets `temperature` raises a typed `ProviderError` subclass before any call (never sent, never clamped), per ADR-0001 "Owner decisions 2026-11-02 for 03..05";
    - never send `tools`, `tool_choice` or `cache_control`. `thinking` is set explicitly per model (Haiku `disabled`, Sonnet as documented), per the same ADR paragraph.
  - `complete`: `text` is the concatenated `text` blocks; skip `thinking`/`redacted_thinking` blocks; `tool_use` is `bad_response`. Map `stop_reason`: `end_turn`/`stop_sequence` → `stop`, `max_tokens` → `length`, `refusal` → `ProviderCallError(refused)`, anything else → `bad_response`.
  - `stream`: parse SSE from `aiter_lines()` (`event:`/`data:` lines, blank-line dispatch) with no new dependency.
    - Yield `text_delta` deltas; ignore `ping`.
    - An `error` event, invalid JSON, or an end without `message_stop` → `ProviderCallError` (mapped type or `bad_response`).
    - Usage comes from `message_start` and is updated by `message_delta` per item 4.
    - Close the response and client in `finally`.
  - Usage: `token_source=PROVIDER` only when `input_tokens` and `output_tokens` are ints ≥ 0; otherwise `bad_response`, never an estimate for a paid call. Cache fields come from the API. Cost uses `estimate_cost` with cache kwargs, and is `None` if 1-hour cache-write tokens > 0, since that rate is not in the profile.
- Create `tests/providers/test_anthropic_chat.py` (MockTransport, canned JSON and SSE shaped per the docs):
  - `CHAT_CHECKS` and `DETERMINISTIC_CHAT_CHECKS` pass.
  - Payload rules, including the system split and refusals before any call.
  - Every `stop_reason`; usage with and without cache tokens gives exact Decimal cost; an unknown model gives `None` cost.
  - An error event mid-stream; a stream with no `message_stop`; an early `break` closes the response.
  - Extend the 03 leak test to cover `complete`, `stream` and a `RecordingChatModel` + `UsageLedger` (from 02): the sentinel is absent from DEBUG logs, errors, tracebacks, `repr(model)`, profile dumps, `Usage` and ledger dumps.
