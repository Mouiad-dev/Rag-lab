## Goal
The grounded and ungrounded system messages come only from the active rows of the prompt store (cached by id, hash-checked); `prompt.py` keeps the delimiter, nonce and decline rules. The P3.6-00 golden requests still match unchanged (the byte-level proof), pins carry `prompt_sha256`, store failures fail the run with no fallback, and 3 live runs pass the ADR-0013 D15 gates; per-run differences from the 2026-11-06 runs are reported as measured.
