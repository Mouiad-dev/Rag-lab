## Goal
`CagWorkflow` (R47, `workflow` plugin) answers over a `CagSnapshot` through the existing `AnswerService`, so gating, citation checks and anchor resolution are unchanged. Arm `cag` sends a byte-identical prefix for every question (stable nonce); arm `full_context_uncached` sends the same evidence with a per-run nonce. All guards run before any model call; the nonce never leaves the process except inside the model request.

## Change
- `cag.py` add:
  - `CagConfig(arm: Literal["cag", "full_context_uncached"] = "cag", max_output_tokens, temperature)` (bounds as `AnswerConfig`).
  - `CagWorkflow` manifest `R47`, kind `workflow`, version 1.0.0, fidelity `adaptation`; `__init__(config, *, snapshot, anchors, index)`.
  - `_SnapshotRetriever` (not registered): every item as a `RetrievedChunk` (`chunk_id`, `extraction_view_id`, `start`, `end`, `block_ids`, `text`, `score=1.0`, `rank` = marker number) in `RetrievalResult(technique_id="R47", grounding="corpus", index_version_id=...)`.
  - `async answer(scope, question, *, prompts, chat, ledger) -> RunResponse`, guards in order, all before any chat call: `snapshot.check_scope`; re-fetch `index.get_index_version(scope, snapshot.index_version_id)` and require `ready` (else `cag_snapshot_mismatch`); `prompts.grounded.content_sha256` and `chat.profile.id` equal the snapshot's (else `cag_snapshot_mismatch`); arm `cag` and `snapshot.nonce in question` -> `RunError("cag_nonce_conflict")` (message without the nonce). Then `AnswerService(anchors, nonce_factory=...)` with the snapshot nonce (arm `cag`) or `secrets.token_hex(8)` per run (other arm), `AnswerConfig(min_score=0.0, max_evidence_chars=snapshot.max_evidence_chars)` and the re-fetched index version. If `"evidence_truncated"` appears in warnings, raise `cag_overflow` (should be unreachable).
  - `RunPins.k` is the `AnswerConfig` default and is not meaningful for R47 (all items are sent); comment this, and put the real item count in the trace.
  - `last_trace`: arm, snapshot_id, item_count, estimated_prompt_tokens, `prefix_sha256` (SHA-256 of the request text up to the question block). No text, no nonce.
- New `rag_foundry_answering.register_builtin_plugins(registry)` registering R47; wire into `test_builtin_kinds.py` (52 -> 53), `test_contract_kit.py` `_builtins()` and `new_technique.py` `_builtin_ids()`.
- Create `tests/answering/test_cag_workflow.py` (scripted chat citing the marker that holds the fact):
  - EN and AR questions answered; citations resolve `exact`; one chat call each on the answer ledger; trace item count equals the snapshot's.
  - Arm `cag`: `prefix_sha256` equal for two questions and captured requests byte-identical up to the question block. Arm `full_context_uncached`: prefixes differ.
  - Guards, each with zero chat calls: nonce in question -> `cag_nonce_conflict`; wrong prompt or chat profile -> `cag_snapshot_mismatch`; index version no longer ready (repository fake) -> `cag_snapshot_mismatch`; stranger scope fails.
  - Nonce secrecy: absent from `last_trace`, `RunResponse.model_dump_json()` and every error message; a scripted answer that echoes the bare nonce gives `abstained` (`invalid_citation`).
  - Losing cases: a fact not in the corpus -> scripted decline -> `abstained`; a corpus too large for the profile window is refused at build (`cag_overflow`) while R02 on the same index answers (comment: "CAG needs the whole corpus to fit; RAG does not").
