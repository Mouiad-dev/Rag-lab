## Goal
A shared, async core for model-based chunkers (context, cache port keyed by source text, model and prompt, rejection report, strict JSON parsing, delimited unit rendering, segment packing) and the C15 plugin: sentence units are embedded through the `EmbeddingModel` port, semantic breaks are placed where the cosine distance between neighbouring sentence windows passes a threshold, and segments are packed under a code-point budget. Every chunk boundary is a sentence (or word / safe-cut) boundary of the canonical text, so offsets always slice the source exactly.

  - `make_nonce(text: str, *others: str) -> str`: 16 lowercase hex; `sha256(text_sha256 + ":" + str(counter))[:16]` for counter 0, 1, 2, ... until it occurs in none of `text, *others`. Deterministic.

  - `segments_to_spans(text: str, units: Sequence[tuple[int, int, int]], break_after: Iterable[int], chunk_size: int) -> tuple[ChunkSpan, ...]`: `break_after` holds unit indexes `i` (0 <= i < len(units) - 1) after which a new segment starts. Each segment's units are packed with `pack(text, seg_units, chunk_size, 0)`. `split_level` = 0 when the packed chunk is the whole segment and all its units are sentences; otherwise `1 + max unit level` of that chunk (1 = budget split at sentences, 2 = word, 3 = safe cut). Returns spans sorted by `(start, end)`. Raise `ValueError` for an index outside the range.

- Create `packages/chunking/src/rag_foundry_chunking/semantic.py` (C15):
  - `SemanticConfig` (frozen, forbid): `chunk_size: int = 800` (32..8000); `buffer_size: int = 1` (0..3); `threshold_type: Literal["percentile", "std_dev", "absolute"] = "percentile"`; `threshold_amount: float = 90.0`; `embed_batch_size: int = 32` (1..256); `max_units: int = 5000` (1..50000). Validator: percentile amount in [0, 100], std_dev amount in [0, 10], absolute amount in [0, 2].
  - `SemanticChunker`: manifest `C15`, `PluginKind.CHUNKER`, `"1.0.0"`, `Fidelity.ADAPTATION`, `config_model=SemanticConfig`. `chunk(doc)` calls `unavailable_sync("C15")`.
  - `async def chunk_with_models(self, doc: ChunkInput, ctx: ModelChunkContext) -> ModelChunkResult`:
    1. `ctx.embedder` required (`missing_model`), its `profile.kind` must be `ModelKind.EMBEDDING` (`wrong_model_kind`); `ctx.prompt` is ignored and recorded as `None`.
    2. `units = build_units(text, chunk_size)`; more than `max_units` raises `too_many_units` before any model call. 0 or 1 unit: one span per unit packing, no model call, `cache_hit=False`, `model_calls=0`.
    3. Window `i` text = `text[units[max(0, i - b)][0] : units[min(n - 1, i + b)][1]]` for `b = buffer_size`.
    4. Cache key from `segmentation_cache_key(... prompt=None ...)`. On a hit the cached value is JSON `{"distances": [float, ...]}`; it is used only if it has exactly `n - 1` finite values in [0, 2]; otherwise it is ignored (recorded in `details["cache_invalid"] = True`) and recomputed. On a miss, embed windows in batches of `embed_batch_size` with `input_type="document"` (a vector count different from the batch raises `embedding_count_mismatch`), `distance_i = 1 - cosine(v_i, v_{i+1})` (a zero vector gives cosine 0), clamp to [0, 2], store JSON `{"distances": [...]}`.
    5. Threshold: `percentile` = linear interpolation between closest ranks on the sorted distances (`numpy.percentile` default method, implemented with stdlib); `std_dev` = mean + amount * population std dev; `absolute` = amount. A break goes after unit `i` when `distance_i > threshold` (strict).
    6. `spans = segments_to_spans(text, units, breaks, chunk_size)`; `details = {"threshold": t, "distances": [...], "break_after": [...], "unit_count": n}`; `model_calls` = number of embed calls on a miss, 0 on a hit; `usage` from those calls.
