## Goal
Deterministic, I/O-free functions build `SourceAnchor` v1 values from a pinned extraction payload and resolve an untrusted anchor against it, failing explicitly (never fuzzy, never relocated).

## Change
- `packages/ingestion/pyproject.toml`: depend on `rag-foundry-contracts` (workspace source); `uv lock`.
- `rag_foundry_domain/errors.py` + export in `__init__.py`: `AnchorError(IntakeError)` with codes `block_not_found`, `range_out_of_bounds`, `empty_range`, `no_block_in_span`, `invalid_namespace`; message never contains text.
- `rag_foundry_ingestion/anchors.py`:
  - `anchor_id_for(ref: SourceRef, block_id, start, end) -> str`: namespace must match `^[a-z0-9][a-z0-9._-]{0,63}$` else `AnchorError("invalid_namespace")`; `"anc_"` + first 32 hex of SHA-256 of `json.dumps(["anchor-id-v1", ns, doc, ver, view, block_id, start, end], separators=(",", ":"), ensure_ascii=True)` encoded UTF-8.
  - `make_anchor(payload, ref, block_id, start, end, *, context=32) -> SourceAnchor`: `block_text = canonical[b.start:b.end]`; require `0 <= start < end <= len(block_text)` (`empty_range` / `range_out_of_bounds`); `exact = block_text[start:end]`; `prefix`/`suffix` = up to `context` code points inside the block (None when empty); `section_path` and `page_index` from the block; `precision=exact_text`; `regions=()`; `page_label=None`.
  - `anchors_for_span(payload, ref, start, end, *, context=32) -> tuple[SourceAnchor, ...]`: canonical absolute span -> one anchor per overlapped block (clipped, block order); text between blocks is not cited; no overlap -> `no_block_in_span`.
  - `resolve_anchor(payload, view_ref, anchor) -> AnchorResolution`, checks in this order, first failure wins:
    1. namespace differs -> `unavailable/foreign_namespace`; 2. any of the four `source` IDs differs from `view_ref` -> `mismatch/source_mismatch`;
    3. `precision != exact_text`, or `text_range is None`, or `exact is None`, or `regions` non-empty -> `unavailable/unsupported_precision` (never `exact`);
    4. block missing -> `mismatch/block_not_found`; 5. `start == end` or `end > len(block_text)` -> `mismatch/range_out_of_bounds`;
    6. `block_text[start:end] != exact` -> `quote_mismatch`; 7. `prefix` not None and (`len(prefix) > start` or `block_text[start-len(prefix):start] != prefix`) -> `prefix_mismatch`; 8. `suffix` not None and `block_text[end:end+len(suffix)] != suffix` -> `suffix_mismatch` (None = not checked); 9. anchor `page_index` set and different from the block's -> `page_mismatch`.
    Compare code points as-is (canonical text is already NFC); never normalize the anchor's text. An exact result returns text, block_id, section_path, page_index from the view, never from the anchor.
- `tests/ingestion/test_anchors.py`: Arabic with harakat and a non-BMP emoji (code-point lengths, not UTF-16); multi-block span drops the separator; prefix/suffix clipped at block edges; ids deterministic, differ when any input differs, bad namespace raises; JSON round trip (`model_dump_json` -> `model_validate_json`) resolves the same; a decomposed (NFD) `exact` gives `quote_mismatch`; a `page` block gives `page_index` and empty `regions`; empty/out-of-range creation raises `AnchorError`.

- Escapes only for non-ASCII in code and tests.
