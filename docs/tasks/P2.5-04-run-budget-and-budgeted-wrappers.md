## Goal
A shared `RunBudget` is a hard cap: before every call it reserves the worst-case cost and refuses with `BudgetExceededError` if spent + reserved + worst case would pass `max_usd` (or `max_calls`). Each call then settles to its real cost. A stream stopped early keeps its reservation (D8). Embedding usage can now be recorded too.

## Change
- Edit `errors.py`: `BudgetError(ProviderError)`; `BudgetExceededError(BudgetError)` with `profile_id`, `limit` (`"usd"`|`"calls"`), `cap`, `spent`, `reserved`, `requested` (Decimal/int) in the message (numbers and profile id only); `UnboundedCostError(BudgetError)` naming the profile and the missing rate field; `BudgetRequiredError(BudgetError)` listing non-local profile ids (used by 05). None subclasses `ProviderCallError`.
- Create `rag_foundry_providers/budget.py`:
  - `RunBudget(max_usd: Decimal, max_calls: int | None = None)`; `max_usd` must be a finite Decimal >= 0 (float rejected). Thread-safe (`threading.Lock`). `reserve(profile, worst: Decimal) -> Reservation` raises before any I/O; `settle(reservation, usage: Usage | None)`: known cost replaces the reservation; None cost or no usage keeps the full reservation as spent and counts it in `unsettled_calls`. Read-only `snapshot()` (frozen model: spent_usd, reserved_usd, calls, unsettled_calls). Local profiles (D6) reserve 0 USD but count a call.
  - `worst_case_chat_cost(profile, request, default_max_output_tokens: int | None) -> Decimal` and `worst_case_embed_cost(profile, texts)` per D9; a non-local profile missing `cost_per_mtok_in` (or `_out` for chat) or an output cap → `UnboundedCostError`.
  - `BudgetedChatModel(model, budget, *, default_max_output_tokens)` and `BudgetedEmbeddingModel(model, budget)`: reserve, call, settle from `result.usage`, the final stream chunk usage, or `ProviderCallError.usage`; settle exactly once in `finally` (early `aclose()`, cancellation and errors included).
- Edit `ledger.py`: add `RecordingEmbeddingModel(model, sink)` (records `result.usage`; errors record nothing). Do not change `RecordingChatModel`.
- Edit `adapters/anthropic.py` and `adapters/openai_compat.py`: add read-only property `default_max_tokens -> int | None` on the chat models, returning the existing private value. Nothing else.
- Edit `__init__.py`: export the new names.
- Create `tests/providers/test_budget.py` (fakes plus scripted inner models; paid-rate profiles built in the test):
  - **Done:** cap USD 0.001; calls succeed until the next worst case would pass the cap, then `BudgetExceededError` (limit `usd`) and the inner model is not called.
  - `max_calls` overrun; unknown rate → `UnboundedCostError` before any call; local zero-key profile never blocked by USD.
  - settle: real cost below worst case frees the difference; cost None keeps the reservation.
  - stream consumer stops after one chunk → reservation kept, `unsettled_calls == 1`, ledger unchanged.
  - Arabic request bound >= its UTF-8 byte count; 10 concurrent calls via `asyncio.gather` never exceed the cap.
  - `RecordingEmbeddingModel` records once per call. Contract checks still pass through both budgeted wrappers.
