- First verify (PyPI, official colpali GitHub repo, colSmol-256M model card) and record in the module docstring: `colpali-engine` version and licence, its `transformers`/`torch`/`peft` requirements vs the locked `transformers 5.22.2` and `torch 2.15.0+cpu`, model/processor classes for colSmol (e.g. `ColIdefics3`/`ColIdefics3Processor`; confirm), whether a separate base checkpoint is needed, weights format, Pillow version/licence. - `ports.py`: `PageImageEncoder` Protocol: `profile`, `async encode_pages(pngs: Sequence[bytes]) -> MultivectorResult`, `async encode_queries(texts) -> MultivectorResult`.
- Create `colpali_pages.py`: `ColPaliPageEncoder(model_dir=None)` (env `RAG_VISUAL_MODEL_DIR`), lazy import, `local_files_only=True`, no remote code, safetensors only, CPU, float32, batch size 1.
