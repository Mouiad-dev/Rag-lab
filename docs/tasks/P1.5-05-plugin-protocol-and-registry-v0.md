## Goal
A `TechniqueRegistry` built from the loaded catalogue holds plugins keyed by catalogue ID. These cases raise explicit typed errors: unknown IDs (`UnknownTechniqueError`), catalogue entries with no plugin (`TechniqueUnavailableError`) and duplicate registrations (`DuplicatePluginError`). This closes the P1.5 done criteria.

## Change
- Create `src/rag_foundry_techniques/protocol.py`:
  - `PROTOCOL_VERSION = "0"`. `PluginKind` (StrEnum) with exactly the 12 ADR-0002 kinds. `Fidelity` (StrEnum): `faithful`, `adaptation`, `simulation`.
  - `PluginManifest` (pydantic, frozen, `extra="forbid"`): `technique_id`, `kind: PluginKind`, `version` (`^\d+\.\d+\.\d+$`), `fidelity: Fidelity`, `required_capabilities: frozenset[str] = frozenset()`, `config_model: type[BaseModel]` (`arbitrary_types_allowed`).
  - `TechniquePlugin` (`typing.Protocol`, `runtime_checkable`): `manifest: ClassVar[PluginManifest]`. Kind-specific methods (for example `chunk(...)`) are explicitly deferred; say so in the docstring.
- Create `src/rag_foundry_techniques/registry.py` with `TechniqueRegistry(catalogue: Catalogue)`:
  - `register(plugin_cls)`: the ID must be in the catalogue, else `UnknownTechniqueError`. A second plugin for the same ID raises `DuplicatePluginError`. The config model must have `extra="forbid"`, else `TechniqueError`. A class without a valid `manifest` raises `TechniqueError`.
  - `entry(tid)` delegates to `catalogue.get`.
  - `plugin(tid)`: unknown → `UnknownTechniqueError`; known without a plugin → `TechniqueUnavailableError` whose message names the ID and catalogue `status`.
  - `validate_config(tid, raw: Mapping)` returns the plugin's config model instance. Pydantic errors propagate.
  - `registered_ids()` returns them in sorted order. No built-in plugins are registered; no entry-point discovery.
- Export the public names from `__init__.py`. Update the README (v0 API, the three errors, trusted in-process code note from ADR-0002).
- Create `tests/techniques/test_registry.py`. Define a dummy test-only plugin for `C01` inside the test file:
  - A fresh registry over the real catalogue: for all 72 IDs, `entry()` works and `plugin()` raises `TechniqueUnavailableError`.
  - `plugin("X99")`, `entry("X99")` and registering a dummy with `technique_id="X99"` each raise `UnknownTechniqueError`.
  - Registering the C01 dummy works and `plugin("C01")` returns it. Registering it again raises `DuplicatePluginError`.
  - `validate_config` accepts a valid dict and rejects an unknown key (`ValidationError`). A config model without `extra="forbid"` is refused.
  - `PluginKind` has 12 members, matching ADR-0002.
- Edit `docs/PROGRESS.md`: P1.5 state and History line with exact commands and counts, only as actually run.
