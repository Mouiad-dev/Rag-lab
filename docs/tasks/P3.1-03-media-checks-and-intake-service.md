## Goal
`IntakeService` takes an authorized `Scope`, a byte stream, a raw declared media type and a filename, enforces limits and type rules while streaming, stores the bytes and returns an `IntakeOutcome`. Offline tests prove the P3.1 done criterion: same bytes dedup; changed bytes create a new version.

## Change
- Create `packages/ingestion` (`rag-foundry-ingestion`, depends on `rag-foundry-domain`; `rag-foundry-storage` only in tests); register in workspace, sources, dev group and `Dockerfile`.
- `rag_foundry_ingestion/media.py`:
  - `parse_media_type(raw: str | None) -> MediaType`: strip, lowercase, split off parameters; the base must be one of the four `MediaType` values else `UnsupportedMediaTypeError`; a `charset` parameter other than `utf-8`/`utf8` (case-insensitive) → `UnsupportedMediaTypeError` (415); other parameters ignored.
  - `validate_filename(name) -> str`: NFC-normalize, 1..255 code points, reject `/`, `\`, NUL, other control chars, leading/trailing spaces, `.` and `..` → `InvalidFilenameError`. Returns the NFC name; this is also the `display_name` of a new document.
  - `ContentInspector(declared: MediaType, filename)` fed chunk by chunk: extension matched case-insensitively (`.txt`; `.md`/`.markdown`; `.html`/`.htm`; `.pdf`) else `MediaTypeMismatchError`. PDF: first 5 bytes must be `%PDF-` (also when split across chunks). Text: strict incremental UTF-8 decode across chunk boundaries, NUL rejected, leading BOM recorded as `utf-8-sig`; invalid → `InvalidTextEncodingError`. `finish()` returns `text_encoding`. HTML is stored as untrusted bytes, never parsed.
- `rag_foundry_ingestion/intake.py` `IntakeService(store, repo, *, max_bytes)`:
  - `ingest(scope, chunks, *, media_type: str | None, filename: str, document_id: str | None = None) -> IntakeOutcome`.
  - Order: `repo.project_exists(scope)` else `NotFoundError` → if `document_id`: `repo.get_document(scope, document_id)` (raises `NotFoundError`) → `parse_media_type` → `validate_filename` → wrap `chunks` with the inspector → `store.stage(..., max_bytes)` → `inspector.finish()` → `key = store.key_for(scope, sha256)` → `store.commit` → `repo.create_document_or_get(..., display_name=<NFC filename>)` or `repo.add_version_or_get`. Any error before `commit` discards the staged object. All checks that need no bytes run before staging.
- Create `tests/ingestion/test_media.py` (each rule, both sides; `TEXT/PLAIN; charset=UTF-8` accepted, `charset=latin-1` rejected; `.PDF` accepted; Arabic character split across two chunks decodes; mixed Arabic/English filename accepted and NFC-normalized) and `tests/ingestion/test_intake.py` using `LocalObjectStore(tmp_path)` + `InMemoryDocumentRepository`:
  - **done criterion**: upload A → created doc v1; upload A again → `deduplicated`, same IDs, one object file; upload A' (one byte changed) as a version → v2, different sha256 and key; v1 still readable and unchanged; A again as a version → returns v1.
  - same bytes in another project → separate document; unknown project and another tenant's `document_id` → `NotFoundError` with no staging file created (assert the stream was never read); rejected uploads leave no staging or object files.
