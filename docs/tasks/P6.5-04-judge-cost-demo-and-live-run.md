## Goal
- An offline demo writes `docs/evidence/P6.5/judge_and_cost_demo.md`. It is byte-identical across runs and shows:
  - the judge plumbing, using **scripted** replies;
  - one `invalid_output`;

  - the agreement line "not yet measured".

## Change
- **Create `docs/techniques/lessons/demos/p65_judge_cost_demo.py`.** ASCII source, offline, using `StageSinks` and `RecordingChatModel`. Sections:
  1. **Items.** The 6 judge items: id, question, answer and evidence marker.
  2. **Scripted judge.** A `ScriptedChat` replies `{"label":"supported","reason":"scripted"}` for **every** item, except `j-05`, which gets the malformed reply `not json`. The scripted labels must not encode any intended answer.
     - The verdict table shows item, status, label, `prompt_sha256[:12]`, and rubric id and version.
     - A bold note says "scripted replies, identical for every item; not a judgement; shows plumbing only".
  3. **Agreement.** Print `render_agreement(agreement(verdicts, placeholder, rubric=...))`. It must contain "not yet measured (0 human labels)".
  4. **Cost and latency.** Print `render_cost_latency(usage={"judge": totals}, timings=(), ...)`. Latency is `not_measured` offline.

  The file starts with one header line: the command, the date, and "offline; scripted chat; no model; not a benchmark". It ends with `## Live run (orchestrator)` and `<orchestrator>` placeholders. The demo output must equal the file up to that heading.
- **Create `tests/live/test_judge_live.py`.**
  - Gate it with `RAG_LIVE_OLLAMA=1`. Use `gemma4:e4b` with `timeout_s=300`. Async: `def test_x(): asyncio.run(...)`.
  - Use one `TimingRecorder(time.perf_counter)` and `StageSinks` with the stages `judge_complete` and `judge_stream`. The stack is `TimingChatModel(RecordingChatModel(ollama, sinks.sink(stage)))`.
  - Call `judge_all(items)` with `JudgeConfig(mode="complete")`, then with `mode="stream"`. That is 12 calls.
  - Assert invariants only:
    - there are 12 timing records;
    - every `complete` record has `ttft_ms is None`;
    - every ok `stream` record with a TTFT has `0 <= ttft_ms <= total_ms`;
    - the ledger has 12 calls in total;
    - every verdict has `source == "llm_judge"` and the pinned rubric sha;
    - the agreement status is `not_yet_measured`.
  - Print:
    - the verdict table (item, mode, status, label, `reason[:80]`);
    - `render_cost_latency(usage=..., timings=recorder.records(), notes=(...))`;
    - the agreement line.
  - Add this module comment: "Whether Ollama already had the model loaded is not controlled; cold is the first call in this process, not a guaranteed model load."
