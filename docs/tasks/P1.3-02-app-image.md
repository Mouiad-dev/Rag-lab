## Goal
A multi-stage `Dockerfile` builds one non-root image containing `rag-foundry-api` and `rag-foundry-worker` from `uv.lock`. A static test pins and checks its base images. No image is built or pulled in this task.

## Read only these files
- `pyproject.toml` (virtual workspace root: no `[project]`; members)
- `apps/api/pyproject.toml` (script names, hatchling `src/` layout)
- `.gitignore` (mirror secret and cache exclusions)
- uv docs "Using uv in Docker": https://docs.astral.sh/uv/guides/integration/docker/ (verify `--locked --no-dev --all-packages --no-install-workspace --no-editable`, `UV_COMPILE_BYTECODE`, `UV_LINK_MODE=copy`, `UV_PYTHON_DOWNLOADS=0`)
- Docker Hub tag lists for `python` and `ghcr.io/astral-sh/uv` (check that the exact tags exist; do not pull them)

## Change
- Create `Dockerfile`:
  - `FROM ghcr.io/astral-sh/uv:<exact x.y.z> AS uv`. Use a uv version that satisfies `required-version >=0.7.9`.
  - Build stage `FROM python:3.12.<patch>-slim-<debian codename>`. Copy `/uv` from the uv stage. Copy `pyproject.toml`, `uv.lock` and each member `pyproject.toml` first, then run `uv sync --locked --no-dev --all-packages --no-install-workspace`. Then copy `packages/` and `apps/` and run `uv sync --locked --no-dev --all-packages --no-editable`.
  - Runtime stage: the same python tag. Create user `app` (uid/gid 10001) with no login shell. `COPY --from=build --chown=root:root /app/.venv /app/.venv`. Prepend `/app/.venv/bin` to `PATH`. Set `PYTHONDONTWRITEBYTECODE=1`, `PYTHONUNBUFFERED=1`, `USER 10001`, `EXPOSE 8000`, `CMD ["rag-foundry-api"]`.
  - Do not use an `ENV` or `ARG` that holds credentials, and do not set `RAG_FOUNDRY_API_HOST` in the image. Compose sets it (P1.3-03), so the code default `127.0.0.1` stays the safe default everywhere else.
- Create `.dockerignore` excluding: `.git`, `.venv`, `**/__pycache__`, `.pytest_cache`, `.ruff_cache`, `.env`, `.env.*`, `secrets/`, `*.pem`, `*.key`, `private/`, `data/`, `artifacts/`, `.claude/`, `docs/`, `tests/`, `node_modules/`, `apps/web/`.
- Create `tests/stack/test_dockerfile.py` (text parsing only, no docker):
  - Every `FROM` image has an explicit tag and no `latest`. The python tag matches `3.12.\d+-slim-\w+`, and the uv tag matches `\d+\.\d+\.\d+`.
  - The final stage has a `USER` that is not `root` or `0`.
  - No `ENV` or `ARG` name contains `KEY`, `SECRET`, `TOKEN` or `PASSWORD`.
  - `.dockerignore` contains `.env` and `.git`.

## Constraints

- Do not mount the Docker socket, and do not copy the whole repo context into the runtime stage.
