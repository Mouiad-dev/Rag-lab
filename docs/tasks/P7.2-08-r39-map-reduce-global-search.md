## Goal
R39 answers corpus-level questions as in GraphRAG global search, adapted:
- **Map:** one chat call per community summary returns a helpfulness score and points citing claim IDs.
- **Reduce:** one chat call combines the best points into an answer whose sentences cite point IDs.

Every citation resolves through point, claim and fact to original source spans. No usable point means an explicit abstention. Map and reduce usage are counted separately.

## Change
- Create `packages/indexing/src/rag_foundry_indexing/graph_global.py`:
  - `R39_MAP_SYSTEM_V1` and `R39_REDUCE_SYSTEM_V1`, each with its SHA (untrusted-JSON wording).
    - Map reply: `{"helpfulness": int 0-100, "points": [{"text", "claim_ids": [str]}]}`.
    - Reduce reply: `{"answer": [{"text", "point_ids": [str]}]}`.
  - `GlobalSearchConfig(extra="forbid")`:
    - `prefilter_top: int | None = None`. `None` maps every summary, as in the paper. An integer keeps only the top N summaries, ranked by `lexical_tokens` overlap between the query and the community's **entity names**, with `min_overlap` (1). Documented recall risk;
    - `max_map_calls` (20, 1-200). More candidates raises `global_search_too_many_communities` before any call;
    - `min_helpfulness` (1, 1-100), `max_points` (20), `max_point_chars` (400), `max_output_tokens`, `temperature=0.0`;
    - `on_invalid: Literal["fail", "skip"] = "fail"`.
  - **Invalid model output** (not JSON or wrong shape, i.e. `invalid_model_output`): usage is always recorded.
    - Map reply, `fail`: raise. `skip`: drop that summary, count it in `invalid_map_replies`, continue.
    - Reduce reply: never raises; the answer abstains with reason `reduce_invalid`.
    - `reduce_invalid` is an abstention reason, not an `IndexingError` code; no `errors.py` change.
  - `CommunityGlobalSearch`:
    - manifest `R39`, `RETRIEVER`, `1.0.0`, `Fidelity.ADAPTATION`;
    - constructor `(config, *, scope, graph, summaries, index, index_version, chat)`;
    - calls `graph.check_scope`; any summary whose `graph_key` differs raises `graph_key_mismatch`.
    - `retrieve(q)`: map step only. Hits are the original chunks behind kept points' claims, ordered by helpfulness then `community_id`, with score `helpfulness/100`. Summary text is never hit text.
    - `answer(q) -> GlobalAnswer`: map, then reduce.
  - **Map step:**
    - a point citing a claim ID outside its summary is rejected (`untraced_point`);
    - helpfulness below `min_helpfulness` drops the summary;
    - kept points are sorted and cut to `max_points`.
  - **Reduce step:** runs only if at least one point is kept. If none is kept (no candidates, all unhelpful, all points `untraced_point`, or all map replies invalid under `skip`), the answer abstains with `no_relevant_community` and `reduce_calls == 0`.
    - An answer sentence citing an unknown point ID is dropped and counted.
    - If no sentence is kept, the answer abstains with `reduce_untraced`.
  - `GlobalAnswer`:
    - `status`: `answered` / `abstained`;
    - `reason`: `no_relevant_community`, `reduce_untraced`, `reduce_invalid`, or `None`;
    - `sentences: tuple[CitedSentence(text, point_ids, claim_ids, sources: tuple[GraphSpan, ...])]`;
    - `map_calls`, `reduce_calls`, `map_usage`, `reduce_usage`, `rejected_points`, `invalid_map_replies`, `dropped_sentences`;
    - `summaries_used` (each `synthetic=True`).
  - `last_trace` on the retriever keeps the map outputs.
- `retrievers.py`: register `CommunityGlobalSearch`. Export the names.
- Create `tests/indexing/test_graph_global.py`:
  - **Success:** "Which organisations work with the Harbor Authority?" is answered. Every sentence has at least one source span whose quote equals the view slice. `map_calls == number of summaries`, `reduce_calls == 1`, and `len(map_usage) == map_calls`, `len(reduce_usage) == 1`.
  - **Losing case, nothing relevant:** an unrelated question (all helpfulness 0) gives `no_relevant_community`, `reduce_calls == 0`, no sentences.
  - **Losing case, all points untraced:** every point cites unknown claim IDs. They are all rejected, and the result is `no_relevant_community` with `reduce_calls == 0`.
  - **Losing case, reduce untraced:** the reduce reply cites only unknown point IDs, giving `reduce_untraced`.
  - **Invalid map output:**
    - `fail` raises;
    - `skip` with one invalid map reply drops it, counts it, records its usage, and still answers from the others;
    - `skip` with every map reply invalid gives `no_relevant_community`.
  - **Invalid reduce output:** gives `reduce_invalid`; `reduce_usage` has one entry.
  - **Losing case, prefilter:** with `prefilter_top=1`, an Arabic question about the English cluster has no candidates and abstains. With `prefilter_top=None` the same scripted run answers.
  - **Guards:** the cap raises before any call; stranger scope raises; summaries from another graph raise; the plugin passes `check_plugin_contract`.

## Constraints
- The reduce text is never evidence: citations are source spans only. The module docstring names the deviations from the paper: one level, one summary per map call, no shuffling or context-window batching of reports.
