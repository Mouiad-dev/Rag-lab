## Goal
`.github/workflows/ci.yml` runs `uv sync --locked` and `uv run python scripts/tasks.py check` on ubuntu-latest and windows-latest (this is the P1.1 clean-clone evidence), plus an ubuntu-only job that builds the app image and smoke-tests the compose stack. Every action is pinned to a verified commit SHA. A stdlib test guards those properties.

## Read only these files
- `.github/workflows/ci.yml` (existing stdlib-only job; replace it, do not add a second workflow)
- `scripts/tasks.py` (after P1.4-01: `check` = repo, lint, test)
- `compose.yaml`, `.env.example` (service names, `POSTGRES_PASSWORD` required, API on 127.0.0.1:8000)
- `Dockerfile` (uv image tag, to pin the same uv version in CI)
- Official docs: github.com/actions/checkout and github.com/astral-sh/setup-uv READMEs and release pages (inputs `persist-credentials`, `enable-cache`, `cache-dependency-glob`, `version`, `python-version`)

## Change
- Rewrite `.github/workflows/ci.yml`:
  - Triggers: `pull_request`, `push` to `main`. Top-level `permissions: contents: read`. `concurrency` group per ref with `cancel-in-progress: true`.
  - Job `check`: matrix `os: [ubuntu-latest, windows-latest]`, `fail-fast: false`, `timeout-minutes: 20`. Steps: checkout (`persist-credentials: false`); setup-uv (`version` = the uv version in the Dockerfile, `python-version: "3.12"`, `enable-cache: true`, `cache-dependency-glob: uv.lock`); `uv sync --locked`; `uv run python scripts/tasks.py check`. On ubuntu only, also run `docker compose --env-file .env.example config --quiet` so the compose model is validated even if pytest skipped (compose tests need no pulls; on Windows they may skip).
  - Job `image`: `runs-on: ubuntu-latest`, `needs: check`, `timeout-minutes: 20`. Write `.env` from `.env.example` with `POSTGRES_PASSWORD` replaced by `$(openssl rand -hex 24)` (never echoed); `docker compose up -d --build --wait`; `curl -fsS http://127.0.0.1:8000/health`; `docker compose ps`; always-run step `docker compose down -v` (runner is ephemeral). No ollama profile.
  - Every `uses:` is `owner/repo@<40-hex SHA> # vX.Y.Z`. Resolve SHAs with `git ls-remote --tags https://github.com/<owner>/<repo> 'refs/tags/vX.Y.Z*'` (use the peeled `^{}` SHA for annotated tags) and confirm the tag is a published release on its GitHub releases page. Use the latest stable major of each action. Drop `actions/setup-python` (setup-uv provides Python).
  - No `secrets.*`, no `pull_request_target`, no write permissions, no third-party actions beyond checkout and setup-uv.
- Create `tests/repo/test_ci_workflow.py` (stdlib text checks, no YAML dependency):
  - every `uses:` line matches `^\s*(-\s+)?uses:\s+[\w.-]+/[\w.-]+@[0-9a-f]{40}\s+#\s+v\d+\.\d+\.\d+\s*$`;
  - contains `permissions:` followed by `contents: read`, and no `: write`, `secrets.` or `pull_request_target`;
  - contains `uv sync --locked`, `scripts/tasks.py check`, `ubuntu-latest`, `windows-latest`.
- Edit `docs/VALIDATION.md` line about CI: describe the new jobs; still say it has not run yet.
