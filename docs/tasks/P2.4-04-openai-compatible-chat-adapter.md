## Change
- Edit `adapters/openai_compat.py`, add `OpenAICompatibleChatModel(profile, *, api_base, api_key_env: str | None, timeout_s=60.0, default_max_tokens=None, transport=None, clock=...)`:
  - Refuses at construction a profile declaring `tool_calling`, `structured_output` or `vision` as `True` (docstring: success paths deferred, see 05 ADR note). `check_chat_request` runs first in `complete`/`stream`, so tools or a schema raise `MissingCapabilityError` before any I/O.
  - Payload: `model`, `messages` (`system`/`user`/`assistant`; a `tool` role → `ProviderError` before any call), `max_tokens` field name per 01, `temperature` only when set, `stream`. Never sends `tools`, `tool_choice`, `response_format`. When streaming, sends `stream_options: {"include_usage": true}` only where 01 says the endpoint supports it.
  - `complete`: text from `choices[0].message.content`; `finish_reason` `stop` → `stop`, `length` → `length`, `content_filter` → `ProviderCallError(refused)`, `tool_calls` or anything else → `bad_response`. Billed failures attach `Usage` to `ProviderCallError.usage`.
  - `stream`: parse `data:` lines from `aiter_lines()`, stop at `[DONE]`; yield `delta.content`; an `error` object, invalid JSON or an end without `[DONE]` → `ProviderCallError`; close response and client in `finally`, including on early `break`.
  - Usage: `PROVIDER` when `prompt_tokens` and `completion_tokens` are ints ≥ 0. Missing usage: `ESTIMATED` for `local` profiles (same estimate helper as Ollama), `bad_response` for non-local (paid) profiles. Cached prompt tokens go to `cache_read_tokens` only if 01 documents the field and a rate exists, else cost is `None`.
- Create `tests/providers/test_openai_compat_chat.py` (MockTransport, canned JSON and SSE shaped per 01):
  - `CHAT_CHECKS` and `DETERMINISTIC_CHAT_CHECKS` pass for a local keyless profile and a non-local keyed profile.
  - Payload rules and refusals before any call; every `finish_reason`; stream with usage chunk, without usage (local vs paid), mid-stream error, missing `[DONE]`, early `break` closes.
  - Leak test as in 03 extended to `complete`, `stream` and `RecordingChatModel` + `UsageLedger` dumps.
