## Goal
`ResilientChatModel` and `ResilientEmbeddingModel` wrap any port implementation and add bounded retries with jittered backoff and a hard per-attempt deadline, deterministic in tests (injected sleep and RNG, no real waiting).

## Change
- Create `rag_foundry_providers/resilience.py`:
  - `RetryPolicy` (frozen pydantic, extra=forbid): `max_attempts` (D1, ge 1), `base_delay_s`, `max_delay_s`, `max_retry_after_s` (D2), `attempt_timeout_s` (D4, gt 0), `retry_timeouts_for_local: bool = True`. Defaults are module constants named `DEFAULT_*` with a comment pointing to ADR-0001 D1-D4.
  - `ResilientChatModel(model, policy, *, sleep=asyncio.sleep, rng: random.Random | None = None)`; `.profile` passes through.
  - `complete`: each attempt runs under `asyncio.timeout(attempt_timeout_s)`; `TimeoutError` becomes `ProviderCallError(pid, "timeout")` raised outside the `except` block (no cause/context). Retry only `ProviderCallError` whose reason is in `RETRYABLE_REASONS`, or `timeout` when `profile.capabilities.local is True` and `retry_timeouts_for_local`. Any other exception (including `MissingCapabilityError` and any non-`ProviderCallError`) propagates at once.
  - Delay: if `retry_after_s` is set: > `max_retry_after_s` → raise now; else sleep exactly that. Otherwise full jitter `rng.uniform(0, min(max_delay_s, base_delay_s * 2**(attempt-1)))`. After the last attempt the last error is raised unchanged.
  - `stream`: async generator; per attempt, read chunks with `asyncio.wait_for(anext(it), remaining)` against one deadline for the whole attempt (no `asyncio.timeout` spanning a `yield`). Retry (same rules) only if the error happens before the first chunk is yielded; after that, raise. Always `aclose()` the inner generator in `finally`.
  - `ResilientEmbeddingModel(model, policy, ...)`: same rules for `embed(texts, input_type=...)`.
- Edit `__init__.py`: export `RetryPolicy`, `ResilientChatModel`, `ResilientEmbeddingModel`.
- Create `tests/providers/test_resilience.py` with a scripted fake port (raises a queued sequence of errors, then delegates to `FakeChatModel`/`FakeEmbeddingModel`) and a recording fake sleep:
  - 503-then-success → 2 attempts, one sleep within the jitter bound; seeded RNG gives a fixed delay.
  - `retry_after_s=7` → sleep(7.0); `retry_after_s=120` → no retry, raised with no sleep.
  - each non-retryable reason → 1 attempt; `MissingCapabilityError` → 1 attempt.
  - `timeout` retried for a local profile, not for a non-local one.
  - deadline: an inner call that awaits forever (`asyncio.Event().wait()`) with `attempt_timeout_s=0.05` → `ProviderCallError` reason `timeout`, `__cause__` and `__context__` None.
  - stream: error before first chunk retried; error after first chunk not retried; stalled stream hits the deadline; inner generator closed on early consumer `aclose()`.
  - `CHAT_CHECKS + DETERMINISTIC_CHAT_CHECKS` and `EMBEDDING_CHECKS` pass through the wrappers around the fakes.
