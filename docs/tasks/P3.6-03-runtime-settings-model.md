## Change
- `packages/domain/src/rag_foundry_domain/errors.py`: `SettingsError(IntakeError)`, `CODES = ("unknown_key", "scope_not_allowed", "invalid_value", "invalid_file", "invalid_override", "version_conflict", "store_unavailable")`, same shape as `RunError`.
- Create `packages/domain/src/rag_foundry_domain/runtime_settings.py` (pydantic; `frozen=True, extra="forbid"`; strict int/bool; `allow_inf_nan=False`; bounds as named constants):
  - `AnswerSettings`: `max_output_tokens=512` (1..4096), `temperature=0.0` (0..2), `max_evidence_chars=12000` (500..100000), `min_scores: dict[str, float] = {"ollama/bge-m3/1024": 0.45}` (`MIN_SCORE_KEY = r"^[a-z0-9._-]{1,64}/[A-Za-z0-9._:-]{1,128}/[1-9][0-9]{0,4}$"`, values -1..1, at most 32 entries).
  - `RunSettings`: `max_attempts=2` (1..5), `attempt_timeout_s=120.0` (>0, <=600), `retry_timeouts_for_local=False`, `deadline_s=300.0` (>0, <=1800), `max_concurrent=1` (1..8).
  - `IndexingSettings`: `embed_batch_size=32` (1..256), `c05_chunk_size=800` (32..8000), `c05_chunk_overlap=100` (>=0, < chunk size).
  - `RuntimeSettings`: `schema_version: Literal[1] = 1`, `answer`, `run`, `indexing` (`default_factory`).
  - `Level = Literal["global", "tenant", "project"]`; `KEY_SCOPES: Mapping[str, frozenset[Level]]` per D5 (`run.max_concurrent` -> empty set); `ALLOWED_KEYS = frozenset(KEY_SCOPES)` (P3.6-07 copies this list into the DB CHECK).
  - `LayerOverride` (frozen dataclass): `level`, `key`, `value: int | float | bool | dict[str, float] | None` (None = reset).
  - `RunSnapshot` (frozen): `answer`, `run`, `sources: Mapping[str, str]` (`default`/`file`/`global`/`tenant`/`project` per key), `effective_json() -> str` = `json.dumps({"answer": ..., "run": ...}, sort_keys=True, separators=(",", ":"), ensure_ascii=True)` over `model_dump(mode="json")`, `sha256()` of that string.
  - `resolve_run(base, overrides, *, file_keys=frozenset()) -> RunSnapshot` and `resolve_indexing(base, overrides, *, file_keys=frozenset()) -> IndexingSettings`: apply global, then tenant, then project (later wins inside a level), using only keys of their own sections and ignoring the other section; a key whose section prefix is unknown, or a name not in `ALLOWED_KEYS`, -> `SettingsError("unknown_key")`; level not allowed -> `scope_not_allowed`; validate only the touched section models, failure -> `invalid_value` raised outside the `except` (no cause, no values). A value replaces the old one whole.
  - `load_runtime_settings_file(path) -> tuple[RuntimeSettings, frozenset[str]]`: UTF-8, <= 64 KiB, object root, duplicate keys rejected, partial nesting allowed, returns the dotted keys the file sets; any problem -> `SettingsError("invalid_file")`.
- `packages/core/src/rag_foundry_core/settings.py`: `runtime_config_path: Path | None = None`.
- Create `config/runtime.example.json`: every key with its default.
- Contracts: `source.py` `CONTRACT_VERSION = "1.1"`; `runs.py` module docstring says version 1.1 and `RunPins` gains `settings_sha256: Sha256 | None = None`, `prompt_sha256: Sha256 | None = None` (`Sha256 = Annotated[str, Field(pattern=r"^[0-9a-f]{64}$")]`); `packages/contracts/README.md` line 3 says `1.1` plus one line on what 1.1 added; regenerate schemas with `uv run python -m rag_foundry_contracts.export packages/contracts/schemas`; committed fixtures stay at 1.0, unchanged.
- Tests `tests/domain/test_runtime_settings.py`: defaults equal today's literals (0.45, 512, 0.0, 12000, 2, 120.0, False, 300.0, 1, 32, 800, 100); chunk defaults equal `RecursiveConfig()`; layer order (project > tenant > global > file > default) for both resolvers; reset falls back; an indexing override with overlap >= size breaks `resolve_indexing` but not `resolve_run`, and an invalid `answer.temperature` breaks `resolve_run` but not `resolve_indexing`; every error code, with a sentinel value absent from `str(err)`; `"5"` and NaN rejected; `sha256()` stable across dict order and changes with `answer.temperature`; file loader: example file equals defaults; duplicate key, > 64 KiB, non-object, unknown key -> `invalid_file`. `tests/contracts`: 1.0 fixtures validate; pins with both hashes round-trip; 63-char or uppercase hash rejected; schema drift test passes. `tests/core`: `RAG_FOUNDRY_RUNTIME_CONFIG_PATH` accepted.
