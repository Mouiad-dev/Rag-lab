## Goal
An authorized export of explicit extraction views and anchors produces a framework-neutral versioned bundle (JSON Schema committed); a validating importer loads it into a local, scope-bound bundle catalog that resolves the same anchors with no access to the original store, database or service (REUSE_AND_INTEGRATION §5, §7 gate 4).

- Create `packages/ingestion/src/rag_foundry_ingestion/bundle.py`:
  - `BundleError(ValueError)` with `.code`; `BundleLimits(max_files=1000, max_file_bytes=20_000_000, max_total_bytes=50_000_000, max_anchors=10_000)`.
  - `BundleExportService(store, uow, *, provider_namespace, clock)`. `export(scope, view_ids, anchors) -> dict[str, bytes]`: every view via `uow.extractions.get_view(scope, id)` first (a view outside `scope` raises `NotFoundError` before any payload read; no partial bundle); then payloads; every anchor must use this namespace, reference an exported view and resolve `EXACT` against it, else `BundleError("anchor_not_exportable")`. Files: `documents.json`, `structure.jsonl`, `anchors.jsonl` (one canonical JSON object per line, sorted keys, `ensure_ascii=False`), `text/<view_id>.txt`, `manifest.json` listing every other file with size and SHA-256; originals (and page renders when `page_count`) listed in `omitted`. `bundle_id = "bun_" + sha256(namespace, sorted view ids, sorted anchor ids)[:32]`.
  - `import_bundle(files: Mapping[str, bytes], limits) -> ImportedBundle` (pure, all-or-nothing): limits; manifest parses and version is 1.x; the file set equals manifest assets + `manifest.json` exactly; sizes and hashes match; UTF-8 strict; `char_count`/`canonical_sha256` match each text; blocks ascending inside the text; every anchor's namespace and view are in the manifest and it resolves `EXACT` (dangling or mismatched -> reject). Codes: `unsupported_version`, `too_large`, `bad_path`, `unlisted_file`, `missing_file`, `hash_mismatch`, `invalid_json`, `invalid_structure`, `dangling_anchor`.
  - `LocalBundleCatalog`: `add(scope, imported)` keyed by `(scope, bundle_id)`; same id and same manifest digest is a no-op; different digest -> `BundleError("bundle_conflict")`. `resolve(scope, anchors) -> tuple[AnchorResolution, ...]` in input order: foreign namespace -> `UNAVAILABLE/FOREIGN_NAMESPACE`; view not in a bundle added under this `scope` -> `UNAVAILABLE/NOT_FOUND` (same answer as "does not exist"); else `resolve_anchor`.
  - `write_bundle_dir(files, root)` (root must be absent or empty) and `read_bundle_dir(root, limits)`: reject symlinks, any directory other than `text/`, and any name failing the path rule.
- Create `tests/contracts/test_bundle_contract.py` (path rule incl. `../x`, `/abs`, `C:\\x`, `text/x.txt`; version 2.0 rejected; schema drift) and `tests/ingestion/test_source_bundle.py` using `extract_fixture` (Arabic, emoji, repeated paragraph): round trip export -> `write_bundle_dir` -> `read_bundle_dir` -> import into a fresh catalog under a different scope -> every anchor resolves `EXACT` with the same `exact`, `block_id`, `section_path` while the original store is replaced by one that raises on any read; exported bytes contain neither scope UUID; export with a view of another tenant raises `NotFoundError` and reads no payload; resolve from a third scope -> `NOT_FOUND`; tampered text -> `hash_mismatch`; extra file -> `unlisted_file`; symlink (skip if the OS refuses) and `../` -> rejected; anchor with an edited `exact` -> `dangling_anchor`; re-add same bundle is a no-op, same id with changed bytes -> `bundle_conflict`; limits exceeded -> `too_large`.

## Constraints
- Stdlib + pydantic only; no DB, no migrations, no HTTP route (routes are P5+). Do not export originals, signed URLs, ORM rows or tenant IDs. Hashes detect accidental mismatch only; say so in the module docstring.
- Non-ASCII in Python source only as `\u` escapes.
