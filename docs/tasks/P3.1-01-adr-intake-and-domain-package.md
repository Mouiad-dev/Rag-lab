## Change
- Create `docs/decisions/ADR-0009-document-intake-and-versions.md` (max ~65 lines; add README row): lineage `Document → DocumentVersion` (immutable bytes, hash, media type, object key; no update path; anchors later belong to versions, never to chunks); scope `(tenant_id, project_id)` only from auth context; dedup is atomic inside the repository; when several documents in a project hold the same bytes, dedup returns the earliest-created version (ties: lowest version ID); re-uploading v1's bytes as a version of the same document returns v1 (dedup), even when v2 exists; a DB failure after `commit` can leave an unreferenced content-addressed object (harmless, later cleanup job). Decisions, all "decided by owner 2026-11-05":
  D1 upload = `multipart/form-data` with one file part, parsed by `python-multipart` (FastAPI's form parser), exact pin, verified in 05; declared media type = the part's `Content-Type`, filename = the part's filename · D2 SQLAlchemy 2 async + Alembic + `psycopg[binary]` 3, exact pins, verified in 04 · D3 new-document upload dedups by sha256 within the project; new-version upload dedups within that document only · D4 object store root `var/objects` locally, `/data/objects` volume in compose · D5 formats `.txt`, `.md`, `.html`, `.pdf`; text must be UTF-8 · D6 max upload 100 MiB, configurable, ceiling 1 GiB · D7 object key `t/{tenant}/p/{project}/sha256/{hh}/{hex}` · D8 filename is display metadata only, NFC, 1..255 code points, no separators/control chars · D9 IDs UUID4 strings · D10 no real auth yet: dev/test map to `LOCAL_DEV_SCOPE`; prod refuses (401) · D11 DB tests in a CI `db-tests` job and locally against compose profile `test` service `testdb` (tmpfs) · D12 201 created / 200 dedup.
