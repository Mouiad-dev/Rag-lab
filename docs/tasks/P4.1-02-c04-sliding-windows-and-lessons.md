## Change
- Create `packages/chunking/src/rag_foundry_chunking/sliding.py`:
  - `SlidingWindowConfig` (frozen, `extra="forbid"`): `unit: Literal["chars", "words", "tokens"] = "words"`, `window_size: int = 200` (ge=2, le=8000), `overlap: int = 50` (ge=1); validator: `overlap <= window_size // 2`. For `unit="chars"` also require `window_size >= 8`. `tokenizer: Literal["lab-regex-v1"] = "lab-regex-v1"` (used only for `unit="tokens"`).
  - `SlidingWindowChunker`: manifest `C04`, `PluginKind.CHUNKER`, `1.0.0`, `Fidelity.FAITHFUL`; `__init__(self, config, tokenizer=None)` like C03. Uses `pack_windows` with the units of the chosen kind (char clusters weighted by length; words and tokens weight 1) and `overlap=config.overlap`. Do not change `pack_windows` semantics; if a real bug in it shows up, fix it and add a regression test that fails without the fix, and say so in Result.
  - `WindowStats` (frozen pydantic or dataclass): `chunks`, `stored_code_points` (sum of span lengths), `unique_code_points` (size of the union of spans), `duplicated_code_points` (`stored - unique`), `storage_ratio` (`stored / unique`, `0.0` when no spans). `window_stats(spans) -> WindowStats`.
- Edit `__init__.py`: export `SlidingWindowChunker`, `SlidingWindowConfig`, `WindowStats`, `window_stats`; register `SlidingWindowChunker` (add lines only).
- Create `tests/chunking/test_sliding.py` (non-ASCII as `\u` escapes; Arabic samples asserted NFC):
  - For each unit: adjacent spans overlap, the overlap measured in that unit (code points for chars, whitespace words for words, tokens for tokens) is `>= 1` and `<= overlap` whenever a window was full, every window holds `<= window_size` units, strictly increasing starts and ends, offsets exact, every non-whitespace code point covered.
  - A boundary fact: a short fact sentence placed so C02 (no overlap) splits it across two chunks, while C04 with words and enough overlap has one span that contains the whole sentence. Assert both.
  - `window_stats`: hand-computed example (e.g. spans (0,10), (6,16) -> stored 20, unique 16, duplicated 4, ratio 1.25); C04 on a longer text has `storage_ratio > 1` and C01 on the same text has `duplicated_code_points == 0`.
  - Arabic words text with `،` and harakat: words unit keeps punctuation attached; chars unit never cuts before `َ`.
  - Config: rejects `overlap > window_size // 2`, `unit="chars"` with `window_size < 8`, unknown keys; registry default for `C04` equals `SlidingWindowConfig()`; seeded random property test (200 texts, all three units).
