## Goal
Running `uv sync --locked` then `uv run pytest` on a clean clone installs a minimal uv workspace containing one member, `packages/core`. Pytest runs the existing hook tests plus a single smoke test, and ruff passes on the new code.

## Read only these files
- `.gitignore` (already ignores `.venv/`, `.pytest_cache/`, `.ruff_cache/`; keep it as is unless something is missing)
- `.github/workflows/ci.yml` (CI uses Python 3.12; do not edit it here)
- `tests/hooks/test_dev_hooks.py` (unittest-style; pytest must collect it unchanged)
- `scripts/verify_package.py` lines 14-40 (it syntax-checks every `*.py`/`*.json`/`*.md` outside `.venv` and checks every local Markdown link)
- uv docs: workspaces and dependency groups (docs.astral.sh/uv/concepts/projects/workspaces/)

## Change
- Create the root `pyproject.toml` as a **virtual workspace root** with no `[project]` table:
  - `[tool.uv] required-version = ">=0.7.9"`. `[tool.uv.workspace] members = ["packages/core"]`. Use an explicit list, not `apps/*`, because `apps/web` will hold Node code later and has no `pyproject.toml`.
  - `[dependency-groups] dev = ["pytest", "ruff", "rag-foundry-core"]` with `[tool.uv.sources] rag-foundry-core = { workspace = true }`. A plain `uv sync` then installs the members. If uv 0.7.9 does not allow this in a virtual root, use `uv sync --all-packages` instead and record that under Deviations.
  - Lower bounds: take whatever versions `uv add` resolves today and write them as `>=X.Y`. Do not invent numbers.
  - `[tool.ruff]` `target-version = "py312"`, `line-length = 120`, `extend-exclude = [".claude", "scripts", "tests/hooks"]` so existing files are not reformatted. `[tool.ruff.lint] select = ["E", "F", "W", "I", "UP", "B"]`.
  - `[tool.pytest.ini_options]` `testpaths = ["tests"]`, `addopts = ["--import-mode=importlib", "--strict-markers"]`, `minversion = "8.0"`.
- Create `packages/core/pyproject.toml`: name `rag-foundry-core`, version `0.0.0`, `requires-python = ">=3.12"`, no runtime dependencies yet. Build backend is `hatchling` (src layout).
- Create `packages/core/src/rag_foundry_core/__init__.py` with only `__version__ = "0.0.0"`.
- Create `tests/core/test_import.py`: one test asserting `rag_foundry_core.__version__ == "0.0.0"`.
- Generate and commit `uv.lock`. It is generated, so it does not count toward diff size.

## Constraints
- `requires-python = ">=3.12"` everywhere, with no upper bound. CI tests the 3.12 floor, the developer's local 3.14 covers the newest version, and the lock is universal.
- Do **not** commit `.python-version`. Pinning 3.12 would make uv download an interpreter, which needs the user's OK. Leave it as an open question.
- Hook tests stay unittest. They keep working with `python -m unittest` and are also collected by pytest. Do not edit them.
- Do not use vendor SDKs or add dependencies beyond pytest, ruff and hatchling.
